Lesson overview

Period 13 · Check Digits

Topic 2 · Data Transmission: Students learn how a check digit is used to detect errors in data entry and identify common examples such as ISBNs and bar codes.

Success criteria: Students can explain the purpose of a check digit, describe how it is generated from other digits, explain how a receiver/system recalculates and compares it, and identify ISBNs and bar codes as examples.

Important syllabus distinction: A check digit is used to detect errors in data entry; it is not the same as a parity bit, checksum or echo check used after transmission. citeturn0search12

Key vocabulary: check digit, validation, data entry, recalculation, comparison, ISBN, bar code, error detection.

My teaching route

Move from transmission errors to entry errors

  1. Retrieve parity, checksum and echo check.
  2. Introduce the new problem: data can be entered incorrectly.
  3. Show an ordinary identification number with an additional check digit.
  4. Explain that the check digit is calculated from the other digits.
  5. At checking time, recalculate and compare.
  6. Use ISBN and bar-code examples.
  7. Clarify that a check digit detects likely entry errors; it does not prove all data is correct.
Teaching principle: Students should first understand the purpose and process; detailed real-world algorithms should only be taught when specifically required.
0–6 min · Retrieval

Three transmission checks

Parity: count the 1s.
Checksum: calculate and compare a value.
Echo: return and compare the data.

Now consider a different problem: a person types a number into a system and accidentally enters one digit incorrectly. How could the system detect that?

6–15 min · Teach

What is a check digit?

A check digit is an extra digit added to a number. It is calculated from the other digits and is used to help detect errors when the number is entered.

4827?
data digits → calculated check digit
Core idea: The final digit is not simply another piece of identification data. It carries information that allows the entered number to be checked.
15–24 min · Process

How does the check work?

1. Start with the original digits.
2. Apply the specified calculation.
3. Produce the check digit.
4. Store or print the complete number.
5. When the number is entered later, repeat the calculation.
6. Compare the calculated check digit with the supplied check digit.

If the values do not match, the system can flag the entry as potentially incorrect.

24–32 min · Simple classroom example

Understanding the calculation

For a classroom demonstration, suppose a system uses this simplified rule:

Add the first four digits and use the final digit of the total as the check digit.
4 + 8 + 2 + 7 = 21
Check digit = 1

The complete number would therefore be 48271.

Important: This is a teaching example only. Real ISBN and bar-code check-digit algorithms use specified standards and calculations.
32–38 min · Error demonstration

What if a digit is entered incorrectly?

Original number: 48271

Suppose a user enters: 48371.

4 + 8 + 3 + 7 = 22
Calculated check digit = 2
Entered check digit = 1
2 ≠ 1 → the check fails → the system can flag a possible data-entry error.

1 · The problem

People can make mistakes while typing or entering numbers. A digit may be changed, omitted or entered incorrectly.

Question: How can the computer recognise that an entered number may be wrong?

2 · The check digit

A check digit is an extra digit calculated from the other digits in the number.

48271
data digits + check digit
The checking system knows the rule used to calculate the final digit.

3 · A simple example

Use the classroom rule: add the first four digits and take the final digit of the total.

4 + 8 + 2 + 7 = 21
Check digit = 1

So the complete number is 48271.

4 · Checking an entered number

The user enters 48271.

The system recalculates the check digit:

4 + 8 + 2 + 7 = 21
Calculated = 1 · Entered = 1
Match → the check passes.

5 · Detecting an error

The user accidentally enters 48371.

4 + 8 + 3 + 7 = 22
Calculated = 2 · Entered = 1
Mismatch → the system flags a possible error.

9 · Exam practice

Question: Explain how a check digit is used to detect an error in data entry.

A check digit is calculated from the other digits in a number. When the number is entered, the check digit is calculated again and compared with the entered check digit. If they do not match, an error in the entered data is indicated.

10 · Challenge

Why is a check digit not normally described as an encryption method?

A check digit is used to detect errors in data entry. It does not transform data to protect it from unauthorised readers, which is the purpose of encryption.

11 · Common mistakes

  • Confusing a check digit with a parity bit.
  • Forgetting that the syllabus uses check digits for data-entry error detection.
  • Thinking the check digit corrects the wrong data automatically.
  • Claiming that a matching check digit guarantees every possible error has been detected.
  • Using an invented classroom calculation as if it were the real ISBN or bar-code standard.
