Period 16 · Choosing the Right Encryption Method

This consolidation lesson brings together encryption, symmetric encryption and asymmetric encryption. Students practise selecting and explaining the appropriate key model for a scenario.

Success criteria: Students can explain the need for encryption, distinguish symmetric from asymmetric encryption, identify public/private keys, and construct a clear exam-quality explanation of a confidential transmission.

16–25 min · Scenario 1

Two devices already share a secret

Two authorised systems already possess the same secret key and need to protect a large stream of data.

Best model: symmetric encryption.
Reason: both systems already have the shared secret key, and symmetric encryption is efficient for large amounts of data.
25–33 min · Scenario 2

A recipient publishes a key

A sender wants to send confidential information to a recipient without receiving the recipient's private key.

Best model: asymmetric encryption.
Process: sender uses recipient's public key to encrypt; recipient uses the corresponding private key to decrypt.

33–40 min · Exam technique

Build a 4-part answer

1. Name the method → symmetric or asymmetric.
2. Identify the key(s) → shared secret or public/private pair.
3. Describe the process → encrypt → transmit → decrypt.
4. Link to the scenario → explain why the method fits.

This prevents vague answers such as “encryption makes data safe.”

40–45 min · Misconceptions

Four traps

  • Encryption is not the same as error detection.
  • Symmetric encryption does not use a public/private pair.
  • The private key is not shared publicly.
  • For confidentiality, do not reverse the recipient's public/private key sequence.
45–50 min · Assessment

Mastery check

  1. Explain the purpose of encryption when transmitting data.
  2. Describe symmetric encryption.
  3. Describe asymmetric encryption.
  4. Explain the role of public and private keys.
  5. Compare the two methods.

Encryption protects confidentiality. It is different from methods that detect transmission errors.

2 · Symmetric encryption

ONE SHARED SECRET KEY

The sender and receiver use the same secret key for the corresponding encryption and decryption processes.

3 · Asymmetric encryption

PUBLIC KEY + PRIVATE KEY

For a confidential message, the sender can use the recipient's public key to encrypt. The recipient uses the corresponding private key to decrypt.

5 · Exam-quality model

Question: Explain how asymmetric encryption can be used to transmit confidential data.

The sender obtains the recipient's public key and uses it to encrypt the plaintext. The encrypted data, or ciphertext, is transmitted. The recipient uses the corresponding private key to decrypt the ciphertext and recover the plaintext. The private key is kept secret.
