Lesson overview

Period 9 · Echo Check

Topic 2 · Data Transmission: Students learn how an echo check can detect errors by sending received data back to the sender so that it can be compared with the original.

Success criteria: Students can explain the echo check sequence, identify where comparison takes place, explain what a mismatch means, and compare echo checking with parity and checksum methods.

Prior learning: Periods 6–8 — transmission errors, parity checks and checksums.

Key vocabulary: echo check, original data, received data, return transmission, comparison, mismatch, error detection.

My teaching route

Make the return journey visible

  1. Retrieve the purpose of error detection.
  2. Ask how the receiver could prove what it received.
  3. Introduce the echo check sequence.
  4. Trace the original data → receiver → data sent back → comparison.
  5. Show a successful match.
  6. Change one piece of data and show a mismatch.
  7. Compare echo check with parity and checksum.
Memory rule: Echo check = send → receive → send back → compare.

5–14 min · Teach

What is an echo check?

In an echo check, the receiver sends the data it received back to the sender. The sender compares the returned data with the original data.

Advantages and disadvantages

AdvantagesLimitations
Simple concept: compare the returned data with the original.Extra data must be transmitted back to the sender.
Can detect a difference between original and returned data.Uses additional time and communication bandwidth.
Easy to understand and implement in suitable systems.A matching return does not prove that every possible error is impossible.
37–42 min · Compare

Three error-detection methods

MethodWhat is checked?
ParityWhether the number of 1s follows an agreed rule.
ChecksumWhether a calculated checking value matches.
Echo checkWhether returned data matches the original.
Think in actions: Parity counts · Checksum calculates · Echo check returns and compares.

5 · Why is extra transmission needed?

The receiver has to send the received data back to the sender. This creates an additional transmission and therefore uses additional communication resources.

Advantage: direct comparison with the original data.
Disadvantage: additional transmission is required.

6 · Compare the methods

MethodMemory clue
ParityCount the 1s.
ChecksumCalculate a value.
Echo checkReturn and compare.

7 · Exam practice

Question: Describe how an echo check is used to detect errors in transmitted data.

The receiver sends the data it received back to the sender. The sender compares the returned data with the original data. If they are different, an error has been detected.

8 · Challenge

Why does an echo check require more communication than simply receiving the original data?

Because the received data must be transmitted back to the sender for comparison, creating an additional transmission.

9 · Common mistakes

  • Thinking the receiver compares the data with the original when it may not have the original.
  • Forgetting that the received data is sent back.
  • Saying a match proves that no error is possible.
  • Confusing echo check with checksum.
  • Forgetting the extra transmission is a limitation.
