Lesson overview

Period 6 · Why Do We Need Error Detection?

Topic 2 · Data Transmission: Students now move from how data is transmitted to an essential question: How can we know whether transmitted data has been changed, lost or gained?

Success criteria: Students can explain why errors occur during transmission, identify data loss, data gain and data change, and explain why transmitted data must be checked.

Prior learning: Periods 3–5 — transmission modes, serial/parallel transmission and USB.

Key vocabulary: error, interference, data loss, data gain, data change, error detection, parity, checksum, echo check.

My teaching route

Build the need before teaching the methods

  1. Retrieve serial transmission and USB.
  2. Introduce the idea that transmitted data can be affected by interference.
  3. Show three possible errors: loss, gain and change.
  4. Ask why the receiver cannot simply assume the data is correct.
  5. Introduce the purpose of error detection.
  6. Preview the methods that follow: parity check, checksum and echo check.
Teaching principle: Students should understand why error detection is needed before memorising individual checking methods.

32–38 min · Teach

Why check for errors?

  • Incorrect data can produce an incorrect result.
  • Errors can corrupt files or messages.
  • Incorrect transmitted information can affect systems and decisions.
  • A receiver needs a way to establish whether received data is likely to be correct.
Exam sentence: Error detection is needed because data can be altered, lost or gained during transmission due to interference.

1 · The big idea

Sending data does not guarantee that the receiver gets exactly the same data.

Electrical or electromagnetic interference and other transmission problems can affect data as it travels between devices.

2 · Data loss

Data loss occurs when some of the transmitted data does not arrive at the receiver.

Sent: 101101
Received: 10101
One or more bits have been lost.

3 · Data gain

Data gain occurs when extra data appears in the received information.

Sent: 101101
Received: 1011101
Extra information has appeared.

4 · Data change

Data change occurs when transmitted data is altered during transmission.

Sent: 101101
Received: 100101
A bit has changed.

5 · Quick check

Q2: Extra bits appear in the received data. What type of error is this?

Q3: A 1 is received as a 0. What type of error is this?

6 · Why do we need error detection?

Imagine downloading an important file. If one part of the data changes during transmission, the file may no longer be correct.

Error detection is needed because interference during transmission can cause data to be lost, gained or changed. Checking allows the receiver to determine whether an error has occurred.

7 · Method preview

You will soon learn three important error detection methods:

  • Parity check — checks the number of 1s using an added parity bit.
  • Checksum — compares a calculated value associated with the data.
  • Echo check — sends received data back for comparison with the original.
Don't memorise the full procedures yet. Today's goal is to understand why checking is necessary.

8 · Challenge

A student says: “If the receiver gets a complete message, the message must be correct.” Is this always true?

9 · Common mistakes

  • Thinking error detection means correcting every error automatically.
  • Confusing data loss with data change.
  • Forgetting that interference can cause transmission errors.
  • Writing “data is wrong” instead of naming the specific type of error.
  • Trying to memorise parity/checksum before understanding the need for checking.
