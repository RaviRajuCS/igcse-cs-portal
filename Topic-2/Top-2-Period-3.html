Lesson overview

Period 3 · Transmission Modes

Topic 2 · Data Transmission: Students learn the three transmission modes: simplex, half-duplex and full-duplex.

Success criteria: Students can define all three modes, distinguish the direction of communication and select a suitable mode for a given scenario.

Prior learning: Periods 1–2 — data packets, packet switching and routers.

Key vocabulary: simplex, half-duplex, full-duplex, one direction, both directions, simultaneously, transmission mode.

My teaching route

Teach direction before terminology

  1. Draw two devices, A and B.
  2. For simplex, draw an arrow only A → B.
  3. For half-duplex, draw arrows A ↔ B but explain that only one direction operates at a time.
  4. For full-duplex, show two simultaneous arrows A ↔ B.
  5. Attach a familiar example to each mode.
  6. Finish with scenario selection questions.
Memory rule: Simplex = one way · Half-duplex = two ways, one at a time · Full-duplex = two ways at the same time.

Simplex transmission

Simplex mode occurs when data can be sent in one direction only.

Example from the textbook: sending data from a computer to a printer.

Teaching question: Can the printer send data back to the computer using the same simplex communication?

14–23 min · Teach

Half-duplex transmission

A
↔
B

Half-duplex mode allows data to be sent in both directions, but not at the same time.

Example from the textbook: a walkie-talkie. A person can transmit or receive, but the two directions cannot operate simultaneously.

Teaching question: Why do people say “over” when using a walkie-talkie?

23–32 min · Teach

Full-duplex transmission

A
⇄
B

Full-duplex mode allows data to be sent in both directions at the same time.

Example from the textbook: a broadband internet connection.

Teaching question: What advantage does simultaneous two-way communication provide?

7 · Exam practice

Question: Explain the difference between half-duplex and full-duplex transmission.

Half-duplex allows data to travel in both directions, but not at the same time. Full-duplex allows data to travel in both directions at the same time.

8 · Common mistakes

  • Thinking half-duplex means one direction only.
  • Forgetting the phrase “at the same time” for full-duplex.
  • Confusing the direction of transmission with the route through a network.
