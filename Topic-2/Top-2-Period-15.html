Lesson overview

Period 15 · Asymmetric Encryption

Topic 2 · Data Transmission: Students extend their understanding of encryption by learning the public/private key model used in asymmetric encryption.

Success criteria: Students can explain why asymmetric encryption uses two related keys, distinguish a public key from a private key, describe how a public key can be used to encrypt data for a recipient, and explain why the private key must be kept secret.

Prior learning: Periods 11–12 — encryption, plaintext, ciphertext, keys and symmetric encryption.

Key vocabulary: asymmetric encryption, public key, private key, key pair, plaintext, ciphertext, encryption, decryption.

25–33 min · Key security

Why is the private key private?

The public key is intended to be shared. The private key must be kept secret by its owner.

KeyWhat happens?
Public keyCan be distributed to others.

Never reverse them in a confidentiality question: encrypt with the recipient's public key; decrypt with the recipient's private key.

39–44 min · Clarify

What students must not confuse

Public ≠ secret. The public key can be shared.
Private = secret. The private key must be protected.
Encryption ≠ error detection. Encryption protects confidentiality; parity/checksum/echo/ARQ deal with transmission integrity and reliable delivery.

5 · Why is this useful?

With symmetric encryption, two parties need to share the same secret key. Asymmetric encryption provides a public key that can be distributed without revealing the corresponding private key.

Main idea: the private key does not need to be published simply so that others can encrypt messages for its owner.

6 · Symmetric vs asymmetric

QuestionSymmetricAsymmetric

7 · Exam practice

Question: Explain how asymmetric encryption can be used to send confidential data to a recipient.

The sender obtains the recipient's public key and uses it to encrypt the plaintext. The resulting ciphertext is sent to the recipient. The recipient uses the corresponding private key to decrypt the ciphertext and recover the plaintext.

8 · Challenge

Why is it safe to distribute a public key while the private key must be protected?

The public key is intended for distribution and is not the secret key that the owner must protect. The corresponding private key is kept secret and is used by the owner for the appropriate cryptographic operation.

9 · Common mistakes

  • Calling the public key secret.
  • Giving the recipient's private key to the sender for confidentiality.
  • Forgetting that asymmetric encryption uses a pair of related keys.
  • Confusing asymmetric encryption with symmetric encryption.
  • Thinking the public key and private key are simply two unrelated passwords.
