5–15 min · Question 1

Purpose of encryption

Question: Explain why encryption is used when transmitting data.

Marking points: data is transformed into ciphertext / prevents unauthorised people from understanding the data / protects confidentiality.

Model: Encryption transforms readable plaintext into ciphertext so that an unauthorised person intercepting the transmission cannot readily understand the information.

15–25 min · Question 2

Symmetric encryption

Question: Describe how symmetric encryption is used to transmit data.

Expected sequence: plaintext → shared secret key used to encrypt → ciphertext transmitted → same shared secret key used to decrypt → plaintext recovered.

Common lost mark: saying only “a key is used” without stating that it is the same shared secret key.

25–35 min · Question 3

Asymmetric encryption

Question: Describe how a sender can send confidential data to a recipient using asymmetric encryption.

Expected sequence: sender obtains recipient's public key → encrypts plaintext → sends ciphertext → recipient uses corresponding private key to decrypt.

Common lost mark: reversing public and private keys in the confidentiality sequence.

🎯 Before you begin

Remember these five terms:
Encryption · Plaintext · Ciphertext · Symmetric · Asymmetric

And remember the key rule:

Symmetric → same secret key.
Asymmetric → public/private key pair.

1 · Quick diagnostic

Encryption primarily protects:

Which is the original readable data?

2 · Structured question

Explain symmetric encryption.

The sender uses a shared secret key to encrypt the plaintext and produce ciphertext. The ciphertext is transmitted to the receiver. The receiver uses the same shared secret key to decrypt the ciphertext and recover the plaintext.

3 · Structured question

Explain asymmetric encryption for confidential communication.

The sender uses the recipient's public key to encrypt the plaintext. The ciphertext is transmitted. The recipient uses the corresponding private key to decrypt the ciphertext and recover the plaintext. The private key is kept secret.

4 · Scenario challenge

A school wants to send a confidential report to a recipient whose public key is available. Which encryption model is appropriate?

Asymmetric encryption fits because the sender can use the recipient's public key without needing the recipient's private key. The recipient can then use the private key to decrypt.

5 · Key-direction test

For confidential communication using asymmetric encryption, complete the sequence:

Recipient's ______ key → encryption → ciphertext → recipient's ______ key → decryption.

6 · Compare for marks

Complete this sentence:

“The main difference is that symmetric encryption uses __________, whereas asymmetric encryption uses __________.”
Symmetric encryption uses the same shared secret key for encryption and decryption, whereas asymmetric encryption uses a related public/private key pair.

7 · Final exam question

Question: Explain why encryption is important when data is transmitted and describe how both symmetric and asymmetric encryption can provide confidentiality.

Encryption protects confidentiality by transforming plaintext into ciphertext so unauthorised people cannot readily understand intercepted data. In symmetric encryption, the same shared secret key is used for encryption and decryption. In asymmetric encryption, the sender can use the recipient's public key to encrypt and the recipient uses the corresponding private key to decrypt.
