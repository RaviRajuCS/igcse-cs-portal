String Processing

Students apply their algorithmic skills to strings: examining characters, counting occurrences, validating text and building simple text-processing solutions.

Core idea: A string can be processed character by character. A loop, a counter, a flag or an accumulator can turn individual characters into useful information.

3 · Count a character

Count ← 0
INPUT Word
INPUT Target
FOR I ← 1 TO LENGTH(Word)
  IF Word[I] = Target THEN
    Count ← Count + 1
  ENDIF
NEXT I
OUTPUT Count

This is the same counter pattern students already know, applied to characters.

27–35 min · Worked example

4 · Example #1 — Count vowels

Count ← 0
INPUT Word
FOR I ← 1 TO LENGTH(Word)
  IF Word[I] = "A" OR Word[I] = "E" OR Word[I] = "I" OR Word[I] = "O" OR Word[I] = "U" THEN
    Count ← Count + 1
  ENDIF
NEXT I
OUTPUT Count
For production-quality solutions, case handling should also be considered if both uppercase and lowercase input are possible.
35–42 min · Worked example

5 · Example #2 — Build a new string

NewWord ← ""
INPUT Word
FOR I ← 1 TO LENGTH(Word)
  IF Word[I] <> " " THEN
    NewWord ← NewWord & Word[I]
  ENDIF
NEXT I
OUTPUT NewWord

This demonstrates string concatenation: characters are added to a new string one at a time.

7 · Worked Example #3 — Password check

Valid ← TRUE
IF LENGTH(Password) < 8 THEN
  Valid ← FALSE
ENDIF
HasDigit ← FALSE
FOR I ← 1 TO LENGTH(Password)
  IF Password[I] >= "0" AND Password[I] <= "9" THEN
    HasDigit ← TRUE
  ENDIF
NEXT I
IF HasDigit = FALSE THEN
  Valid ← FALSE
ENDIF

This illustrates how several Boolean conditions can contribute to one validation result.

8 · Debugging workout

Count ← 0
FOR I ← 1 TO LENGTH(Word) - 1
  IF Word[I] = "A" THEN
    Count ← Count + 1
  ENDIF
NEXT I

What potential problem is caused by the loop limit?

The final character is not examined. If indexing starts at 1, the traversal should normally reach LENGTH(Word).

13 · Common mistakes

  • Stopping the loop before the last character.
  • Forgetting to initialise a counter or flag.
  • Using the wrong character comparison.
  • Ignoring uppercase/lowercase issues.
  • Confusing a character with the whole string.
  • Changing a flag incorrectly after it has been set.
