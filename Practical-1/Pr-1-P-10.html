Sorting an Array — Bubble Sort

Students now move from searching to sorting. Bubble sort repeatedly compares neighbouring elements and swaps them when they are in the wrong order.

Core idea: Compare neighbours → swap if necessary → repeat passes until the array is ordered.
Teaching route

0–8 min · Retrieval

1 · Why sort?

A list of marks is [72, 45, 91, 63, 58]. Why might arranging the values from smallest to largest be useful?
Sorted data can make later processing easier—for example, displaying ordered results or preparing for efficient searching techniques.
8–18 min · Teach

2 · One bubble-sort comparison

[7, 3, 9, 2]

Compare 7 and 3 → swap
[3, 7, 9, 2]
Compare 7 and 9 → no swap
[3, 7, 9, 2]
Compare 9 and 2 → swap
[3, 7, 2, 9]

After the first pass, the largest value has moved to the end.

18–27 min · Worked example

3 · Example #1 — Ascending bubble sort

FOR Pass ← 1 TO 4
  FOR I ← 1 TO 5 - Pass
    IF A[I] > A[I + 1] THEN
      Temp ← A[I]
      A[I] ← A[I + 1]
      A[I + 1] ← Temp
    ENDIF
  NEXT I
NEXT Pass

For five elements, at most four passes are needed in this straightforward version.

27–35 min · Worked example

4 · Example #2 — Descending order

To sort from largest to smallest, reverse the comparison.

IF A[I] < A[I + 1] THEN
  Temp ← A[I]
  A[I] ← A[I + 1]
  A[I + 1] ← Temp
ENDIF
The swap mechanism stays the same. The comparison direction changes.
35–42 min · Worked example

5 · Example #3 — Trace one pass

Trace one ascending pass through [5, 2, 8, 1].
Start: [5, 2, 8, 1]
5 > 2 → [2, 5, 8, 1]
5 > 8 → [2, 5, 8, 1]
8 > 1 → [2, 5, 1, 8]

The largest value, 8, has bubbled to the end.

42–47 min · Guided workout

6 · Design the swap

Why is a temporary variable useful when swapping A[I] and A[I+1]?
Without a temporary variable, assigning one value to the other would overwrite information. Temp preserves the first value while the two elements exchange positions.
47–50 min · Exit

  • What changes for descending order?
  • Why is a temporary variable needed?

9 · Debugging workout

IF A[I] > A[I + 1] THEN
  A[I] ← A[I + 1]
  A[I + 1] ← A[I]
ENDIF

Why does this fail to perform a correct swap?

The first assignment destroys the original left value. The second assignment then copies the new left value again. A temporary variable is needed to preserve the original value.

11 · Exam-style question

Explain what happens during one pass of an ascending bubble sort.

Adjacent elements are compared from left to right. If the left element is greater than the right element, they are swapped. Repeating these comparisons moves the largest remaining value towards the end of the unsorted portion.

12 · Common mistakes

  • Using the wrong comparison for the required order.
  • Forgetting the second assignment in a swap.
  • Not using a temporary variable.
  • Using an index outside the array range.
  • Using incorrect inner-loop limits.
  • Stopping after one pass and assuming the array is sorted.
