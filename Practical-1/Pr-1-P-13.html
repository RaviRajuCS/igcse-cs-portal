Working with Files

Students now move from data held temporarily in variables and arrays to persistent data. Files allow information to be stored so that it can be used again when the program runs later.

Core idea: Open the file → perform the required read/write operation → close the file. Students must also understand whether a file is being opened for reading or writing.

1 · Temporary or persistent?

A program stores a student's mark in a variable. What happens to that value when the program finishes? How could the program keep the information for tomorrow?
A normal variable is temporary while the program runs. A file can provide persistent storage so the data can be retrieved later.

...

The exact file-handling keywords should follow the pseudocode specification used in the course. The important sequence is to open the file in the required mode, perform the operation, then close it.

3 · Reading records

OPENFILE "Marks.txt" FOR READ
READFILE "Marks.txt", Mark
OUTPUT Mark
CLOSEFILE

A read operation transfers stored data from the file into a program variable.

5 · Example #2 — Read several values

OPENFILE "Marks.txt" FOR READ

This combines file handling + iteration. The loop processes several stored values.

A file contains five marks. Design an algorithm that reads the five marks and calculates their total.

  Total ← Total + Mark
NEXT I
CLOSEFILE
OUTPUT Total

6 · Workout — Count passes

A file contains 20 marks. Read them and count how many are at least 50.
Count ← 0
OPENFILE "Marks.txt" FOR READ
FOR I ← 1 TO 20
  READFILE "Marks.txt", Mark
  IF Mark >= 50 THEN
    Count ← Count + 1
  ENDIF
NEXT I
CLOSEFILE
OUTPUT Count

7 · Worked Example #3 — Read, process, report

Highest ← -1
OPENFILE "Marks.txt" FOR READ
FOR I ← 1 TO 10
  READFILE "Marks.txt", Mark
  IF Mark > Highest THEN
    Highest ← Mark
  ENDIF
NEXT I
CLOSEFILE
OUTPUT Highest

This combines file input with the extreme-value pattern learned earlier.

8 · Debugging workout

READFILE "Marks.txt", Mark
OPENFILE "Marks.txt" FOR READ

What is wrong with the order?

The file is being read before it is opened. The OPENFILE operation must occur first.

10 · Challenge — File search

A file contains 15 student IDs. Input a target ID and report whether it occurs in the file.
Found ← FALSE
OPENFILE "IDs.txt" FOR READ
FOR I ← 1 TO 15
  READFILE "IDs.txt", ID
  IF ID = Target THEN
    Found ← TRUE
  ENDIF
NEXT I
CLOSEFILE
IF Found THEN
  OUTPUT "Found"
ELSE
  OUTPUT "Not found"
ENDIF

12 · Mini exam question

A file Temperatures.txt contains 12 temperatures. Write an algorithm to read all 12 values, calculate the average and output it.

Total ← 0
OPENFILE "Temperatures.txt" FOR READ
FOR I ← 1 TO 12
  READFILE "Temperatures.txt", Temperature
  Total ← Total + Temperature
NEXT I
CLOSEFILE
Average ← Total ÷ 12
OUTPUT Average

13 · Common mistakes

  • Reading or writing before opening the file.
  • Forgetting to close the file.
  • Using READ when the task requires writing.
  • Forgetting to initialise a total or counter.
  • Reading the wrong number of records.
  • Mixing up the file name and the variable receiving the data.
