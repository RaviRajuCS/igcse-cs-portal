Repeating Steps — Introduction to Iteration

Students have mastered sequence and selection. Now we introduce iteration: repeating a group of instructions. The first focus is the count-controlled loop, where the number of repetitions is known in advance.

Core idea: If the same steps need to happen many times, do not write the same instructions repeatedly. Put them inside a loop.

1 · Why loops?

A program must display the word “Hello” 10 times. Would you write OUTPUT “Hello” ten times?
It would work, but it is repetitive and difficult to maintain. A loop gives one instruction a repetition count.
8–18 min · Teach

2 · FOR…NEXT

FOR Count ← 1 TO 5
  OUTPUT Count
NEXT Count

This outputs 1, 2, 3, 4 and 5. The loop variable changes automatically each time around the loop.

StartCount begins at 1.
EndLoop stops after Count reaches 5.
BodyOUTPUT Count runs once per iteration.
After NEXTThe next value of Count is considered.

3 · Workout — Count backwards?

Can the standard FOR…NEXT structure above produce 10, 9, 8 … 1 without changing its step?

A descending loop requires a suitable step or loop structure. In Cambridge-style pseudocode, a FOR loop can use a STEP value where appropriate, for example FOR I ← 10 TO 1 STEP -1.

7 · Workout — Sum of even numbers

Calculate the sum of 2, 4, 6, 8 and 10 using a loop.
Total ← 0
FOR I ← 2 TO 10 STEP 2
  Total ← Total + I
NEXT I
OUTPUT Total

Result = 30.

8 · Workout — Count positive numbers

Input 6 numbers and count how many are positive.

This combines iteration + selection.

Count ← 0
FOR I ← 1 TO 6
  INPUT Number
  IF Number > 0 THEN
    Count ← Count + 1
  ENDIF
NEXT I
OUTPUT Count

9 · Debug the loop

Total ← 0
FOR I ← 1 TO 5
  INPUT Number
NEXT I
Total ← Total + Number
OUTPUT Total

Why does this fail to add all five numbers?

The addition occurs after the loop, so only the final value of Number is added. The accumulator update must be inside the loop.

10 · Challenge — Multiplication table

Input a number and display its multiplication table from ×1 to ×12.
INPUT Number
FOR I ← 1 TO 12
  OUTPUT Number × I
NEXT I

11 · Challenge — Highest mark

Input 5 marks and display the highest mark.
Highest ← -1
FOR I ← 1 TO 5
  INPUT Mark
  IF Mark > Highest THEN
    Highest ← Mark
  ENDIF
NEXT I
OUTPUT Highest

For a known mark range of 0–100, another safe initial value could be 0.

12 · Mini exam question

Write an algorithm that inputs 8 temperatures and outputs the total temperature.

Total ← 0
FOR I ← 1 TO 8
  INPUT Temperature
  Total ← Total + Temperature
NEXT I
OUTPUT Total

13 · Common mistakes

  • Forgetting to initialise the accumulator.
  • Putting the accumulator update outside the loop.
  • Using the wrong start/end values.
  • Miscounting the number of iterations.
  • Forgetting that the end value is included in a normal inclusive FOR range.
