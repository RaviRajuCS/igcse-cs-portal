Working with One-Dimensional Arrays

Students now apply their algorithm skills to a collection of related values. An array stores multiple values under one name, with each value accessed using an index.

Core idea: Instead of creating separate variables for many related values, use one array and a position/index to access each element.

0–8 min · Retrieval

1 · Why use an array?

A program stores the marks of 30 students. Would it be sensible to create Mark1, Mark2, Mark3 … Mark30?
An array provides a structured way to store and process a collection of related values.
8–18 min · Teach

2 · Indexes and elements

DECLARE Mark : ARRAY[1:5] OF INTEGER
Mark[1] ← 72
Mark[2] ← 85
Mark[3] ← 61
Mark[4] ← 94
Mark[5] ← 78

Each element has a position. The exact indexing convention must match the pseudocode specification being used; here the array is deliberately shown as 1 to 5.

18–27 min · Worked example

3 · Example #1 — Input five marks

DECLARE Mark : ARRAY[1:5] OF INTEGER
FOR I ← 1 TO 5
  INPUT Mark[I]
NEXT I

The loop visits every valid index exactly once.

27–35 min · Worked example

4 · Example #2 — Display all elements

FOR I ← 1 TO 5
  OUTPUT Mark[I]
NEXT I
Traversal pattern: start at the first index → process the current element → move to the next index → stop after the final index.
35–42 min · Worked example

5 · Example #3 — Find the total

Total ← 0
FOR I ← 1 TO 5
  Total ← Total + Mark[I]
NEXT I
OUTPUT Total

This combines array traversal + accumulator + FOR loop.

42–47 min · Guided workout

6 · Find the highest mark

Five marks are stored in an array. Design an algorithm to find and display the highest mark.
Highest ← Mark[1]
FOR I ← 2 TO 5
  IF Mark[I] > Highest THEN
    Highest ← Mark[I]
  ENDIF
NEXT I
OUTPUT Highest

7 · Worked Example #3 — Highest value

Highest ← Numbers[1]
FOR I ← 2 TO 8
  IF Numbers[I] > Highest THEN
    Highest ← Numbers[I]
  ENDIF
NEXT I
OUTPUT Highest

Why does the loop begin at 2? Because element 1 is already being used as the initial highest value.

8 · Search workout

An array stores 10 student ID numbers. Input a target ID and display “Found” if it appears in the array; otherwise display “Not found”.
Found ← FALSE
INPUT Target
FOR I ← 1 TO 10
  IF ID[I] = Target THEN
    Found ← TRUE
  ENDIF
NEXT I
IF Found = TRUE THEN
  OUTPUT "Found"
ELSE
  OUTPUT "Not found"
ENDIF

10 · Debug this algorithm

Total ← 0
FOR I ← 1 TO 5
  Total ← Total + Mark[5]
NEXT I
OUTPUT Total

Why does this not calculate the total of all five marks?

The algorithm adds Mark[5] five times. It should use Mark[I] so that each element is visited.

11 · Challenge — Count and total

An array contains 12 temperatures. Calculate the total and count how many temperatures are below 0.
Total ← 0
BelowZero ← 0
FOR I ← 1 TO 12
  Total ← Total + Temperature[I]
  IF Temperature[I] < 0 THEN
    BelowZero ← BelowZero + 1
  ENDIF
NEXT I
OUTPUT Total
OUTPUT BelowZero

12 · Mini exam question

An array Age[1:20] stores 20 ages. Write an algorithm to find the youngest age.

Youngest ← Age[1]
FOR I ← 2 TO 20

    Youngest ← Age[I]
  ENDIF
NEXT I
OUTPUT Youngest

13 · Common mistakes

  • Using an index outside the declared range.
  • Using a fixed index such as [5] when a loop variable is required.
  • Starting an extreme-value search with an unsuitable arbitrary value.
  • Forgetting to initialise counters or totals.
  • Confusing an array index with the value stored at that index.
