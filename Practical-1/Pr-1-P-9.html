Searching an Array

Students now use arrays to solve a very common problem: finding whether a particular value exists. The main technique is linear search—checking elements one by one until the target is found or the array has been fully examined.

Core idea: A search algorithm must handle both outcomes: the target is found, or the target is not found.

0–8 min · Retrieval

1 · How would you find a name?

A class register contains 30 names. A teacher wants to know whether “Amina” is in the list. What should the algorithm do?
Compare the target with each array element. If a match occurs, record that it was found. If every element is checked without a match, report “Not found”.
8–18 min · Teach

2 · Linear search with a flag

Found ← FALSE
FOR I ← 1 TO 10
  IF ID[I] = Target THEN
    Found ← TRUE
  ENDIF
NEXT I
IF Found = TRUE THEN
  OUTPUT "Found"
ELSE
  OUTPUT "Not found"
ENDIF

The Boolean variable Found acts as a flag. It records whether a match has occurred.

35–42 min · Improved search

5 · Stop when the target is found

Discuss why continuing to compare every remaining element after a match may be unnecessary.
For a simple linear search, an early-exit design can stop once the target is found. The exact loop construct should match the pseudocode specification being taught.
I ← 1
WHILE I <= 10 AND Found = FALSE DO
  IF ID[I] = Target THEN
    Found ← TRUE
  ENDIF
  I ← I + 1
ENDWHILE
42–47 min · Guided workout

6 · Search and count matches

An array contains 12 marks. Input a target mark and count how many times it occurs.
Count ← 0
INPUT Target
FOR I ← 1 TO 12
  IF Mark[I] = Target THEN
    Count ← Count + 1
  ENDIF
NEXT I
OUTPUT Count

Position ← -1

9 · Debugging workout

Found ← TRUE
FOR I ← 1 TO 10
  IF ID[I] = Target THEN
    Found ← TRUE
  ENDIF
NEXT I
IF Found = FALSE THEN
  OUTPUT "Not found"
ENDIF

Why will this fail to report a missing target correctly?

Found starts as TRUE, so it never represents the “not found yet” state. It should be initialised to FALSE.

13 · Common mistakes

  • Not resetting the Found flag before a new search.
  • Reporting “found” without checking all relevant elements.
  • Confusing the target value with its index.
  • Counting a match when the task asks only whether it exists.
  • Forgetting to handle the “not found” case.
