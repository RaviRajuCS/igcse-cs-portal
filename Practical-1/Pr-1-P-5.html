Combining Conditions

Students now learn to make decisions using more than one condition. This is a major step towards realistic algorithms: eligibility checks, validation, security rules and classification often require several facts to be true—or at least one of several facts to be true.

Core idea: Use AND when all required conditions must be true; use OR when at least one condition can be true; use NOT to reverse a logical condition.

1 · Why one condition is not enough

A student can enter a competition only if their age is at least 14 and they have permission.

Ask students: should age alone be enough?

No. Both requirements must be satisfied, so the algorithm needs AND.

4 · NOT

IF NOT Locked THEN
  OUTPUT "Access available"
ELSE
  OUTPUT "Access blocked"
ENDIF

NOT reverses a Boolean condition: TRUE becomes FALSE and FALSE becomes TRUE.

34–41 min · Worked example

5 · Example #1 — Sports team selection

A student may join a team if their age is between 13 and 16 inclusive AND they have passed the fitness test.
IF Age >= 13 AND Age <= 16 AND Fitness = "Pass" THEN
  OUTPUT "Selected"
ELSE
  OUTPUT "Not selected"
ENDIF
There are three conditions, and all must be TRUE.
41–47 min · Worked example

6 · Example #2 — Free entry

Entry is free for children under 5 OR senior citizens aged 60 or over.
IF Age < 5 OR Age >= 60 THEN
  OUTPUT "Free entry"
ELSE
  OUTPUT "Pay"
ENDIF

Only one of the two age conditions needs to be TRUE.

47–50 min · Exit challenge

7 · Think before coding

Ask students to decide whether each requirement needs AND or OR:

  • Username AND password must be correct.
  • Saturday OR Sunday is a weekend.
  • Age must be 12–15 inclusive.

4 · Quick check — OR

If A = FALSE and B = TRUE, what is A OR B?

6 · Workout — Multiple valid choices

A school club meets on Monday, Wednesday or Friday. Input the day and display “Club day” if it is one of these days.
IF Day = "Monday" OR Day = "Wednesday" OR Day = "Friday" THEN
  OUTPUT "Club day"
ELSE
  OUTPUT "No club"
ENDIF

7 · Worked Example #3 — Range using AND

IF Mark >= 40 AND Mark <= 59 THEN
  OUTPUT "Pass range"
ELSE
  OUTPUT "Outside range"
ENDIF

Both comparisons must be true. Test 39, 40, 59 and 60.

9 · Workout — Password security

Access is granted only when the username is correct AND the password is correct.

Why would OR be a security error?

OR would allow access when only one credential was correct. AND requires both credentials to be correct.

10 · NOT workout

If Locked = TRUE, what is NOT Locked?

11 · Challenge — Sports qualification

A student qualifies if their score is at least 70 AND their attendance is at least 80%, OR they are the defending champion.

Explain the logic carefully before writing it.

IF (Score >= 70 AND Attendance >= 80) OR Champion = "Yes" THEN
  OUTPUT "Qualified"
ELSE
  OUTPUT "Not qualified"
ENDIF

The brackets make the intended grouping clear.

12 · Debugging workout

IF Age >= 13 OR Age <= 16 THEN
  OUTPUT "Teen range"
ELSE
  OUTPUT "Outside range"
ENDIF

Why is this condition wrong for “13 to 16 inclusive”?

Almost every number satisfies at least one side of the OR. The correct range test is Age >= 13 AND Age <= 16.

13 · Mini exam question

Write an algorithm that inputs a mark and attendance percentage. A student passes if the mark is at least 50 and attendance is at least 75.

INPUT Mark
INPUT Attendance
IF Mark >= 50 AND Attendance >= 75 THEN
  OUTPUT "Pass"
ELSE
  OUTPUT "Fail"
ENDIF

14 · Common mistakes

  • Using OR when all requirements must be satisfied.
  • Using AND for alternatives.
  • Writing a range with OR instead of AND.
  • Ignoring the order/grouping of compound conditions.
  • Testing only one combination of TRUE/FALSE conditions.

15 · Self-assessment

Can you choose correctly between AND, OR and NOT?
