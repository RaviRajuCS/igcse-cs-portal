String Processing — Practical Techniques

Students apply their algorithmic skills to strings. They learn to inspect characters, count occurrences, search for text, validate simple string requirements and build reusable string-processing routines.

Core idea: A string can be processed systematically by examining its characters, applying a condition and maintaining a suitable counter, flag or result.

0–8 min · Retrieval

1 · Strings are data too

How could a program count how many times the letter "A" occurs in a word?
Traverse the characters one by one. Whenever the current character equals "A", increment a counter.
8–18 min · Teach

2 · Traversing a string

Count ← 0
FOR I ← 1 TO LENGTH(Word)
  IF Word[I] = "A" THEN
    Count ← Count + 1
  ENDIF
NEXT I
OUTPUT Count

The loop visits every character. The counter records how many characters satisfy the condition.

18–27 min · Teach

3 · Searching for a character

Found ← FALSE
FOR I ← 1 TO LENGTH(Text)
  IF Text[I] = "X" THEN
    Found ← TRUE
  ENDIF
NEXT I
IF Found = TRUE THEN
  OUTPUT "X found"
ELSE
  OUTPUT "X not found"
ENDIF
A Boolean flag is useful when the final question is simply whether something was found.
27–35 min · Worked example

4 · Example #1 — Count vowels

Count ← 0
FOR I ← 1 TO LENGTH(Text)
  IF Text[I] = "A" OR Text[I] = "E" OR Text[I] = "I" OR Text[I] = "O" OR Text[I] = "U" THEN
    Count ← Count + 1
  ENDIF
NEXT I
OUTPUT Count

For "COMPUTER", the result is 3: O, U and E.

35–42 min · Worked example

5 · Example #2 — Validate a simple identifier

Valid ← TRUE
IF LENGTH(Code) < 3 THEN
  Valid ← FALSE
ENDIF

IF Valid = TRUE THEN
  OUTPUT "Length acceptable"
ELSE
  OUTPUT "Too short"
ENDIF

This demonstrates how string length can become part of a validation rule.

8 · Debugging workout

Count ← 0
FOR I ← 1 TO LENGTH(Text) - 1
  IF Text[I] = "A" THEN
    Count ← Count + 1
  ENDIF
NEXT I

Why might this miss a character?

The loop stops at LENGTH(Text) - 1, so the final character is never checked. If every character must be examined, the upper limit should be LENGTH(Text).

15 · Common mistakes

  • Using the wrong upper limit for the character loop.
  • Forgetting to initialise the counter or flag.
  • Counting the wrong character.
  • Confusing a counter with a Boolean flag.
  • Ignoring case requirements specified by the problem.
  • Not considering an empty or one-character string when appropriate.
