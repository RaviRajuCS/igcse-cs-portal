Nested Loops and Complex Decisions

Students now strengthen their ability to solve problems that require one control structure inside another. They learn to recognise nested loops, nested selection and combinations such as loops containing decisions and decisions containing repeated processing.

Core idea: Read the indentation and structure carefully. An inner loop completes its required repetitions for each execution of the outer loop.

0–8 min · Retrieval

1 · Why nest?

A teacher wants to process 5 students, with each student having 4 marks. Why might two loops be more suitable than one?
The outer loop can represent students and the inner loop can represent the four marks belonging to each student.
8–18 min · Teach

2 · Basic nested loop

FOR Student ← 1 TO 5
  FOR Mark ← 1 TO 4
    INPUT Score
  NEXT Mark
NEXT Student

The inner loop runs four times for every one execution of the outer loop, giving 5 × 4 = 20 inputs.

18–27 min · Teach

3 · Nested loop with a condition

FOR Row ← 1 TO 3
  FOR Column ← 1 TO 4
    IF Row = Column THEN
      OUTPUT "*"
    ELSE
      OUTPUT "."
    ENDIF
  NEXT Column
NEXT Row

Selection can occur inside a nested loop to treat particular positions differently.

27–35 min · Worked example

4 · Example #1 — Multiplication table

FOR A ← 1 TO 5
  FOR B ← 1 TO 5
    OUTPUT A × B
  NEXT B
NEXT A
There are 25 executions of the OUTPUT statement: 5 outer iterations × 5 inner iterations.
35–42 min · Worked example

5 · Example #2 — Count values meeting a condition

Count ← 0
FOR Student ← 1 TO 3
  FOR Test ← 1 TO 4
    INPUT Mark
    IF Mark >= 50 THEN
      Count ← Count + 1
    ENDIF
  NEXT Test
NEXT Student
OUTPUT Count

The counter counts passes across all 12 marks.

42–47 min · Guided workout

6 · Trace the nested loops

How many times does OUTPUT "X" execute?
FOR I ← 1 TO 4
  FOR J ← 1 TO 3
    OUTPUT "X"
  NEXT J
NEXT I
12 times. The inner loop runs 3 times for each of 4 outer iterations: 4 × 3 = 12.
47–50 min · Exit

  • How many times does an inner loop execute?
  • Why is indentation important?
  • What happens when a selection statement is placed inside a loop?

8 · Debugging workout

FOR Row ← 1 TO 3
FOR Column ← 1 TO 4
  OUTPUT Grid[Row, Column]
NEXT Row
NEXT Column

What is wrong?

The closing statements are matched incorrectly. NEXT Column must close the inner loop before NEXT Row closes the outer loop.

12 · Mini exam question

A 5 × 4 array stores 20 marks. Write an algorithm to count how many marks are at least 50 and output the count.

Count ← 0
FOR Row ← 1 TO 5
  FOR Column ← 1 TO 4
    IF Marks[Row, Column] >= 50 THEN
      Count ← Count + 1
    ENDIF
  NEXT Column
NEXT Row
OUTPUT Count

13 · Common mistakes

  • Mixing up outer and inner loops.
  • Putting NEXT statements in the wrong order.
  • Miscounting total iterations.
  • Forgetting that the inner loop restarts for every outer iteration.
  • Using incorrect row/column indexes.
  • Failing to trace nested structures one level at a time.

14 · Self-assessment

Can you trace, design and debug nested loops and combine them with selection?
