Functions — Getting a Value Back

Students now extend their subroutine skills by using functions. Unlike a procedure that performs a task, a function is designed to return a value that can be used elsewhere in an algorithm.

Core idea: Procedure = perform a task. Function = calculate or determine a value and return it.

0–8 min · Retrieval

1 · Procedure or function?

A program needs to calculate the square of a number and use the result in another calculation. Would a procedure that only displays the answer be ideal?
A function is more suitable because the calculated value can be returned and stored or used in another expression.
8–18 min · Teach

2 · A simple function

FUNCTION Square(Number)
  RETURN Number × Number
ENDFUNCTION

Result ← Square(7)
OUTPUT Result

The function receives 7, calculates 49 and returns that value to the calling statement.

18–27 min · Teach

3 · Functions inside expressions

FUNCTION Double(Number)
  RETURN Number × 2
ENDFUNCTION

Total ← Double(5) + Double(3)
OUTPUT Total

A returned value can be used as part of a larger expression.

27–35 min · Worked example

4 · Example #1 — Maximum of two numbers

FUNCTION Maximum(A, B)
  IF A > B THEN
    RETURN A
  ELSE
    RETURN B
  ENDIF
ENDFUNCTION

Largest ← Maximum(18, 25)
OUTPUT Largest
35–42 min · Worked example

5 · Example #2 — Validation function

FUNCTION ValidMark(Mark)
  IF Mark >= 0 AND Mark <= 100 THEN
    RETURN TRUE
  ELSE
    RETURN FALSE
  ENDIF
ENDFUNCTION
The returned Boolean value can be used directly in a decision or stored in a variable.

9 · Debugging workout

FUNCTION Square(N)
  N × N
ENDFUNCTION

Result ← Square(6)

Why can Result fail to receive the square?

The function calculates an expression but does not RETURN the value. It should contain RETURN N × N.

10 · Challenge — Discount function

FUNCTION FinalPrice(Price, Discount)

ENDFUNCTION

12 · Mini exam question

Write a function Largest(A, B, C) that returns the largest of three numbers.

FUNCTION Largest(A, B, C)
  Largest ← A
  IF B > Largest THEN
    Largest ← B
  ENDIF
  IF C > Largest THEN
    Largest ← C
  ENDIF
  RETURN Largest
ENDFUNCTION

13 · Common mistakes

  • Forgetting RETURN.
  • Confusing a parameter with the value returned.
  • Calling a function without using its result when the task requires it.
  • Returning the wrong value or returning before the calculation is complete.
  • Using a procedure when a reusable returned value is required.
