Advanced String Operations

Period 18 introduced character-by-character processing. This period extends that skill to common string operations: determining length, extracting portions of text, changing case, comparing strings and combining these operations into useful algorithms.

Core idea: A string problem can often be solved by combining a built-in string operation with a loop, selection, counter or Boolean flag.

7 · Worked Example #3 — Character + function

Count ← 0
INPUT Word
FOR I ← 1 TO LENGTH(Word)
  IF UCASE(Word[I]) = "A" THEN
    Count ← Count + 1
  ENDIF
NEXT I
OUTPUT Count

This version counts both uppercase and lowercase A characters.

8 · Debugging workout

INPUT Word
FOR I ← 1 TO LENGTH(Word) + 1
  OUTPUT Word[I]
NEXT I

What problem can occur?

The loop attempts to access one character beyond the end of the string. The normal traversal limit should be LENGTH(Word).

13 · Common mistakes

  • Using the wrong substring starting position.
  • Requesting more characters than the string contains.
  • Forgetting to validate minimum length before extraction.
  • Ignoring case when the requirement is case-insensitive.
  • Using LENGTH incorrectly in loop limits.
  • Assuming string functions have identical syntax in every programming language.
