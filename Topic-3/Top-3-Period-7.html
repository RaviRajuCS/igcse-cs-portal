Lesson overview

Period 7 · Primary Storage

This lesson begins 3.3 Data storage. Students learn what primary storage means, why it is directly accessed by the CPU, and the roles of RAM and ROM.

Success criteria: Students can define primary storage, explain why RAM and ROM are needed, distinguish RAM from ROM, and explain why a computer needs both.

Cambridge specifies that primary storage is directly accessed by the CPU and includes RAM and ROM. Students must understand why both are needed and the difference between them. citeturn0search12

My teaching route

Build the storage hierarchy from the CPU

  1. Retrieve CPU processing.
  2. Define primary storage.
  3. Explain direct CPU access.
  4. Introduce RAM and its role during current processing.
  5. Introduce ROM and its role in storing essential instructions that persist without power.
  6. Compare RAM and ROM.
  7. Apply the distinction to real situations.
Core distinction: RAM is working memory for current programs/data; ROM stores essential instructions that are retained when power is removed.

7–17 min · Teach

1 · RAM

Random Access Memory (RAM) is primary storage used to hold programs and data that are currently being used by the computer.

VolatileIts contents are lost when power is switched off.
Working memoryHolds programs and data currently in use.
CPU accessDirectly accessed by the CPU.
ChangeableContents can be read and written during normal operation.
17–27 min · Teach

2 · ROM

Read Only Memory (ROM) is primary storage that contains essential instructions needed to start or operate the computer system.

Non-volatileContents are retained when power is switched off.
Essential instructionsStores instructions needed for startup/booting.
Primary storageDirectly accessible by the CPU.
PersistentIts contents do not disappear simply because power is removed.

3 · RAM vs ROM

RAMROM
Volatile.Non-volatile.
Stores programs/data currently in use.Stores essential startup instructions.
Contents change as programs run.Contents are retained without power.
Used as working memory.Used for persistent essential instructions.

4 · Why does a computer need both?

A computer needs ROM so that essential instructions remain available when the system is powered on. It needs RAM to provide temporary working storage for the operating system, programs and data currently being used.

43–47 min · Misconceptions

5 · Avoid these mistakes

  • Calling RAM permanent storage.
  • Saying ROM loses its contents when power is removed.
  • Calling secondary storage “primary” because it stores files permanently.
  • Forgetting that primary storage is directly accessed by the CPU.
  • Saying RAM stores only programs and never data.

9 · Exam practice

Question: State what is meant by primary storage.

Storage that is directly accessed by the CPU.

Question: Explain why RAM is needed.

RAM provides temporary working storage for programs and data that are currently being used by the computer.

Question: Explain why a computer needs ROM.

ROM retains essential instructions when power is removed, so they are available when the computer starts.

10 · Challenge

A student says: “ROM is more useful than RAM because ROM does not lose its contents when the power is switched off.” Is this a good comparison?

No. RAM and ROM have different purposes. RAM is needed for temporary working storage of programs and data currently being used, while ROM retains essential instructions needed for startup. A computer needs both.
