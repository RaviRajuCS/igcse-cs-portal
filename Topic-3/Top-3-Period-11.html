Lesson overview

Period 11 · Cloud Storage

This lesson completes the final two learning outcomes of 3.3 Data storage: understanding cloud storage and explaining its advantages and disadvantages compared with local storage.

Success criteria: Students can define cloud storage, explain remote access, identify that cloud data is stored on physical servers and storage, and evaluate cloud versus local storage using balanced advantages and disadvantages.

Cambridge states that cloud storage can be accessed remotely compared with local storage, and that physical servers and storage are needed to store data in the cloud. citeturn0search12

My teaching route

Teach cloud storage as a comparison

  1. Retrieve secondary storage.
  2. Define local storage and cloud storage.
  3. Explain remote access through a network/Internet connection.
  4. Correct the misconception that “the cloud” means data has no physical location.
  5. Build an advantages/disadvantages table.
  6. Use scenarios to decide when cloud or local storage is more suitable.
Core idea: Cloud storage is still physical storage. The difference is that the data is stored on remote infrastructure and accessed remotely.

1 · What is cloud storage?

Cloud storage is a service in which data is stored on remote physical servers and storage systems and can be accessed remotely over a network/Internet connection.

25–36 min · Advantages

3 · Advantages of cloud storage

  • Remote access: files can be accessed from different locations/devices.
  • Sharing: files can be shared or collaborated on more easily.
  • Less local hardware: users do not need to provide all the storage infrastructure themselves.
  • Scalability: storage capacity can often be increased without replacing a local drive.
  • Backup/recovery: cloud services can support remote copies of data.
36–44 min · Disadvantages

4 · Disadvantages of cloud storage

  • Internet dependency: remote access may not be possible without a suitable connection.
  • Security/privacy risks: data is held on remote infrastructure and must be protected.
  • Reliance on provider: outages or service changes can affect access.
  • Ongoing cost: some services require subscriptions or usage payments.
  • Less direct control: the user does not physically control the remote servers.
44–47 min · Evaluate

5 · Which is better?

There is no universal answer. The best choice depends on the context.

Cloud may be suitable when remote access and sharing are important.
Local may be suitable when reliable offline access, direct hardware control or strict local management is important.

8 · Scenario challenge

A school wants students and teachers to access the same files from home and school. Give one reason cloud storage may be suitable.

Cloud storage allows remote access to files from different locations, making it suitable when users need to work from home and school.

A computer lab has an unreliable Internet connection and needs reliable access to large local files. Give one reason local storage may be suitable.

Local storage can provide access to the files without depending on an Internet connection.

9 · Exam practice

Question: State what is meant by cloud storage.

Storage of data on remote physical servers and storage systems that can be accessed remotely.

Question: Explain one advantage of cloud storage compared with local storage.

Data can be accessed remotely, so a user can access files from different locations/devices when a suitable network connection is available.

Question: Explain one disadvantage of cloud storage compared with local storage.

Access may depend on an Internet connection, so a user may be unable to access remote files if the connection is unavailable.

10 · Six-mark evaluation challenge

A small business is deciding whether to keep its customer files locally or store them in the cloud. Explain two advantages and two disadvantages of cloud storage compared with local storage.

Advantages: files can be accessed remotely from different locations, and files can be shared more easily. Disadvantages: access can depend on an Internet connection, and the business has less direct physical control over the remote storage infrastructure/security.

11 · Common exam mistakes

  • Saying cloud storage has no physical storage.
  • Forgetting the word remote.
  • Giving an advantage without explaining why it is useful.
  • Giving “security” as automatically good or bad without explaining the context.
  • Listing advantages and disadvantages without comparing them with local storage.
