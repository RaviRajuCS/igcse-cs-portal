Lesson overview

Period 13 · IP Addresses

This lesson covers the next part of 3.4 Network hardware: what an Internet Protocol (IP) address is, its purpose, the fact that IP addresses are allocated by the network, and the differences between IPv4 and IPv6, including static and dynamic addresses.

Success criteria: Students can define an IP address, explain its purpose, distinguish an IP address from a MAC address, explain static and dynamic allocation, and identify the characteristics of IPv4 and IPv6.

The Cambridge 2026–2028 syllabus states that an IP address is allocated by the network and can be static or dynamic; it requires knowledge of the characteristics and differences between IPv4 and IPv6. citeturn1view1

2 · Static and dynamic IP addresses

Static IPRemains the same unless it is deliberately changed. Useful where a device needs a consistent address.
Dynamic IPCan be allocated automatically and may change. This is common for ordinary network devices.
Cambridge requirement: Students need to understand that IP addresses can be static or dynamic.
25–37 min · Teach

3 · IPv4

IPv4 uses a 32-bit address. It is normally written as four denary numbers separated by full stops, for example:

192.168.1.25

Each part represents 8 bits, so there are four 8-bit groups.

Key characteristics: 32 bits · four denary groups · separated by dots · smaller address space than IPv6.
37–44 min · Teach

4 · IPv6

IPv6 uses a 128-bit address. It is normally written using hexadecimal groups separated by colons, for example:

2001:0db8:85a3:0000:0000:8a2e:0370:7334
Key characteristics: 128 bits · hexadecimal notation · colon-separated groups · vastly larger address space than IPv4.

9 · MAC vs IP challenge

A student says: “The MAC address and IP address are both permanently assigned to the computer.” Is this correct?

No. The MAC address is associated with the network interface and assigned at manufacture. The IP address is allocated by the network and can be static or dynamic.

10 · Exam practice

Question: State what is meant by an IP address.

A network address allocated by the network and used for network communication/addressing.

Question: State the difference between a static and a dynamic IP address.

A static IP address remains the same unless deliberately changed, whereas a dynamic IP address can be allocated automatically and may change.

Question: State two differences between IPv4 and IPv6.

IPv4 uses 32 bits and is normally written as four denary groups separated by dots. IPv6 uses 128 bits and is normally written as eight hexadecimal groups separated by colons.

11 · Scenario challenge

A school wants a server to be reachable at the same network address every day. Which type of IP address is more appropriate?

A static IP address, because it is intended to remain the same unless deliberately changed.

12 · Common exam mistakes

  • Calling an IP address the permanent hardware address of the NIC.
  • Mixing up MAC and IP addresses.
  • Reversing static and dynamic.
  • Writing IPv4 as hexadecimal groups.
  • Forgetting that IPv6 is 128 bits.
  • Giving only “IPv6 is longer” without stating 128 bits or its hexadecimal/colon notation.
