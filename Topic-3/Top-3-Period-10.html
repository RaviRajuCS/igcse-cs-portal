Lesson overview

Period 10 · Virtual Memory

This lesson covers the fourth requirement of 3.3 Data storage: what virtual memory is, how it is created and used, and why it is necessary.

Success criteria: Students can define virtual memory, explain that it uses part of secondary storage as an extension of RAM, describe pages being transferred between RAM and virtual memory when needed, and explain why virtual memory is necessary.

Cambridge specifically requires candidates to understand that pages of data are transferred between RAM and virtual memory when needed. citeturn0search12

My teaching route

Make virtual memory visible

  1. Retrieve RAM and secondary storage.
  2. Introduce the problem: a program needs more RAM than is currently available.
  3. Explain that part of secondary storage can be used as virtual memory.
  4. Explain that data is divided into pages.
  5. Show pages moving between RAM and virtual memory as needed.
  6. Explain the benefit and the performance limitation.
Core idea: Virtual memory allows the system to handle programs/data that do not all fit into available RAM by moving pages between RAM and a reserved area of secondary storage.

7–18 min · Teach

1 · What is virtual memory?

Virtual memory is an area of secondary storage used by the operating system as an extension of RAM.

Uses secondary storageA reserved area on secondary storage is used when RAM is insufficient.
Works with RAMIt does not replace RAM; it extends the available working space.
Uses pagesData is organised into pages that can be transferred between storage areas.
Managed by the OSThe operating system controls which pages are moved.

The reserved storage area is sometimes called a page file or swap area, depending on the operating system. The syllabus focus is the concept, not a particular operating system.

3 · How virtual memory is used

When RAM is needed for other data, pages that are not currently needed can be moved from RAM to virtual memory. When a page is needed again, it can be transferred back into RAM.

39–46 min · Why necessary?

4 · Why is virtual memory necessary?

  • It allows a computer to run programs when available RAM is insufficient to hold all the required pages.
  • It provides additional working space using secondary storage.
  • It can help prevent a program from failing simply because RAM is full.
But: Virtual memory is slower than RAM because it uses secondary storage. Heavy use can reduce performance.

Virtual memory. The SSD provides an area of secondary storage that is used as an extension of RAM.

9 · Exam practice

Question: State what is meant by virtual memory.

An area of secondary storage used as an extension of RAM.
