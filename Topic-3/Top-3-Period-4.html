Period 4 · Instruction Sets & Embedded Systems

This lesson completes the remaining learning outcomes of 3.1 Computer architecture: the purpose and use of a CPU instruction set, followed by the purpose and characteristics of embedded systems.

Success criteria: Students can define an instruction set, explain its purpose and relationship to machine code, define an embedded system, describe its characteristics, distinguish it from a general-purpose computer, and identify common applications.

The CPU fetches a machine-code instruction from memory, decodes it and executes it. The instruction set defines the commands the CPU is designed to understand and execute.

Important: The instruction set is not the same thing as a program. A program is a sequence of instructions; the instruction set is the collection of commands available to the CPU.
25–33 min · Teach

3 · Embedded systems

An embedded system is a computer system designed to perform a dedicated function within a larger device or product.

DedicatedDesigned for a specific function or limited set of functions.
Built into a deviceOften forms part of a larger appliance or system.
Task-focusedRuns software designed for the particular job.
Different from a PCNot intended to be a general-purpose computer for many unrelated tasks.

3 · Machine code

The commands in the CPU's instruction set are represented as machine code.

Machine code consists of instructions in the form directly processed by the CPU.

When the CPU performs the FDE cycle, it fetches an instruction, decodes it and executes it according to the commands it supports.

8 · Embedded or general-purpose?

A laptop can be used for word processing, browsing, programming, gaming and many other tasks.

A washing machine controller is designed mainly to manage washing programmes.

9 · Exam practice

Question: State what is meant by an instruction set.

An instruction set is a list of all the commands that can be processed by a CPU.

Question: State the form of the commands in a CPU instruction set.

The commands are machine code.

Question: Describe the purpose of an embedded system.

It is used to perform a dedicated function, usually as part of a larger device or system.

10 · Challenge: choose the system

A supermarket has a machine that accepts payment, checks product selection and releases one chosen product. Is this likely to be an embedded system?

11 · Common exam mistakes

  • Defining an instruction set as a program.
  • Forgetting that the CPU commands are machine code.
  • Describing an embedded system simply as “a small computer”.
  • Forgetting the phrase dedicated function.
  • Calling a laptop an embedded system simply because it contains a microprocessor.
