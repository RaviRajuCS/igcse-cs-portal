ComponentMain role
CPUProcesses instructions and data.
Input deviceProvides data/instructions to the computer.

Common mistake: The CPU is not “the place where all data is stored.” Its primary role is processing.
27–35 min · New concept

What is a microprocessor?

A microprocessor is a type of integrated circuit on a single chip.

Simple definition: A microprocessor is an integrated circuit containing the processing functions of a CPU on one chip.

Modern computers and many electronic systems use microprocessors to carry out processing.

1 · Meet the CPU

CPU stands for central processing unit.

Think of the CPU as the component that carries out the processing required by the computer.

2 · What does “process” mean?

Processing means carrying out operations on instructions and data so that the computer can produce a result.

For example, when a program calculates 25 + 17, the CPU performs the processing needed to produce 42.

Input: values and instructions → CPU: processing → Output: result.

5 · Microprocessor

A microprocessor is a type of integrated circuit on a single chip.

The word micro refers to the very small physical implementation, while processor relates to processing functions.

For Cambridge exam questions, remember the exact ideas: integrated circuit and single chip.

6 · CPU vs microprocessor

TermWhat to remember
CPUThe central processing unit; processes instructions and data.
MicroprocessorA type of integrated circuit on a single chip.

7 · Exam practice

8 · Challenge

A computer receives two numbers from a keyboard and displays their total. Which part performs the processing?

The CPU performs the processing needed to calculate the total.

9 · Common mistakes

  • Calling the monitor the processor.
  • Saying the CPU only stores data.
  • Defining a microprocessor as “a small computer” instead of an integrated circuit on a single chip.
  • Forgetting the words instructions and data when describing the CPU.
