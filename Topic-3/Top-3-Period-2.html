Lesson overview

Period 2 · CPU Components in a Von Neumann Architecture

This lesson moves from the general role of the CPU to the specific components inside the CPU and their purposes. Students begin the fetch–decode–execute (FDE) cycle and learn how the ALU, Control Unit, registers and buses work together.

Success criteria: Students can identify the ALU and Control Unit, explain the purpose of the PC, MAR, MDR, CIR and ACC, identify the address/data/control buses, and explain the main stages of the FDE cycle.

The Cambridge 2026–2028 syllabus explicitly requires the purpose of CPU components in a Von Neumann architecture and the fetch–decode–execute cycle, including the role of each component. citeturn2view0

6–15 min · Teach

The two main CPU units

Arithmetic Logic Unit (ALU)Performs arithmetic calculations and logical operations.
Control Unit (CU)Controls and coordinates the activities of the CPU and the execution of instructions.
Memory rule: ALU = calculations and logic. CU = controls and coordinates.
15–28 min · Teach

The five CPU registers

RegisterPurpose
Program Counter (PC)Stores the address of the next instruction to be fetched.
Memory Address Register (MAR)Stores the address in memory that is being accessed.
Memory Data Register (MDR)Stores data or an instruction being transferred to or from memory.
Current Instruction Register (CIR)Stores the current instruction while it is being decoded and executed.
Accumulator (ACC)Stores intermediate arithmetic/logic results during processing.
Exam distinction: MAR stores an address; MDR stores the data or instruction being transferred.
28–35 min · Teach

The three buses

Address busCarries addresses between the CPU and memory.
Data busCarries data and instructions between the CPU, memory and other components.
Control busCarries control signals between the CPU and other components.
Memory rule: Address = where. Data = what. Control = what should happen.
35–44 min · Guided FDE

Fetch → Decode → Execute

FETCH
→
DECODE
→
EXECUTE
↻

Fetch: The address in the PC is copied to the MAR. The instruction is fetched from memory into the MDR. The instruction is copied to the CIR. The PC is updated to point to the next instruction.

Decode: The Control Unit decodes the instruction in the CIR and determines what operation is required.

Execute: The required operation is carried out, using the ALU and/or other CPU components as necessary. Results may be stored in the ACC or memory.

Important: The exact sequence can be described at different levels of detail. In an exam, students should clearly identify the registers and the CU/ALU roles when the question asks for them.
44–47 min · Precision

Common register confusions

ConfusionCorrect distinction
PC vs MARPC = address of next instruction; MAR = address currently being accessed.
MDR vs CIRMDR = data/instruction being transferred; CIR = current instruction being decoded/executed.
ALU vs CUALU performs operations; CU controls and coordinates.

6 · The Fetch–Decode–Execute Cycle

FETCH

DECODE
→
EXECUTE
→
NEXT
INSTRUCTION

FETCH: The CPU obtains the next instruction from memory.

DECODE: The Control Unit interprets the instruction and determines what must be done.

EXECUTE: The CPU carries out the instruction, using the ALU and/or other components as required.

Cycle: fetch → decode → execute → fetch the next instruction.

8 · Exam practice

Question: State the purpose of the ALU.

The ALU performs arithmetic calculations and logical operations.

Question: State the purpose of the PC.

The PC stores the address of the next instruction to be fetched.

Question: State the purpose of the control bus.

The control bus carries control signals between the CPU and other components.

9 · Challenge: Follow one instruction

An instruction is stored in RAM. The CPU must process it.

The PC provides the address of the next instruction. The address is copied to the MAR. The instruction is fetched from memory into the MDR. The instruction is copied to the CIR. The PC is updated. The CU decodes the instruction. The instruction is then executed, using the ALU and/or other CPU components as required.

10 · Common exam mistakes

  • Writing “PC stores the instruction” instead of the address of the next instruction.
  • Confusing MAR with MDR.
  • Saying the CU performs calculations — that is the ALU.
  • Saying the data bus carries addresses — the address bus carries addresses.
  • Describing FDE without explaining the roles of the CPU components.
