Lesson overview

Period 5 · Input and Output Devices

This lesson begins 3.2 Input and output devices. Students learn what input and output devices are, why they are required, and how different devices are selected for particular tasks.

Success criteria: Students can define input and output devices, explain their purpose, distinguish between them, and select an appropriate device for a given context.

Cambridge requires understanding of input/output devices and their purposes, including the listed examples. Cambridge guidance also states that students need to understand what each device does, why it does it and when it might be used, rather than its physical internal operation. citeturn2view0turn0search9

My teaching route

Teach function before hardware detail

  1. Connect input/output to the CPU processing model.
  2. Define an input device and an output device.
  3. Explain why a computer needs both.
  4. Group the syllabus devices by their purpose.
  5. Use scenarios to choose the most suitable device.
  6. Emphasise the difference between what a device does and how it physically works.
Core rule: Input sends data into the computer; output presents data/results from the computer.

5 · Input or output?

Input: keyboard · microphone · camera · mouse · barcode scanner · QR scanner · touch screen · 2D/3D scanner.
Output: screen · speaker · printer · projector · actuator.
Interesting case: A touch screen can act as both an input device and an output device because it displays information and accepts touch input.

7 · Scenario challenge

A museum wants visitors to select information about an exhibit by touching icons on a large display. Which device is suitable, and why?

A touch screen is suitable because it can display information and allow visitors to select options by touching the screen.

A factory needs to create a physical plastic prototype from a digital design. Which device is suitable?

A 3D printer is suitable because it can produce a physical three-dimensional object from digital information.

8 · Exam practice

Question: State what is meant by an input device.

Hardware used to enter data or instructions into a computer system.

Question: State what is meant by an output device.

Hardware used to present or produce information/results from a computer system.

Question: Explain why an input device is required.

It allows data or instructions to be entered into the computer so that the computer can process them.

9 · Common exam mistakes

  • Calling a speaker an input device because it is connected to a computer.
  • Forgetting that a touch screen can be both input and output.
  • Choosing a device without explaining why it suits the scenario.
  • Confusing a barcode scanner with a QR code scanner.
  • Describing how a device works internally when the question only asks what it does or when it is used.
