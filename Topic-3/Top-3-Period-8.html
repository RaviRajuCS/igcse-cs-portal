Lesson overview

Period 8 · Secondary Storage

This lesson introduces the second major category in 3.3 Data storage: secondary storage. Students learn how it differs from primary storage, why it is necessary, and why it is used for more permanent storage of data.

Success criteria: Students can define secondary storage, explain why it is needed, distinguish it from primary storage, and choose suitable secondary storage for a situation.

The Cambridge 2026–2028 syllabus defines secondary storage as storage that is not directly accessed by the CPU and is necessary for more permanent storage of data. citeturn0search12

7–17 min · Teach

1 · What is secondary storage?

Secondary storage is storage that is not directly accessed by the CPU and is used for more permanent storage of data.

More permanentData remains stored when the computer is switched off.
Large capacityIt can store many files, programs, media and backups.
Not directly accessed by CPUData must be transferred to primary storage for active processing.
ExamplesHDD, optical discs, SSD, SD card and USB drive.
17–27 min · Compare

2 · Primary vs secondary storage

Primary storageSecondary storage
Directly accessed by CPU.Not directly accessed by CPU.
Used for current processing.Used for more permanent storage.
Includes RAM and ROM.Includes HDD, optical and solid-state storage.
RAM is volatile.Designed to retain stored data when power is removed.
27–34 min · Teach

3 · Why do we need secondary storage?

  • To store files for later use.
  • To store applications and large collections of data.
  • To keep data when the computer is switched off.
  • To provide storage capacity beyond the immediate working memory of RAM.
Example: A student's photographs may be stored on an SSD or USB drive. They are not kept permanently in RAM.
34–41 min · Preview

4 · Three secondary-storage technologies

MagneticUses magnetised areas to represent stored data. Example: HDD.
OpticalUses laser-read/write patterns on optical discs. Examples: CD, DVD, Blu-ray.
Solid-state / flashUses electronic memory cells. Examples: SSD, SD card, USB drive.
The detailed operation of these three technologies is covered in the next period. Today, know the categories and examples.

3 · Why not just use RAM?

RAM is excellent for current processing, but it is volatile. If power is removed, its contents are lost.

Secondary storage solves the permanence problem. Files can remain stored when the computer is switched off.

7 · Scenario challenge

A student wants to carry a small collection of files between computers. Which secondary-storage device would be suitable?

A USB drive is suitable because it is portable solid-state/flash storage and can hold files for transfer between computers.

A family wants a large-capacity internal drive for a desktop computer. Name two suitable technologies.

A hard disk drive (HDD) or a solid-state drive (SSD).

8 · Exam practice

Question: State what is meant by secondary storage.

Storage that is not directly accessed by the CPU and is used for more permanent storage of data.

Question: Explain why a computer needs secondary storage.

It provides more permanent storage for programs, files and data so they can be retained when the computer is switched off.

Question: Give one example of each secondary-storage technology.

Magnetic: HDD. Optical: DVD. Solid-state: SSD/SD card/USB drive.

9 · Common exam mistakes

  • Saying secondary storage is directly accessed by the CPU.
  • Calling RAM secondary storage.
  • Forgetting that secondary storage is used for more permanent storage.
  • Mixing up optical discs and solid-state devices.
  • Giving an example without identifying its technology.
