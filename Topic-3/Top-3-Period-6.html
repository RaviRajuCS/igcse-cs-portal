Lesson overview

Period 6 · Sensors

This lesson completes the sensor section of 3.2 Input and output devices. Students learn what a sensor is, the purpose of sensors, the type of data captured by each required sensor, and how to select the most suitable sensor for a given context.

Success criteria: Students can define a sensor, distinguish sensor input from human input, identify the data captured by each syllabus sensor, state suitable uses, and justify a sensor choice in a scenario.

The 2026–2028 Cambridge syllabus requires the following sensors: acoustic, accelerometer, flow, gas, humidity, infra-red, level, light, magnetic field, moisture, pH, pressure, proximity and temperature. citeturn0search12

My teaching route

Teach sensors through “quantity → data → context”

  1. Define a sensor and its purpose.
  2. Explain that a sensor detects/measures a physical quantity and provides data to a computer system.
  3. Group the syllabus sensors by the quantity they measure.
  4. Use real-world contexts to select the correct sensor.
  5. Stress the difference between sensor and actuator.
  6. Finish with exam-style scenario selection.
Core rule: A sensor captures data from the physical environment; the computer can then process that data.

5 · Do not confuse these pairs

Humidity vs moisture: humidity relates to moisture in the air; a moisture sensor can be used to measure moisture content such as in soil.
Level vs flow: level tells you how much/high a substance is; flow measures movement/rate through a system.
Proximity vs infra-red: proximity identifies nearby objects; infra-red detects/uses infra-red radiation. A particular device may use IR technology for proximity, but the exam answer should follow the quantity/context being measured.

6 · Exam practice

Question: State what is meant by a sensor.

An input device that detects/measures a physical quantity and provides data to a computer system.

Question: A security system needs to detect movement near a doorway. Suggest a suitable sensor.

A proximity sensor, because it detects whether an object/person is nearby.

Question: A chemical process needs to monitor acidity. Which sensor should be used?

A pH sensor, because it measures acidity/alkalinity.

7 · Challenge: choose and justify

A water-management system needs to monitor both how much water is in a tank and how quickly water is moving through a pipe. Which two sensors are required?

A level sensor measures the amount/height of water in the tank, while a flow sensor measures the rate of water movement through the pipe.

9 · Common exam mistakes

  • Calling every input device a sensor.
  • Giving a device name without stating what data it captures when the question asks for data.
  • Confusing level with flow.
  • Confusing humidity with moisture.
  • Selecting a sensor without linking it to the physical quantity in the scenario.
