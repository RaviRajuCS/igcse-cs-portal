Lesson overview

Period 14 · Routers

This lesson completes the specified router outcomes in 3.4 Network hardware. Students learn the three key functions required by Cambridge: how a router sends data to a specific destination, how it assigns IP addresses to devices on a network, and how it connects a local network to the Internet.

Success criteria: Students can explain the role of a router, describe routing data towards a destination using IP information, explain IP address assignment to devices on a local network, and explain how a router connects a local network to the Internet.

The Cambridge 0984 2026–2028 syllabus requires candidates to understand routers in these three contexts: sending data to a specific destination, assigning IP addresses, and connecting a local network to the Internet.

My teaching route

From device → LAN → Internet

  1. Retrieve NIC, MAC and IP addresses.
  2. Introduce the router as a network device that forwards data towards its destination.
  3. Explain that a router can assign IP addresses to devices on a local network.
  4. Show the router as the connection point between a LAN and the Internet.
  5. Trace a simple packet journey.
  6. Apply the three router functions to scenarios.
Core distinction: A router connects networks and forwards data between them. A switch, covered later, primarily connects devices within a LAN.

1 · What is a router?

A router is a network device that connects different networks and forwards data towards its destination.

Connects networksIt can connect a local network to other networks.
Forwards dataIt determines where network data should be sent next.
Uses IP informationDestination addressing helps the router decide where data should go.
Can assign IP addressesOn a local network, a router can automatically assign IP addresses to devices.

3 · Assigning IP addresses

A router can act as a DHCP server on a local network and automatically assign IP addresses to devices.

ROUTER
→
IP ADDRESS
→
DEVICE

For example, a laptop joining the home LAN may receive an address such as 192.168.1.25. Another device may receive a different address.

Important: The router does not manufacture the device's MAC address. The MAC address belongs to the network interface; the IP address can be allocated by the network.

9 · Scenario challenge

A new tablet joins a school wireless LAN. It receives an IP address automatically, and later its data is sent to a server outside the school network. Explain two router functions involved.

The router can assign the tablet an IP address using DHCP, and it can forward the tablet's data towards the destination server on another network.

10 · Exam practice

Question: Explain how a router sends data to a specific destination.

The router examines destination network/address information and forwards the data towards the appropriate network or next destination.

Question: Explain how a router can assign IP addresses.

The router can act as a DHCP server and automatically allocate IP addresses to devices joining the local network.

Question: Explain how a router connects a local network to the Internet.

The router acts as a gateway between the local network and external networks, forwarding traffic between the LAN and the Internet.

12 · Common exam mistakes

  • Saying a router is the same as a NIC.
  • Saying the router manufactures a MAC address.
  • Explaining routing as simply “sending data” without mentioning its destination.
  • Forgetting that a router can assign IP addresses on a local network.
  • Forgetting the router's role as a gateway between a LAN and the Internet.
