Network Interface Cards · MAC addresses
Lesson overview

Period 12 · NICs and MAC Addresses

This lesson begins 3.4 Network hardware. Students learn why a computer needs a Network Interface Card (NIC) to access a network and what a Media Access Control (MAC) address is, including its purpose and structure.

Success criteria: Students can explain the role of a NIC, define a MAC address, explain why a MAC address identifies a network interface, recognise its hexadecimal structure, and explain how manufacturer and serial information form the address.

The Cambridge 2026–2028 syllabus states that a computer needs a NIC to access a network; a NIC receives a MAC address at manufacture; MAC addresses are usually written in hexadecimal and are created using a manufacturer code and serial code. citeturn2view0

My teaching route

Build the idea from device → interface → identity

  1. Ask how a computer physically/technically connects to a network.
  2. Introduce the NIC as the network interface hardware.
  3. Explain that the NIC has a MAC address assigned at manufacture.
  4. Show the hexadecimal structure of a MAC address.
  5. Distinguish MAC address from an IP address, which students will study next.
  6. Apply the ideas to identification scenarios.
Core distinction: NIC = network interface hardware. MAC address = hardware/interface address used to identify that network interface on the network.

1 · Network Interface Card (NIC)

A Network Interface Card is hardware that provides a computer with an interface to a network.

Network accessThe NIC enables the computer to connect to and communicate over a network.
Network interfaceIt provides the hardware interface between the computer and the network medium.
Can be wiredEthernet NICs connect using a network cable.
Can be wirelessWireless network interfaces allow connection without an Ethernet cable.
Exam wording: “A computer needs a NIC to access a network.”
18–30 min · Teach

2 · What is a MAC address?

A Media Access Control (MAC) address is an address associated with a network interface. It is assigned to the NIC at the point of manufacture.

3C : 52 : 82 : A7 : 14 : 9B

MAC addresses are usually written in hexadecimal. The syllabus describes the address as being created using a manufacturer code and a serial code.

Remember: MAC → associated with the NIC → assigned at manufacture → usually written in hexadecimal.

9 · Exam practice

Question: State what is meant by a NIC.

A network interface card is hardware that provides a computer with an interface to access a network.

Question: State what is meant by a MAC address.

An address associated with a network interface/NIC, assigned at manufacture.

Question: Explain the structure of a MAC address.

It is created using a manufacturer code and a serial code and is usually written in hexadecimal.

10 · Scenario challenge

A school technician installs a replacement network interface card. Explain one reason why the new interface has a different MAC address from the old interface.

The MAC address is associated with the network interface and is assigned at manufacture, so a different NIC has its own MAC address.

11 · Common exam mistakes

  • Saying a MAC address is assigned by the router.
  • Saying a MAC address is the same as an IP address.
  • Writing a MAC address as ordinary denary numbers.
  • Forgetting that the MAC address is associated with the NIC.
  • Confusing the manufacturer code with the IP address.
