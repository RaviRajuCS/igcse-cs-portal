SECTION A — CENTRAL PROCESSING UNIT · 12 MARKS

1. Name the component of the CPU that performs calculations and logical operations. (1)

Arithmetic Logic Unit (ALU).

2. State the purpose of the control unit. (2)

It controls and coordinates the activities of the CPU; it sends control signals and manages the execution of instructions.

3. Describe the fetch–decode–execute cycle. (3)

An instruction is fetched from memory, decoded by the control unit, and then executed by the appropriate CPU components.

4. Explain two factors that can affect CPU performance. (4)

Any two: more CPU cores can allow more tasks/instructions to be processed simultaneously; a larger cache can reduce the need to access slower RAM; a higher clock speed allows more clock cycles per second.

5. State one characteristic of an embedded system and give one example. (2)

It is designed to perform a dedicated/specific function. Example: washing machine controller, car security system, vending machine, or similar.
SECTION B — INPUT, OUTPUT & SENSORS · 10 MARKS

6. State the difference between an input device and an output device. (2)

An input device sends data/signals into the computer; an output device presents or produces information/results from the computer.

7. A greenhouse must continuously measure temperature and automatically control a fan. Name the most suitable sensor and the output device. (2)

Temperature sensor; actuator/fan.

8. Explain why a light sensor is suitable for an automatic lighting system. (2)

It detects the level/intensity of light, allowing the system to switch or control lighting when the surroundings become dark/bright.

9. Give two examples of sensors and state what each detects. (4)

Any two correctly matched examples, e.g. pressure sensor → pressure; humidity sensor → humidity; proximity sensor → presence/distance of nearby objects; moisture sensor → moisture; pH sensor → acidity/alkalinity.
SECTION C — DATA STORAGE · 14 MARKS

10. State the difference between primary and secondary storage. (2)

Primary storage is directly accessed by the CPU; secondary storage is not directly accessed by the CPU and is used for more permanent storage.

11. Name one magnetic, one optical and one solid-state storage device. (3)

Magnetic: HDD. Optical: CD/DVD/Blu-ray. Solid-state: SSD/SD card/USB drive.

12. Explain what virtual memory is and why it is needed. (3)

Virtual memory is an area of secondary storage used as an extension of RAM. It is needed when available RAM is insufficient; pages can be transferred between RAM and virtual memory when required.

13. State what is meant by cloud storage and give one advantage compared with local storage. (3)

Cloud storage stores data on remote physical servers/storage and allows remote access. An advantage is that files can be accessed from different locations/devices, subject to suitable network access.

14. Explain one disadvantage of cloud storage compared with local storage. (3)

Remote access may depend on an Internet/network connection, so files may be unavailable if the connection is not working. Other valid disadvantages include security/privacy, provider dependence or ongoing cost with appropriate explanation.
SECTION D — NETWORK HARDWARE · 14 MARKS

15. State why a computer needs a NIC. (1)

To provide an interface that allows the computer to access a network.

16. State two characteristics of a MAC address. (2)

It is associated with the network interface/NIC and assigned at manufacture; it is usually written in hexadecimal and is created using a manufacturer code and serial code. Any two.

17. Explain the difference between a static and a dynamic IP address. (2)

A static IP address remains the same unless deliberately changed; a dynamic IP address can be allocated automatically and may change.

18. State two differences between IPv4 and IPv6. (4)

IPv4 uses 32 bits and is normally written as four denary groups separated by dots. IPv6 uses 128 bits and is normally written as eight hexadecimal groups separated by colons. Any two paired differences.

19. Explain two roles of a router in a network. (3)

Any two explained: it forwards data towards a specific destination using network addressing information; it can assign IP addresses to devices on a local network; it can connect a local network to the Internet.

20. A laptop joins a school network and receives an IP address automatically. It then sends data to a server on another network. Identify two router functions involved. (2)

The router can automatically assign the laptop an IP address, for example using DHCP, and it can forward the laptop's data towards the destination server.
