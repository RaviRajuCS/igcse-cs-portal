Lesson overview

Period 8 · Two's Complement

Cambridge focus: Topic 1.1 Number systems — students need to understand two's complement as a method of representing negative binary integers and understand the effect of the number of bits available on the range of values that can be represented. fileciteturn6file0L44-L50

Success criteria: Students can explain why a method is needed to represent negative integers, identify the sign bit in a two's complement representation, determine the value of a positive two's complement number, and recognise the range available for a given number of bits.

Prior learning: Binary place value, binary addition, overflow and logical shifts.

Key vocabulary: two's complement, signed integer, sign bit, positive, negative, magnitude, most significant bit, range, representation.

Teacher preparation

Before students enter

  • Display the idea that ordinary unsigned binary represents only non-negative values.
  • Prepare 4-bit and 8-bit two's complement examples.
  • Keep the sign-bit rule visible: in an n-bit two's complement number, the left-most bit has a special negative place value.
  • Use a number line to connect binary patterns with positive and negative values.
  • Do not rush into conversion algorithms: establish the representation and range first.
Teaching principle: students should first understand what two's complement represents before learning a mechanical conversion procedure.

5–14 min · Discover

Why do we need two's complement?

Unsigned binary uses every bit to represent magnitude. That means there is no ordinary unsigned pattern for a negative integer.

Computers therefore need a defined representation for signed integers. Two's complement is the method used in this part of the syllabus.

Key idea: the most significant bit acts as the sign indicator in a fixed-width two's complement representation.

23–31 min · Model

Reading a negative two's complement value

Consider:

11111011

Using the 8-bit two's complement place values:

−128 + 64 + 32 + 16 + 8 + 2 + 1 = −5

Answer: 11111011₂ represents −5₁₀ in 8-bit two's complement.

This is the conceptual place-value method. Students should be able to explain the role of the left-most bit.

38–43 min · Range

What range can be represented?

For an n-bit two's complement representation, the range is:

−2ⁿ⁻¹ to 2ⁿ⁻¹ − 1

For 8 bits this gives:

−128 to +127

The textbook explains the signed range and shows that one bit is effectively used to represent the sign, reducing the positive range compared with unsigned representation. fileciteturn6file0L44-L50

43–47 min · Differentiation

Three levels of challenge

Support: Identify whether 00000110 and 10000110 are positive or negative in 8-bit two's complement.

Core: Find the denary values of 01111111, 11111111 and 10000000.

Challenge: Explain why the positive maximum is +127 rather than +128 in 8-bit two's complement.

Today you will learn how binary can represent negative as well as positive integers using two's complement.

🎯 Learning goals

  • Explain why signed binary representation is needed.
  • Identify the sign bit.
  • Use two's complement place values.
  • Read positive and negative two's complement values.
  • State the range of an 8-bit two's complement representation.

1 · The sign bit

In an 8-bit two's complement number, the left-most bit is the sign bit.

  • 0 in the sign position → non-negative
  • 1 in the sign position → negative
Remember: this is different from unsigned binary, where the left-most bit has a positive place value of 128.

3 · Reading a negative value

Consider:

11111011

Its place values give:

−128 + 64 + 32 + 16 + 8 + 2 + 1 = −5

11111011₂ = −5₁₀ in 8-bit two's complement.

4 · Quick check

Q1: What does a sign bit of 1 indicate?

Q2: What is 00000101 in 8-bit two's complement?

5 · Unsigned or two's complement?

The same pattern can mean different things.

PatternUnsignedTwo's complement
11111111255−1
10000000128−128
01111111127+127
The representation matters. Never interpret a bit pattern without knowing whether it is unsigned or signed.

6 · The 8-bit range

For n-bit two's complement:

−2ⁿ⁻¹ to 2ⁿ⁻¹ − 1

For 8 bits:

−128 to +127

This is why two's complement can represent negative values but has a smaller positive range than unsigned binary.

7 · Practice

Find the denary value of each 8-bit two's complement number:

  1. 00000011
  2. 00001111
  3. 01111111
  4. 11111111
  5. 10000000
Answers: +3, +15, +127, −1, −128.

8 · Challenge

Explain why +128 cannot be represented in 8-bit two's complement, even though 128 can be represented using 8-bit unsigned binary.

In two's complement, the left-most bit has a negative place value (−128). The positive values therefore run only from 0 to +127. The pattern 10000000 represents −128, not +128.

9 · Exam practice

Question: State the range of values that can be represented using 8-bit two's complement.

−128 to +127.

10 · Common mistakes

  • Treating the sign bit as +128.
  • Using the unsigned place-value table for a two's complement number.
  • Thinking that a leading 1 always means 128.
  • Forgetting that the range depends on the number of bits.
  • Assuming every binary pattern has the same meaning regardless of representation.
