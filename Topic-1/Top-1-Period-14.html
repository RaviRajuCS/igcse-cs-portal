Lesson overview

Period 14 · Sound File Size Calculations

Cambridge focus: Topic 1.3 requires candidates to calculate the file size of a sound file using information such as sample rate, sample resolution and track length. The syllabus also specifies that storage calculations use 1024, not 1000, where conversions between storage denominations are required. fileciteturn10file2L186-L214

Success criteria: Students can identify the values needed for a sound-file calculation, calculate the total number of samples, calculate bits/bytes, convert to the requested storage unit, and give the answer in the unit specified.

Prior learning: Period 13 — sampling, sample rate and sample resolution.

Key vocabulary: sample rate, sample resolution, duration, samples, bits, bytes, KiB, MiB, GiB, file size.

My teaching route

The calculation chain

File size (bits) = sample rate × sample resolution × duration
  1. Keep the sample rate in samples/second.
  2. Keep the sample resolution in bits/sample.
  3. Use duration in seconds.
  4. The result is bits.
  5. Divide by 8 to obtain bytes.
  6. Convert to the requested unit using 1024 where the syllabus requires binary storage conversions.
0–5 min · Retrieval

Reconnect with sampling

  1. What does sample rate measure?
  2. What does sample resolution measure?
  3. What happens to file size if sample rate increases?
  4. What happens to file size if sample resolution increases?
Bridge: We now turn those relationships into a calculation.
5–14 min · Model

Worked example 1

A sound recording has:

  • Sample rate = 8,000 samples/s
  • Sample resolution = 8 bits/sample
  • Duration = 10 seconds

Number of samples = 8,000 × 10 = 80,000

File size = 80,000 × 8 = 640,000 bits

Bytes = 640,000 ÷ 8 = 80,000 bytes

Answer: 80,000 bytes before any compression or file-format overhead.
14–23 min · Model

Worked example 2 · MiB

A recording uses 44,100 samples/s, 16 bits/sample and lasts 60 seconds.

Bits = 44,100 × 16 × 60 = 42,336,000 bits

Bytes = 42,336,000 ÷ 8 = 5,292,000 bytes

MiB = 5,292,000 ÷ 1,048,576 ≈ 5.05 MiB

Important: the syllabus specifies 1024 rather than 1000 for these storage conversions. fileciteturn10file2L204-L210
23–31 min · Guided practice

Build the calculation

Question A: 10,000 samples/s, 8 bits/sample, 5 seconds.

Question B: 20,000 samples/s, 16 bits/sample, 10 seconds.

For each, students should show:

  1. Total samples
  2. Total bits
  3. Total bytes
Teacher move: mark the method before marking the final number.
31–37 min · Unit conversion

Bits → bytes → KiB / MiB

Remember:

8 bits = 1 byte
1024 bytes = 1 KiB
1024 KiB = 1 MiB

The syllabus explicitly lists bit, nibble, byte, KiB, MiB, GiB and larger storage denominations and requires answers in the unit specified by the question. fileciteturn10file2L193-L210

37–42 min · Application

What changes file size?

IncreaseEffect on raw sound data
Sample rateMore samples each second → larger file
Sample resolutionMore bits per sample → larger file
DurationMore seconds → more samples → larger file
42–47 min · Assessment

Cambridge-style calculation

A sound file has a sample rate of 16,000 samples/s, a sample resolution of 8 bits and a duration of 20 seconds.

  1. Calculate the number of samples.
  2. Calculate the file size in bits.
  3. Calculate the file size in bytes.
Marking focus: correct multiplication, correct ÷8 conversion, and clear units at every stage.
47–50 min · Exit ticket

Three questions before you leave

  1. Write the formula for raw sound-file size in bits.
  2. Why do we divide bits by 8?
  3. Which value must be used for binary storage conversion: 1000 or 1024?

🧭 Your learning route

1. Recall2. Formula 3. Samples4. Bits & bytes 5. Units6. Assessment

Today you will calculate how much storage a digital sound recording needs.

🎯 Learning goals

  • Calculate total samples.
  • Calculate sound data size in bits.
  • Convert bits to bytes.
  • Convert to KiB or MiB when required.
  • Use 1024 for the specified binary storage conversions.

1 · The formula

File size in bits = sample rate × sample resolution × duration

Make sure:

  • Sample rate = samples per second
  • Resolution = bits per sample
  • Duration = seconds

2 · Worked example

8,000 samples/s × 8 bits/sample × 10 s

640,000 bits

640,000 ÷ 8 = 80,000 bytes

3 · Quick check

Q1: Why do we divide by 8?

Q2: Which conversion factor is specified for KiB/MiB calculations?

4 · Practice A

10,000 samples/s, 8 bits/sample, 5 seconds.

Calculate samples, bits and bytes.

Samples = 10,000 × 5 = 50,000.
Bits = 50,000 × 8 = 400,000 bits.
Bytes = 400,000 ÷ 8 = 50,000 bytes.

5 · Practice B

20,000 samples/s, 16 bits/sample, 10 seconds.

Samples = 200,000.
Bits = 3,200,000 bits.
Bytes = 400,000 bytes.

6 · Storage units

8 bits = 1 byte
1024 bytes = 1 KiB
1024 KiB = 1 MiB

When a question asks for a particular unit, give your final answer in that unit.

7 · Challenge: MiB

44,100 samples/s, 16 bits/sample, 60 seconds.

Bits = 44,100 × 16 × 60 = 42,336,000 bits.
Bytes = 5,292,000 bytes.
MiB = 5,292,000 ÷ 1,048,576 ≈ 5.05 MiB.

8 · Exam practice

A sound file has a sample rate of 16,000 samples/s, resolution of 8 bits and duration of 20 seconds. Find the number of samples, bits and bytes.

Samples = 16,000 × 20 = 320,000.
Bits = 320,000 × 8 = 2,560,000 bits.
Bytes = 2,560,000 ÷ 8 = 320,000 bytes.

9 · Common mistakes

  • Forgetting to multiply by duration.
  • Using bits when the question asks for bytes.
  • Dividing by 8 at the wrong stage.
  • Using 1000 instead of 1024 for the specified binary storage conversions.
  • Leaving out the unit from the final answer.
