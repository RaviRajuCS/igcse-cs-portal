Lesson overview

Period 9 · Converting Two's Complement

Cambridge focus: Topic 1.1 Number systems — representing negative integers using two's complement and understanding the range available for a fixed number of bits. fileciteturn6file0L44-L50

Success criteria: Students can convert a negative denary integer to an n-bit two's complement representation, convert a two's complement bit pattern back to denary, and check whether a requested value is within the available range.

Prior learning: Period 8 — sign bit, two's complement place values and range.

Key vocabulary: two's complement, signed integer, negative, invert, add one, sign bit, magnitude, range, fixed-width.

My teaching route

Before students enter

  • Keep the 8-bit two's complement place-value table visible.
  • Prepare the conversion sequence: positive magnitude → binary → invert bits → add 1.
  • Use fixed-width binary throughout. For an 8-bit task, every intermediate representation must remain 8 bits.
  • Prepare one positive example and one negative example.
  • Remind students to check that the requested denary value lies within −128 to +127 for 8 bits.
Teaching principle: make the conversion algorithm procedural and checkable, but always connect it back to the meaning of the sign bit and fixed-width representation.
0–5 min · Retrieval

Reconnect with Period 8

  1. What is the 8-bit two's complement range?
  2. What does a left-most bit of 1 indicate?
  3. What is 00000101 in two's complement?
  4. What does 11111111 represent?
Bridge: We now know what the representation means. Today we learn how to create the representation for a negative denary value.
5–15 min · Model

Negative denary → two's complement

Use this four-step method for a negative value:

  1. Find the positive magnitude.
  2. Write it in binary using the required number of bits.
  3. Invert every bit.
  4. Add 1.

Example: represent −5 using 8 bits.

+5 = 00000101

Invert → 11111010

Add 1 → 11111011

Therefore −5 = 11111011₂ in 8-bit two's complement.
15–24 min · Model

Another example: −18

Step 1: 18₁₀ = 00010010₂

Step 2: invert → 11101101₂

Step 3: add 1 → 11101110₂

Answer: −18 = 11101110₂

Verification: −128 + 64 + 32 + 16 + 8 + 4 + 2 = −2? Check carefully: for 11101110, the 1 bits after the sign are 64 + 32 + 8 + 4 + 2 = 110; −128 + 110 = −18.

Think → Pair → Explain

  1. −7₁₀

39–44 min · Range and checking

Can the value fit?

Before converting, check the range.

8-bit two's complement: −128 to +127

So −129 cannot be represented in 8-bit two's complement, while −128 can.

Similarly, +128 cannot be represented as a positive 8-bit two's complement integer.

44–47 min · Assessment

Mini-whiteboard check

  1. Convert −6 to 8-bit two's complement.
  2. Convert 11111001₂ to denary.
  3. Can −140 be represented in 8-bit two's complement?
Look for: students who forget the final +1, use variable-width binary, or apply unsigned place values to a negative pattern.
47–50 min · Exit ticket

Three questions before you leave

  1. Convert −5 to 8-bit two's complement.
  2. Convert 11111011₂ to denary.
  3. State the 8-bit two's complement range.
Teacher decision: Period 10 can consolidate number systems and introduce mixed conversion practice before moving further through Data Representation.

Today you will learn how to create and decode two's complement representations.

🎯 Learning goals

  • Convert negative denary integers into fixed-width two's complement.
  • Convert two's complement binary back into denary.
  • Use the invert-and-add-one method correctly.
  • Check whether a value is inside the available range.

1 · The conversion method

To represent a negative denary number:

  1. Write the positive magnitude in binary.
  2. Use the required number of bits.
  3. Invert every bit.
  4. Add 1.
Shortcut to remember: Magnitude → Invert → Add 1.

2 · Worked example: −5

+5 = 00000101

Invert = 11111010

Add 1 = 11111011

−5 = 11111011₂

3 · Worked example: −18

18 = 00010010

Invert → 11101101

Add 1 → 11101110

−18 = 11101110₂

6 · Practice — Denary → two's complement

  1. −7
  2. −12
  3. −25
  4. −64
Answers:
−7 → 11111001
−12 → 11110100
−25 → 11100111
−64 → 11000000

7 · Practice — two's complement → Denary

  1. 11111010
  2. 11110000
  3. 10000001
  4. 11000000
Answers:
11111010 → −6
11110000 → −16
10000001 → −127
11000000 → −64

8 · Check the range

8-bit two's complement = −128 to +127

Therefore:

  • −128 → representable
  • −129 → not representable
  • +127 → representable
  • +128 → not representable as a positive value

9 · Challenge

Convert −100 into 8-bit two's complement. Show every step.

+100 = 01100100
Invert → 10011011
Add 1 → 10011100
Therefore −100 = 10011100₂.

10 · Exam practice

Question: Explain how to represent −13 using 8-bit two's complement.

13 = 00001101
Invert → 11110010
Add 1 → 11110011
So −13 is represented as 11110011₂.

11 · Common mistakes

  • Forgetting to use the required fixed number of bits.
  • Forgetting the final +1.
  • Adding 1 before inverting instead of after.
  • Using unsigned place values to decode a negative value.
  • Trying to represent a number outside the allowed range.
