DR-09

Image Representation
Calculations & File Size

Move beyond knowing what pixels and colour depth are. In this lesson you will calculate how much data an image requires, convert between bits, bytes and binary storage units, and solve reverse and exam-style problems.

THE CORE IDEA
Width × Height × Colour Depth
= image data in bits
01

What You Already Know

▦

Pixels

A bitmap image is made from a rectangular grid of tiny picture elements called pixels.

Each pixel stores information about the colour that should appear at that position.

↔

Resolution

Resolution describes the number of pixels in the image, usually written as:

width × height

For example, 800 × 600 means 800 pixels across and 600 pixels down.

🎨

Colour Depth

Colour depth is the number of bits used to represent the colour of one pixel.

A 24-bit image therefore uses 24 bits for each pixel.

ⓘ

Metadata

Metadata may store information such as image dimensions, colour information, date, camera details or other file data.

The standard exam calculation focuses on the supplied pixel information unless additional information is given.

02

The Image File-Size Formula

Image size in bits = width × height × colour depth
WIDTH number of pixels horizontally
HEIGHT number of pixels vertically
COLOUR DEPTH bits used for each pixel
Important: This formula gives the size of the raw pixel data. A real image file can also contain headers, metadata or compression, so the actual stored file size can differ.
1

Find the pixels

Multiply width by height.

width × height
2

Find the bits

Multiply the number of pixels by colour depth.

pixels × colour depth
3

Convert to bytes

There are 8 bits in one byte.

bits ÷ 8
4

Convert units

Use 1024 when converting binary storage units.

bytes ÷ 1024
03

Bits, Bytes and Storage Units

Image calculations often require more than one conversion. Learn the conversion chain rather than memorising isolated answers.

8 bits = 1 byte
→
1024 bytes = 1 KiB
→
1024 KiB = 1 MiB
→
1024 MiB = 1 GiB

Exam habit

Always look carefully at the unit requested by the question. Do not stop after calculating the answer in bits if the question asks for KiB or MiB.

04

Worked Examples — Step by Step

Example 1

An 800 × 600 image with 8-bit colour depth

Calculate the size of the raw image data in bits and bytes.
Pixels 800 × 600 = 480,000 pixels
Bits 480,000 × 8 = 3,840,000 bits
Bytes 3,840,000 ÷ 8 = 480,000 bytes
KiB 480,000 ÷ 1024 = 468.75 KiB
Answer: 3,840,000 bits = 480,000 bytes = 468.75 KiB
Example 2

A 1024 × 768 image with 24-bit colour depth

Calculate the image size in MiB.
Pixels 1024 × 768 = 786,432 pixels
Bits 786,432 × 24 = 18,874,368 bits
Bytes 18,874,368 ÷ 8 = 2,359,296 bytes
KiB 2,359,296 ÷ 1024 = 2,304 KiB
MiB 2,304 ÷ 1024 = 2.25 MiB
Answer: 2.25 MiB
Example 3

A 1920 × 1080 image with 24-bit colour depth

Calculate the raw image-data size in bytes and MiB.
Pixels 1920 × 1080 = 2,073,600 pixels
Bits 2,073,600 × 24 = 49,766,400 bits
Bytes 49,766,400 ÷ 8 = 6,220,800 bytes
KiB 6,220,800 ÷ 1024 = 6,075 KiB
MiB 6,075 ÷ 1024 ≈ 5.93 MiB
Answer: 6,220,800 bytes ≈ 5.93 MiB
05

Reverse Calculations

Strong Computer Science students should not only calculate forward. You should also be able to work backwards from a file size.

Finding Colour Depth

If the image dimensions and raw data size are known:

Colour depth = file size in bits ÷ number of pixels

For example, suppose an image is 100 × 100 pixels and contains 80,000 bits of raw pixel data.

100 × 100 = 10,000 pixels
80,000 ÷ 10,000 = 8 bits per pixel

Finding Maximum Pixels

If storage space is limited, divide the available number of bits by the colour depth.

Pixels = available bits ÷ colour depth

This tells you how many pixels could be stored under the stated conditions.

06

Which Image Needs More Storage?

Image Resolution Colour Depth Relative Data
A 800 × 600 8-bit 3,840,000 bits
B 800 × 600 24-bit 11,520,000 bits
C 1600 × 1200 8-bit 15,360,000 bits

Think before calculating

Image B has the same number of pixels as A but uses three times the colour depth. Therefore B requires three times the pixel data.

Image C has four times as many pixels as A because both dimensions have doubled. Therefore C requires four times as much pixel data.

The 6-Step Exam Method

  1. Write the dimensions. Identify width and height.
  2. Calculate the number of pixels. Width × height.
  3. Multiply by colour depth. This gives bits.
  4. Convert bits to bytes. Divide by 8.
  5. Convert the unit if required. For KiB, divide by 1024; for MiB, divide by 1024 again.
  6. Check the answer. Does the size and unit make sense?
Exam tip: Show your working. Even if the final answer is wrong, clear intermediate calculations demonstrate your method and make errors easier to diagnose.

CHALLENGE

A Storage-Limited Camera

A camera stores raw bitmap images using 24-bit colour. It has 12 MiB available for one image.

Assuming no metadata or compression, how many pixels can theoretically be stored?

Hint: Convert 12 MiB to bytes first, then to bits. Finally divide by 24 bits per pixel.
