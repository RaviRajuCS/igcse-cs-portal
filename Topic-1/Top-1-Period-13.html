My teaching route

Before students enter

  • Display a smooth analogue waveform and a set of discrete sample points.
  • Ask: “Can a computer store a sound wave directly?”
  • Prepare a simple low-rate and high-rate sampling comparison.
  • Keep the two controls visible: sample rate and sample resolution.
Teaching principle: students should first understand sampling as taking measurements of a changing sound wave before calculating file sizes.
0–5 min · Retrieval

Reconnect with digital representation

  1. What is the difference between analogue and digital data?
  2. What does a bit represent?
  3. Why does a computer need numerical codes to represent text?
  4. Can a computer store a continuously changing sound wave directly as binary?
Bridge: Sound is naturally analogue. To store it digitally, the computer repeatedly measures the wave and stores numerical values.
5–14 min · Discover

What is sampling?

A sound wave changes continuously over time. Sampling takes measurements of the wave at regular time intervals.

Sampling = taking repeated measurements of an analogue signal.

Each measurement is represented digitally as a numerical value. The collection of samples is then used to reconstruct an approximation of the original sound.

Ask: What happens if we take very few measurements?

14–23 min · Teach

Sample rate

Sample rate is the number of samples taken per second. It is measured in hertz (Hz).

Higher sample rate → more samples each second → a more accurate representation of changes over time.

For example, 8,000 samples per second has a sample rate of 8 kHz.

Students should be able to interpret the unit: 1 kHz = 1,000 samples per second.

23–31 min · Teach

Sample resolution

Sample resolution is the number of bits used to store each sample.

More bits allow a sample's amplitude to be represented using more possible values.

Higher sample resolution → more possible amplitude values → greater accuracy of each sample.

Examples:

  • 8-bit resolution → 2⁸ = 256 possible levels
  • 16-bit resolution → 2¹⁶ = 65,536 possible levels
31–37 min · Compare

37–42 min · Application

Quality versus file size

Increasing the sample rate means more samples are stored each second. Increasing sample resolution means more bits are stored for each sample.

Therefore: increasing either setting generally increases the amount of storage required.

This creates a practical trade-off between sound quality and file size.

1 · Analogue → digital

A sound wave is continuously changing. A computer stores digital data, so it takes repeated measurements of the wave.

Sampling = measuring the sound wave at regular intervals.

Each measurement is stored as a numerical value.

2 · Sample rate

Sample rate tells us how many samples are taken every second.

Unit: hertz (Hz)
1 Hz = 1 sample per second
1 kHz = 1,000 samples per second

Higher sample rate means the waveform is measured more frequently.

3 · Sample resolution

Sample resolution tells us how many bits are used for each sample.

8-bit → 2⁸ = 256 possible levels
16-bit → 2¹⁶ = 65,536 possible levels

Higher resolution allows the amplitude of each sample to be represented more precisely.

7 · File size

More samples require more stored data. More bits per sample also require more stored data.

Higher sample rate + higher resolution → larger sound data.

This is a quality-versus-storage trade-off.

9 · Exam practice

Question: Explain the difference between sample rate and sample resolution.

Sample rate is the number of samples taken per second, measured in hertz. Sample resolution is the number of bits used to store each sample and determines how many amplitude levels can be represented.

10 · Common mistakes

  • Confusing sample rate with sample resolution.
  • Thinking Hz means bits per sample.
  • Thinking higher sample rate means more amplitude levels.
  • Forgetting that increasing sampling settings generally increases storage requirements.
