Lesson overview

Period 12 · ASCII and Unicode in Practice

Cambridge focus: Topic 1.2 Text, sound and images — character sets, including ASCII and Unicode. The textbook explains ASCII as a 7-bit character set and Unicode as a much larger character set whose first 128 characters correspond to ASCII. fileciteturn8file3L201-L206

Success criteria: Students can decode common ASCII values, convert character codes between decimal and binary, explain the relationship between ASCII and Unicode, and explain why a larger character set is necessary.

Prior learning: Period 11 — character sets, ASCII and Unicode.

Key vocabulary: character set, character code, ASCII, Unicode, code, encoding, decoding, 7-bit, binary, decimal, character repertoire.

My teaching route

Before students enter

  • Display A, B, C, a, b, c and their ASCII decimal codes.
  • Ask students to convert one decimal code into binary.
  • Prepare a short word for an encoding activity.
  • Keep the 7-bit ASCII range visible.
  • Emphasise that Unicode and ASCII are character-set standards, not programming languages.
Teaching principle: move from recognition → decoding → binary representation → explanation of why Unicode is required.

13–22 min · Guided encoding

Encode a word

Take the word CAT.

C = 67 → 1000011

A = 65 → 1000001

T = 84 → 1010100

CAT can therefore be represented by the sequence of character codes for C, A and T.

Important: each character has its own code. The computer does not store the visual shape of the letter as text; it stores the associated coded data.

22–30 min · Decode

Decode character codes

Give students these decimal codes:

72 · 73 · 32 · 74 · 65

Students use an ASCII table to identify the characters.

Teacher extension: Ask why 32 is not a visible letter. This introduces the idea that character sets also include control and non-letter characters.
30–37 min · Unicode

Why ASCII is not enough

Standard ASCII provides only 128 codes. That is sufficient for many common English characters but is not enough for the huge variety of characters used around the world.

The textbook states that Unicode represents the languages of the world and that the first 128 Unicode characters are the same as ASCII. fileciteturn8file3L201-L206

Key idea: Unicode keeps compatibility with the original ASCII characters while providing a much larger repertoire.
37–43 min · Compare and explain

ASCII vs Unicode

Ask students to complete the sentence:

“Unicode is useful because …”

Then compare:

  • ASCII → small, original character set
  • Unicode → much larger international character repertoire
  • First 128 Unicode characters → same as ASCII
43–47 min · Assessment

Cambridge-style questions

  1. State the number of bits used by standard ASCII.
  2. State the number of possible codes in standard ASCII.
  3. Convert ASCII 65 to 7-bit binary.
  4. Explain why Unicode is needed.
Marking focus: award explanation marks for linking Unicode to the much wider range of characters and languages that need to be represented.
47–50 min · Exit ticket

Three questions before you leave

  1. What character does ASCII 65 represent?
  2. What is 65 in 7-bit binary?
  3. Give one reason Unicode is needed.
Teacher decision: Period 13 can move from text representation to sound representation, while keeping character-set knowledge available for later mixed practice.

6 · Why Unicode?

Standard ASCII has only 128 codes. Think about how many different characters are needed to represent languages and writing systems around the world.

The textbook notes that Unicode's first 128 characters are the same as ASCII. fileciteturn8file3L201-L206

7 · Exam practice

Question: Explain why Unicode is needed rather than using only standard ASCII.

Standard ASCII provides only 128 codes and therefore cannot represent the very large range of characters required for worldwide languages and writing systems. Unicode provides a much larger character repertoire.

9 · Common mistakes

  • Confusing the character with its numerical code.
  • Forgetting that standard ASCII uses 7 bits.
  • Writing 65 as an 8-bit value without understanding that standard ASCII itself is 7-bit.
  • Thinking Unicode replaces binary.
  • Explaining Unicode only as “more characters” without mentioning languages or character repertoire.
