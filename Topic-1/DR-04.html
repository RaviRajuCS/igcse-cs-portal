Hexadecimal Number System

Binary is ideal for computers, but long strings of binary digits can be difficult for humans to read. Hexadecimal provides a compact way of representing binary values.

Why Do We Need Hexadecimal?

Making binary easier for humans to read

BINARY 1101011010110010

16 binary digits

→
HEXADECIMAL D6B2

Only 4 hexadecimal digits

Key idea:

Hexadecimal does not replace binary inside the computer. It provides a shorter and more convenient way for humans to represent binary values.

This is particularly useful when binary values become long and difficult to read.

03

Hexadecimal is Base 16

Sixteen different symbols are required

Denary uses ten symbols: 0–9.

Binary uses two symbols: 0 and 1.

Hexadecimal requires sixteen symbols. The first ten are 0–9, followed by six letters: A–F.

Hexadecimal Place Values

Each position is a power of 16

Position 3 2 1 0
Power 16³ 16² 16¹ 16⁰
Value 4096 256 16 1
Remember:

Just as denary place values are powers of 10 and binary place values are powers of 2, hexadecimal place values are powers of 16.

Where is Hexadecimal Used?

Recognising hexadecimal in the real world of computing

#

Web Colour Codes

Colours in HTML and CSS can be represented using six hexadecimal digits.

#FF0000

This represents a colour using hexadecimal values for the red, green and blue components.

0x

Memory Addresses

Hexadecimal is commonly used when displaying memory addresses because it is much shorter than writing the equivalent binary value.

0x7FF2A
IP

MAC Addresses

Network interface MAC addresses are normally written using hexadecimal digits.

3A:7F:21:B4:09:CE
DB

Machine-Level Data

Hexadecimal can make low-level binary data easier for programmers and technicians to inspect.

7F 45 4C 46

Symbol Lab

The six letters used in hexadecimal are not letters representing unknown values. Each one has a numerical value.

A 10
B 11
C 12
D 13
E 14
F 15

Why not simply use 10, 11, 12, 13, 14 and 15?

A hexadecimal digit must represent a value from 0 to 15 using a single symbol. If we used two denary digits, the position system would become ambiguous.

Therefore hexadecimal uses letters A–F as single-digit symbols for values 10–15.

10₁₀ → A₁₆
12₁₀ → C₁₆
14₁₀ → E₁₆
15₁₀ → F₁₆

Build Hexadecimal Numbers

A hexadecimal number can contain more than one digit. Each position has a place value based on powers of 16.

16² 256
16¹ 16
16⁰ 1

Example: 1A3₁₆

Work from right to left:

1 × 256 + 10 × 16 + 3 × 1 = 419
1A3₁₆ = 419₁₀

Important Pattern

The base determines the place values.

Denary: 10⁰, 10¹, 10², 10³... Binary: 2⁰, 2¹, 2², 2³... Hexadecimal: 16⁰, 16¹, 16², 16³...

Hexadecimal in Computing

Hexadecimal becomes particularly useful when programmers, network engineers and computer technicians need to inspect binary-related information.

Area Example Why hexadecimal helps
Web colours #00FF00 Represents colour components compactly.
MAC addresses 3A:7F:21:B4:09:CE Much shorter than the equivalent binary.
Memory addresses 0x7FF2A Makes low-level addresses easier to read.
Machine data 7F 45 4C 46 Allows long binary sequences to be inspected compactly.
Exam Tip

If asked why hexadecimal is used, do not simply say "because computers use hexadecimal." Explain that it provides a shorter and easier-to-read representation of binary data for humans.

Fix the Mistake

Carefully examine each student's reasoning.

Mistake 1

F₁₆ = 16₁₀

What is wrong?

Reveal explanation

F is the hexadecimal symbol for 15, not 16.

The next hexadecimal value after F is 10₁₆, which represents 16₁₀.

Mistake 2

2A₁₆ = 2 × 16 + 10 = 26

Find the arithmetic error.

Reveal explanation

2 × 16 = 32.

Therefore:

32 + 10 = 42.

So: 2A₁₆ = 42₁₀.

Mistake 3

1G₁₆ is a valid hexadecimal number.
Reveal explanation

Hexadecimal uses only: 0–9 and A–F.

G is not a hexadecimal digit.

Therefore 1G₁₆ is invalid.

Mistake 4

"Hexadecimal is another language that computers use instead of binary."
Improve the statement

A better explanation is:

Hexadecimal is a compact representation of binary data that is easier for humans to read.

Think Like a Computer Scientist

These questions are about understanding, not just remembering.

THINK 01

Why are letters A–F necessary?

Could hexadecimal work using only 0–9?

Think it through

No. Base 16 requires sixteen distinct symbols. The six additional values are represented by A–F.

THINK 02

Why is 10₁₆ equal to 16₁₀?

Compare the meaning of "10" in different bases.

Answer

10₁₆ means: 1 × 16 + 0 = 16.

THINK 03

Why is FF₁₆ equal to 255₁₀?

What happens when both hexadecimal positions contain the largest possible digit?

Answer

F = 15.

15 × 16 + 15 = 255.

THINK 04

Why might a programmer prefer 7F to 01111111?

Key idea

Both represent the same binary information, but 7F is considerably shorter and easier to read and remember.
