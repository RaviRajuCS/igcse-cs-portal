Image Representation

How does a computer turn a photograph, drawing or digital image into nothing more than patterns of binary digits?

1. What Is a Digital Image?

A digital image is an image represented using data that a computer can store and process.

One common type is a bitmap image. A bitmap image is made up of a large number of tiny coloured elements called pixels.

1100 1110 0111 0011
A simplified representation of a tiny image grid
💡 Key idea: A bitmap image is not stored as a photograph inside the computer. It is stored as data describing the pixels that make up the image.

2. Pixels

The word pixel comes from picture element.

A pixel is the smallest individual element of a bitmap image. Each pixel is assigned information that determines its colour.

Zoom in far enough...

...and an image can be viewed as a grid of individual pixels.

When many pixels are viewed together from a normal distance, the human eye perceives them as a complete image.

3. Image Resolution

Resolution describes the number of pixels in an image.

It is commonly expressed as:

Width × Height
800 × 600

An image with a resolution of 800 × 600 contains:

800 × 600
=
480,000 pixels
🎯 Exam point: Do not confuse the dimensions of an image with the number of colours available for each pixel.

4. Resolution and Image Quality

Increasing the resolution means using more pixels to represent the image.

Low Resolution

Fewer pixels can make detail less clear.

Higher Resolution

More pixels can represent finer detail.

5. Colour Depth

Colour depth is the number of bits used to represent the colour of a single pixel.

The more bits available for each pixel, the greater the number of possible colours.

6. Colour Depth and Image Quality

If fewer bits are available for each pixel, fewer colours can be represented.

This can produce visible colour changes or a less realistic image.

Low Colour Depth

Fewer possible colours.

Higher Colour Depth

A much larger range of colours can be represented.

7. What Determines Bitmap Image File Size?

Two important factors are:

🧩

Number of Pixels

Higher resolution means more pixels.

🎨

Colour Depth

More bits per pixel mean more data for each pixel.

Resolution ↑ → Pixels ↑ → File Size ↑
Colour Depth ↑ → Bits per Pixel ↑ → File Size ↑

8. Metadata

An image file can contain more than the pixel data itself.

Metadata is data about the data.

💾 File Size Thinking

For an uncompressed bitmap image, the pixel data can be related to:

File size in bits = width × height × colour depth

Consider: 

Image:
800 × 600 pixels

Colour depth:
8 bits

Pixel data:
800 × 600 × 8

= 3,840,000 bits

🧠 Predict

If the colour depth doubles while the resolution stays exactly the same, what happens to the pixel data size?

The pixel data size also doubles because each pixel now requires twice as many bits.

📝 Guided Practice

Work through these progressively. Try to answer before revealing the explanation.

Challenge 1

An image is 200 pixels wide and 100 pixels high. How many pixels does it contain?

200 × 100 = 20,000 pixels.

Challenge 2

How many colours can be represented using 4 bits per pixel?

24 = 16 colours.

Challenge 3

Which has more pixels: 640 × 480 or 1280 × 720?

640 × 480 = 307,200 pixels.
1280 × 720 = 921,600 pixels.

Therefore the 1280 × 720 image has more pixels.

Challenge 4

Why does increasing colour depth increase the amount of data required?

Each pixel requires more bits to store its colour. Since there may be millions of pixels, the total amount of data increases significantly.

Challenge 5

A student says: "More pixels always means more colours." Is this correct?

No. Resolution determines how many pixels are present. Colour depth determines how many colours each pixel can represent.

Challenge 6

Why might a high-resolution image have a larger file size than a low-resolution image?

A higher-resolution image contains more pixels. More pixels mean more pixel data must be stored.

🕵️ Fix the Mistake

Student:

"A pixel is one bit."
Incorrect. A pixel is an individual picture element. The number of bits used to represent its colour depends on the colour depth.

Student:

"8-bit colour means the image has 8 pixels."
Incorrect. 8-bit colour means each pixel is represented using 8 bits. It allows: 28 = 256 colours.

Student:

"Resolution tells us how many colours an image can have."
Incorrect. Resolution describes the number of pixels. Colour depth determines the number of possible colours per pixel.

Student:

"Increasing resolution decreases file size."
Incorrect. Increasing resolution means more pixels. More pixels normally means more data and therefore a larger uncompressed bitmap file.
