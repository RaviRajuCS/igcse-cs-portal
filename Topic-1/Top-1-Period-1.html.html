Lesson overview

Lesson 1 · Binary Representation & Number Systems

Cambridge focus: Topic 1.1 Number systems. This lesson introduces why computers use binary, the denary/binary/hexadecimal systems, and binary place value. Detailed conversion techniques are deliberately developed in the following lessons.

Success criteria: Students can explain why binary is used, distinguish the three number systems by base and digits, and calculate the denary value of a positive binary integer using place values.

Resources: board/projector, this webpage, mini-whiteboards or paper, and student notebooks.

Key vocabulary: binary, denary, hexadecimal, base, bit, digit, place value, register, 8-bit, most significant bit (MSB), least significant bit (LSB).

Teacher preparation

Before students enter

  • Open this page in full-screen mode.
  • Keep the teacher pane visible while presenting.
  • Prepare three everyday examples of digital data: text, an image and audio.
  • Have students ready to write an 8-bit place-value row: 128, 64, 32, 16, 8, 4, 2, 1.
  • Decide whether students already know powers of two; if not, build the pattern gradually.
Teaching principle: do not begin with conversion algorithms. First establish why binary exists and what a binary place value means.
Questioning strategy

Questions to ask during teaching

  • Why are two states useful inside a computer?
  • What makes binary different from denary?
  • Why does the right-most binary position have a value of 1?
  • What does a 0 mean in a particular place-value column?
  • What does a 1 mean?
  • How could we check our binary-to-denary answer?

Stretch: Ask students to predict the maximum positive value represented by 8 bits before confirming it mathematically.

0–5 min · Starter

Can a computer understand this?

Show students a photograph, a sound recording and a text message. Ask:

  • How can one computer store such different kinds of information?
  • What do all of these forms of data have in common inside a computer?
Target idea: the computer ultimately processes data in binary form.
5–12 min · Teach

Why binary?

Explain the link between binary and the two-state nature of electronic switching.

1  0  1  0  1  1  0  0

Connect the idea of ON/OFF states to 1/0. Emphasise that text, sound, images and numbers are encoded so that the computer can process them as binary data.

12–20 min · Teach

Three number systems

  • Denary — base 10, digits 0–9.
  • Binary — base 2, digits 0 and 1.
  • Hexadecimal — base 16, digits 0–9 and A–F.

Today, focus on understanding the systems. Detailed conversions come in the next lessons.

20–30 min · Demonstrate

Binary place values

Build the 8-bit place-value pattern from right to left:

128
64
32
16
8
4
2
1

Demonstrate that each position is a power of 2. A 1 means that place value contributes to the number; a 0 means it does not.

Example: 11101110₂ = 128 + 64 + 32 + 8 + 4 + 2 = 238₁₀.

30–40 min · Guided practice

Think → Pair → Check

Students work out the denary values of:

  1. 00110011₂
  2. 01111111₂
  3. 10011001₂

Ask students to explain why each 1-bit contributes a particular value.

40–47 min · Check understanding

Mini-whiteboard questions

  1. What base is binary?
  2. How many different digits are used in binary?
  3. What is the value of the right-most bit in an 8-bit number?
  4. Why does a computer use binary to represent data?
47–50 min · Exit ticket

One-minute exit ticket

Students answer without help:

  1. Define binary number system.
  2. Convert 00000101₂ to denary.
  3. Give one reason computers use binary.
Teacher decision: use the responses to decide whether Lesson 2 can begin with conversions or whether a short binary recap is needed.

⭐ Key vocabulary

  • Binary: a base 2 number system using only 0 and 1.
  • Denary: the familiar base 10 number system using 0–9.
  • Hexadecimal: a base 16 number system using 0–9 and A–F.
  • Bit: a binary digit, either 0 or 1.
  • Byte: a group of 8 bits.
  • Register: a small storage location used to hold data being processed.

🧠 Think about this

Imagine a tiny electronic switch that can be in one of two states. If one state is represented by 0 and the other by 1, a computer can build longer patterns from these two values.

For example:

10110100

That pattern can represent a numerical value, but binary patterns can also be used as part of the representation of text, sound, images and other data.

Remember: the binary pattern itself is not automatically “a denary number”. Its meaning depends on the representation being used.

🔍 Common mistakes

  • Calling binary “base 10” — it is base 2.
  • Forgetting that hexadecimal includes A–F.
  • Adding every place value instead of adding only the values under 1.
  • Reading an 8-bit number from the wrong direction when using place values.
  • Dropping leading zeroes when the question specifically requires an 8-bit representation.

Lesson goals

By the end of this lesson you should be able to:

  • explain why computers use binary to represent data;
  • identify denary, binary and hexadecimal as different number systems;
  • state the base and digits used by each system;
  • use binary place values to find the denary value of a positive binary integer.

1 · Why computers use binary

Computers process data electronically. At the basic level, electronic switching can be represented by two states. Binary provides two values:

0 = one state    1 = the other state

For this syllabus, remember the central idea:

Any form of data needs to be converted into binary to be processed by a computer.

2 · Number systems

SystemBaseDigits
Denary100–9
Binary20, 1
Hexadecimal160–9, A–F

Hexadecimal uses A–F for values 10–15.

3 · Binary place values

For an 8-bit positive binary integer, the place values are:

128
64
32
16
8
4
2
1

Example:

1 1 1 0 1 1 1 0

Add only the place values underneath a 1:

128 + 64 + 32 + 8 + 4 + 2 = 238

Therefore 11101110₂ = 238₁₀.
