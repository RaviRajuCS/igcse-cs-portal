Lesson overview

Period 4 · Denary ↔ Hexadecimal and Uses

Cambridge focus: Topic 1.1 Number systems — converting between positive denary and positive hexadecimal, and understanding how and why hexadecimal is used as a beneficial method of data representation. fileciteturn5file0L15-L24

Success criteria: Students can convert positive denary ↔ hexadecimal accurately, explain the place values of hexadecimal, and explain why hexadecimal is useful when representing computer data.

Prior learning: Periods 1–3 — binary place values, binary ↔ denary, hexadecimal digits and binary ↔ hexadecimal.

Key vocabulary: hexadecimal, denary, base 16, place value, digit, A–F, conversion, representation, compact, MAC address, colour code, error code.

Teacher preparation

Before students enter

  • Open the webpage in full-screen mode.
  • Display hexadecimal place values: 4096, 256, 16, 1 for a 4-digit hexadecimal number.
  • Remind students that hexadecimal digits A–F represent denary values 10–15.
  • Prepare one binary → hexadecimal → denary example to connect today's learning to Period 3.
  • Prepare examples of hexadecimal used in real computer systems.
Teaching principle: students should understand hexadecimal place value rather than relying only on memorised conversion shortcuts.
0–5 min · Retrieval

Reconnect with Period 3

  1. What is the base of hexadecimal?
  2. What denary value does F represent?
  3. How many binary bits correspond to one hexadecimal digit?
  4. Convert A5₁₆ to binary.
Bridge: We already know hexadecimal ↔ binary. Today we add denary ↔ hexadecimal so that all three number systems can be connected.
5–15 min · Teach

Hexadecimal place values

Hexadecimal is base 16, so its place values are powers of 16:

4096
256
16
1

For a hexadecimal number such as 2B4₁₆:

2 × 256 + B × 16 + 4 × 1

Since B = 11₁₀:

512 + 176 + 4 = 692₁₀
15–24 min · Model

Hexadecimal → Denary

Use the hexadecimal place values and multiply each digit by its place value.

Example: 3A7₁₆

3 × 256 + A × 16 + 7

A = 10, so:

768 + 160 + 7 = 935

Answer: 3A7₁₆ = 935₁₀

Question to ask: Why is A treated as 10 in the calculation?

24–33 min · Model

Denary → Hexadecimal

Use repeated division by 16, keeping the remainders. Read the hexadecimal digits from the final quotient back through the remainders.

Example: 235₁₀

235 ÷ 16 = 14 remainder 11 → E, B

14 ÷ 16 = 0 remainder 14 → E

Answer: 235₁₀ = EB₁₆

Then verify using place values: E × 16 + B = 14 × 16 + 11 = 235.

33–40 min · Guided practice

Think → Pair → Explain

Hexadecimal → denary:

  1. 1F₁₆
  2. 4A₁₆
  3. C8₁₆

Denary → hexadecimal:

  1. 31₁₀
  2. 74₁₀
  3. 200₁₀

Ask students to explain their method to a partner before checking answers.

40–46 min · Applications

Why is hexadecimal beneficial?

Cambridge states that hexadecimal is easier for humans to understand than binary because it is a shorter representation of binary, and learners should identify areas of computer science where hexadecimal is used. fileciteturn5file0L40-L44

  • MAC addresses — hardware/network addresses are commonly written using hexadecimal digits.
  • Colour codes — hexadecimal is widely used to represent RGB colour values.
  • Error codes — some computer systems display error information in hexadecimal.
  • Low-level representations — hexadecimal can make long binary values easier for humans to read.
Teacher question: If the computer ultimately processes binary, why might a programmer or technician prefer to see hexadecimal?
46–50 min · Assessment & exit ticket

Final check

  1. Convert 2D₁₆ to denary.
  2. Convert 190₁₀ to hexadecimal.
  3. Explain one advantage of hexadecimal over a long binary representation.
Teacher decision: Students who are secure can move to binary addition in Period 5. Students who confuse hexadecimal place values need a short retrieval activity before the next number-systems skill.

🎯 Learning goals

  • Use hexadecimal place values correctly.
  • Convert a positive hexadecimal integer to denary.
  • Convert a positive denary integer to hexadecimal.
  • Explain why hexadecimal is a useful representation of binary data.
  • Recognise common uses of hexadecimal in computer science.

1 · Hexadecimal place values

Because hexadecimal is base 16, each position is a power of 16.

4096
256
16
1

For 2B4₁₆:

2 × 256 + 11 × 16 + 4 × 1

512 + 176 + 4 = 692
Therefore 2B4₁₆ = 692₁₀.

2 · Hexadecimal → Denary

Use the place-value method.

Example: 4C₁₆

C = 12.

4 × 16 + 12 = 76

4C₁₆ = 76₁₀

For more than two digits, continue with the higher powers of 16.

3 · Denary → Hexadecimal

Divide by 16 repeatedly and keep the remainders.

Example: 235₁₀

235 ÷ 16 = 14 remainder 11 → E, B

14 ÷ 16 = 0 remainder 14 → E

235₁₀ = EB₁₆

Verify: E × 16 + B = 14 × 16 + 11 = 235.

4 · Quick check

Q1: What is C₁₆ in denary?

Q2: What is 31₁₀ in hexadecimal?

5 · Practice — Hex → Denary

  1. 1A₁₆
  2. 2F₁₆
  3. 7B₁₆
  4. D0₁₆
Answers: 26, 47, 123, 208.

6 · Practice — Denary → Hex

  1. 26₁₀
  2. 47₁₀
  3. 123₁₀
  4. 208₁₀
Answers: 1A₁₆, 2F₁₆, 7B₁₆, D0₁₆.

7 · Why hexadecimal?

A binary number can become very long. Hexadecimal provides a compact human-readable representation because four binary bits correspond to one hexadecimal digit.

For example:

1101 1010 1111

D A F

110110101111₂ = DAF₁₆

The information has not changed; only the representation has become shorter and easier for a human to read.

8 · Where is hexadecimal used?

  • MAC addresses
  • Colour codes
  • Error codes
  • Low-level computer representations

Cambridge expects you to identify areas where hexadecimal is used and understand its benefit as a shorter representation of binary. fileciteturn5file0L40-L44

9 · Exam practice

Question: Convert 2F7₁₆ into denary. Show all working.

2 × 256 + 15 × 16 + 7
= 512 + 240 + 7
= 759₁₀

10 · Challenge

Without using a calculator:

  1. Convert 3E8₁₆ to denary.
  2. Convert 1000₁₀ to hexadecimal.
  3. Explain why 16 binary bits can be represented by only four hexadecimal digits.
Answers:
1. 1000
2. 3E8₁₆
3. Each hexadecimal digit represents four binary bits, so four hexadecimal digits represent 16 bits.

11 · Common mistakes

  • Using powers of 10 instead of powers of 16.
  • Forgetting that A–F represent 10–15.
  • Reading remainders in the wrong order after division by 16.
  • Confusing a hexadecimal digit with its denary value.
  • Giving only the final answer without showing the conversion method when working is required.
