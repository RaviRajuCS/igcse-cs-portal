Lesson overview

Period 15 · Image Representation

Cambridge focus: Topic 1.2 requires students to understand how and why a computer represents an image, including the effects of resolution and colour depth. The syllabus states that an image is a series of pixels converted to binary, that resolution is the number of pixels, and that colour depth is the number of bits used to represent each colour.

Success criteria: Students can define pixel, image resolution and colour depth; explain how a bitmap image is represented digitally; and predict how changing resolution or colour depth affects image quality and file size.

Prior learning: Binary representation and sound sampling.

Key vocabulary: bitmap, pixel, resolution, colour depth, bit depth, RGB, binary, image quality, file size, pixelated.

My teaching route

Before students enter

  • Display a clear bitmap image and zoom into a small area.
  • Ask students what the tiny coloured squares are.
  • Prepare two versions of an image with different resolutions.
  • Keep the distinction visible: resolution = number of pixels; colour depth = bits per colour/pixel representation.
Teaching principle: let students discover pixels visually before introducing the numerical definitions.

5–13 min · Discover

What is a pixel?

A pixel is the smallest element used to make up an image on a display. A bitmap image is made from pixels.

Pixel = picture element.

Each pixel has information associated with its colour. That information can be represented digitally using binary.

13–22 min · Teach

Image resolution

Resolution describes the number of pixels in an image. It is commonly expressed as width × height, for example 800 × 600 pixels.

Number of pixels = width × height.

Example: 800 × 600 = 480,000 pixels.

Higher resolution means more pixels are used to represent the image and generally gives greater detail.

22–31 min · Teach

Colour depth

Colour depth is the number of bits used to represent the colour information for a pixel.

The number of possible colours can be found using:

Number of colours = 2colour depth
  • 1-bit → 2 colours
  • 2-bit → 4 colours
  • 8-bit → 256 colours
  • 24-bit → 16,777,216 possible colour combinations

37–42 min · Application

Image quality and file size

The Cambridge syllabus states that both image file size and quality increase as resolution and colour depth increase.

Higher resolution → more pixels → more image data.
Higher colour depth → more bits per colour → more image data.

9 · Exam practice

Question: Explain the difference between image resolution and colour depth.

Resolution is the number of pixels in an image, while colour depth is the number of bits used to represent the colour information for each pixel. Increasing either generally increases image data and file size.

10 · Common mistakes

  • Calling a pixel a bit.
  • Confusing resolution with colour depth.
  • Multiplying colour depth by the wrong quantity.
  • Thinking higher resolution means more colours.
  • Forgetting that higher resolution and colour depth generally increase file size.
