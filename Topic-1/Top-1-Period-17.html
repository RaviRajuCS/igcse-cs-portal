Lesson overview

Period 17 · Data Compression

Cambridge focus: Topic 1.3 introduces the purpose and need for data compression. Compression reduces file size, which can reduce bandwidth requirements, storage requirements and transmission time. Students also begin to distinguish lossy and lossless compression.

Success criteria: Students can define compression, explain why compression is needed, identify practical benefits, and distinguish lossy from lossless compression at a conceptual level.

Prior learning: Image and sound file-size calculations.

Key vocabulary: compression, compressed file, bandwidth, storage space, transmission time, lossy, lossless, redundant data, original data.

My teaching route

The big idea

Compression reduces the size of a file.
  • Less storage space required
  • Less data needs to travel across a network
  • Shorter transmission time
  • Lower bandwidth requirement

Begin with a real-life analogy: remove unnecessary repetition from a message without changing what the receiver needs to understand.

0–5 min · Retrieval

Why are files large?

  1. What makes a bitmap image larger?
  2. What makes a sound file larger?
  3. Why might a large file be inconvenient to send?
  4. What is bandwidth?
Bridge: If we can reduce the amount of data in a file, we can make storage and transmission more efficient.
5–13 min · Discover

What is compression?

Compression is the process of reducing the size of a file.

Compression is useful because large files require more storage and more data to be transferred.

Compression does not mean “making the information disappear”. The key question is what happens to the information during compression and decompression.
13–21 min · Why do we need it?

Three practical benefits

BenefitWhy?
Less storageThe compressed file occupies less space.
Faster transmissionFewer bits need to be sent.
Less bandwidthThe transfer requires less network capacity.
Exam connection: when asked for the purpose of compression, give a benefit rather than simply repeating “it makes files smaller”.
21–30 min · Teach

Lossy vs lossless

There are two important categories of compression:

Lossy compression permanently removes some data to reduce file size.
Lossless compression reduces file size without permanently losing data; the original data can be restored.

The Cambridge syllabus specifically requires students to understand both methods.

30–36 min · Examples

Where might each be useful?

  • Lossy: useful where a smaller file is more important than preserving every piece of original data.
  • Lossless: useful where the original data must be recovered exactly.
Remember: “lossy” refers to permanent data loss; “lossless” means the original data can be recovered.

Marking focus: “lossless” must mean that the original data can be fully recovered.
46–50 min · Exit ticket

Three questions before you leave

  1. What is the purpose of compression?
  2. What happens to data in lossy compression?
  3. Can the original data be fully restored after lossless compression?
Teacher decision: Period 18 can introduce Run Length Encoding (RLE) as the main lossless compression technique required by the syllabus.

1 · What is compression?

Compression reduces the size of a file.

Smaller file → less storage space and less data to transmit.

2 · Why compress data?

  • Use less storage space.
  • Reduce the amount of data sent across a network.
  • Reduce transmission time.
  • Reduce bandwidth requirements.

3 · Quick check

Q1: What is the main purpose of compression?

Q2: Which is a benefit of a smaller file?

4 · Lossy compression

Lossy compression reduces file size by permanently removing some data.

Lossy → some original data is lost.

After decompression, the result is not exactly identical to the original data.

5 · Lossless compression

Lossless compression reduces file size without permanently losing data.

Lossless → original data can be restored exactly.

6 · Quick check

Q3: Which type permanently removes some data?

Q4: Which type can restore the original data exactly?

7 · Compare

LossyLossless
Permanent data removalNo permanent data removal
Original cannot be restored exactlyOriginal can be restored exactly

8 · Scenario challenge

A company must send a huge collection of files over a slow network. Give two reasons why compression could help.

Compression reduces the amount of data that needs to be transmitted, so transmission time can be shorter and less bandwidth is required. It also reduces the storage space needed.

9 · Exam practice

Question: Explain the difference between lossy and lossless compression.

Lossy compression permanently removes some data to reduce file size, so the original cannot be recovered exactly. Lossless compression reduces the file size without permanently losing data, so the original can be fully restored.

10 · Common mistakes

  • Thinking compression always means losing data.
  • Confusing “smaller file” with “lower quality” in every situation.
  • Forgetting that lossless compression allows exact recovery.
  • Giving only “smaller files” when asked for practical benefits.
