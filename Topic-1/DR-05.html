The Key Relationship

Four binary bits make one hexadecimal digit

BINARY 1010 Four bits
=
HEXADECIMAL A One digit
The reason:

A group of four binary bits can represent values from 0 to 15. Hexadecimal has exactly sixteen symbols, representing 0 to 15.

Therefore every possible 4-bit binary pattern has exactly one hexadecimal equivalent.

What is a nibble?

A nibble is a group of four binary bits.

Since four bits can represent sixteen different values from 0 to 15, one nibble can be represented by exactly one hexadecimal digit.

Binary → Hexadecimal

The four-step conversion method

1

Start with the binary number

Example:

11010110
2

Split into groups of four

Starting from the right:

1101   0110
3

Convert each group

1101 = D     0110 = 6

4

Write the hexadecimal value

D6
WORKED EXAMPLE

Convert 10101111₂ to hexadecimal.

1010 1111
1010 → A
1111 → F
10101111₂ = AF₁₆
06

What if the Binary Number is Not a Multiple of Four?

Leading zeros are your friend

Suppose we need to convert:

101101₂

We cannot immediately make complete groups of four. Add zeros to the left, not the right.

101101
→
00101101

Now group from the right:

0010 1101
0010 → 2
1101 → D
101101₂ = 2D₁₆
Critical rule:

When adding leading zeros, add them to the left-hand side of the binary number. Adding zeros to the right changes the value.

07

Hexadecimal → Binary

The reverse process is even easier

Step 1 Take each hexadecimal digit separately.
Step 2 Replace each digit with its 4-bit binary equivalent.
Step 3 Join the groups together.
WORKED EXAMPLE

Convert 3C₁₆ to binary.

3 → 0011
C → 1100
0011 1100
3C₁₆ = 00111100₂
ANOTHER EXAMPLE

Convert B7₁₆ to binary.

B → 1011
7 → 0111
1011 0111
B7₁₆ = 10110111₂
08

Why the Conversion Works

See the mathematics behind the shortcut

Binary 8 4 2 1
Hex 8 4 2 1

A 4-bit binary group has place values:

2³   2²   2¹   2⁰

These are:

8   4   2   1

The largest possible value is:

8 + 4 + 2 + 1 = 15

Hexadecimal has exactly sixteen possible digits: 0–15. That is why the relationship is exact.

Group It Correctly

One of the most common errors is grouping binary digits incorrectly.

Example: 110110101111₂

1101 1010 1111

This is correct because every group contains exactly four bits.

1101 1010 1111
D A F
110110101111₂ = DAF₁₆

Example with leading zeros

Convert:

1011011₂

Add one leading zero:

0101 1011
5 B
1011011₂ = 5B₁₆
Group from the RIGHT.

If the first group contains fewer than four bits, add leading zeros to complete it.

Fix the Mistake

Understanding mistakes is part of becoming accurate.

Mistake 1

101101₂ → 1011 01 → B6

What went wrong?

Reveal explanation

Binary must be grouped from the right into groups of four.

101101 becomes:

0010 1101

Therefore the correct answer is: 2D₁₆.

Mistake 2

A₁₆ → 101₂
Reveal explanation

Every hexadecimal digit must become exactly four binary bits.

A → 1010

Mistake 3

0110 → 011 → 3
Reveal explanation

The leading zero is significant when identifying the complete four-bit pattern.

0110 represents denary 6, therefore: 0110₂ = 6₁₆.

Mistake 4

101101 → 1011 0100
Reveal explanation

The zero was added to the wrong side.

Leading zeros must be added to the left.

Correct: 0010 1101.

Think Like a Computer Scientist

Do not just perform the conversion — understand why the method works.

THINK 01

Why exactly four bits?

Why not three bits or five bits?

Think it through

Four binary bits can represent 16 different combinations, from 0000 to 1111. Hexadecimal also has exactly 16 possible symbols.

THINK 02

Why are leading zeros allowed?

Does adding a zero to the left change a binary number's value?

Answer

No. Just as 007 and 7 have the same denary value, 001011 and 1011 have the same binary value.

THINK 03

Why does hexadecimal make binary shorter?

Answer

Each hexadecimal digit represents four binary bits. Therefore four binary characters can be replaced by one hexadecimal character.

THINK 04

Could one hexadecimal digit represent five binary bits?

Answer

No. Five binary bits can represent 32 different values, but hexadecimal has only 16 symbols.
