Binary ↔ Denary Conversion

Computers work with binary, while humans commonly use denary. Computer scientists therefore need to move confidently between the two representations.

One Number — Two Representations

The value does not change; only its representation changes

DENARY 25 Base 10
⇄
BINARY 00011001 Base 2
Key idea:

25 and 00011001 are two different representations of the same numerical value.

The computer does not suddenly change the value. We are simply changing the way the value is represented.

03

Binary → Denary

Use the place values and add the values represented by 1s

METHOD 1

Place-Value Method

To convert a binary number into denary:

  1. Write the binary number.
  2. Write the binary place values underneath.
  3. Identify the positions containing 1.
  4. Add those place values.
  5. The total is the denary value.
Worked Example 1

Convert 00101101₂ to denary.

Binary 0 0 1 0 1 1 0 1
Place value 128 64 32 16 8 4 2 1
32 + 8 + 4 + 1 = 45
00101101₂ = 45₁₀
Worked Example 2

Convert 11001010₂ to denary.

Binary 1 1 0 0 1 0 1 0
Place value 128 64 32 16 8 4 2 1
128 + 64 + 8 + 2 = 202
11001010₂ = 202₁₀
04

Denary → Binary

Use the largest possible binary place value at each step

METHOD 2

Place-Value Selection Method

This is a very useful method for working with the 8-bit values used in this topic.

  1. Start with the largest place value: 128.
  2. Ask: can this value be subtracted from the denary number?
  3. If yes, write 1 and subtract it.
  4. If no, write 0.
  5. Continue from left to right.
  6. Read the eight bits as the final binary number.
Worked Example 3

Convert 77₁₀ to an 8-bit binary number.

128 Too large 0
64 77 − 64 = 13 1
32 Too large 0
16 Too large 0
8 13 − 8 = 5 1
4 5 − 4 = 1 1
2 Too large 0
1 1 − 1 = 0 1
77₁₀ = 01001101₂
Worked Example 4

Convert 156₁₀ to binary.

128 156 − 128 = 28 1
64 Too large 0
32 Too large 0
16 28 − 16 = 12 1
8 12 − 8 = 4 1
4 4 − 4 = 0 1
2 Too large 0
1 Too large 0
156₁₀ = 10011100₂

Binary → Denary

The direction changes

The underlying place-value system remains the same. What changes is the method we use to construct the representation.

Learn the Two Conversion Methods

Learn both directions carefully. Do not try to memorise answers. Learn the process.

BINARY → DENARY

Place-Value Addition

  1. Write the place values.
  2. Look at each binary digit.
  3. Ignore positions containing 0.
  4. Add the values underneath the 1s.
  5. Write the total in denary.
10110100
128 + 32 + 16 + 4
= 180
DENARY → BINARY

Place-Value Selection

  1. Start with 128.
  2. Decide whether it fits.
  3. Write 1 if it fits.
  4. Write 0 if it does not.
  5. Subtract selected values.
  6. Continue to the right.
180
128 + 32 + 16 + 4
= 10110100
Exam Tip

Always write the place values when doing a conversion by hand. It gives you a clear working method and makes mistakes easier to find.

Challenge Zone

These problems require you to use the conversion method rather than simply recall an answer.

Challenge 1

Which binary number represents the denary value 127?

01111111 10000000 11111110 11111111
Check the reasoning

127 = 64 + 32 + 16 + 8 + 4 + 2 + 1.

Therefore every position except the 128 position is 1: 01111111.

Challenge 2

A student says:

"10000001₂ is 9 because I can see a 1 at the beginning and a 1 at the end."

Is the student correct?

Check the reasoning

No. The left-most 1 represents 128 and the right-most 1 represents 1.

Therefore: 10000001₂ = 129₁₀.

Challenge 3

Find a binary number containing exactly four 1s whose denary value is greater than 200.

One possible answer

11001100₂

128 + 64 + 8 + 4 = 204.

Other correct answers are possible.

Fix the Mistake

Strong programmers and computer scientists do not simply find answers — they learn to identify and correct errors.

Mistake 1

A student converts:

00101010₂
32 + 8 + 2 = 40

The answer should actually be 42. What was missed?

Find the error

The binary number is: 00101010

Its 1s represent: 32 + 8 + 2.

That equals: 42.

The student's addition was incorrect.

Mistake 2

A student writes:

25₁₀ = 00011010₂

Find the problem.

Check

00011010 represents:

16 + 8 + 2 = 26.

Therefore it is not 25.

25 is: 00011001₂.

Mistake 3

A student says:

"The binary number 00101 is smaller than 101 because it has more zeroes."
Think about it

Leading zeroes do not change a binary value.

Therefore: 00101₂ = 101₂ = 5₁₀.

Think Beyond the Calculation

Explain the ideas in your own words.

THINK 01

Why can every positive integer be represented in binary?

Think about the powers of 2 and how they can be combined to produce different values.

Key idea

Powers of 2 can be combined to represent every positive integer within the available range.

THINK 02

Why does an 8-bit number stop at 255?

What happens when all eight bits are set to 1?

Check

128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255.

THINK 03

Why is checking the reverse conversion useful?

Suppose you converted 91 to binary. How could you test whether your answer is correct?

Answer

Convert your binary answer back to denary. If you get 91, your conversion is consistent.

THINK 04

Is 01000000 greater than 00111111?

Do not compare the digits as if they were denary. Compare their place values.

Answer

Yes. 01000000 = 64, while 00111111 = 63.
