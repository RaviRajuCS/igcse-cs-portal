Sampled Sound

Bits → Bytes

bytes = bits ÷ 8

Binary Storage Units

Percentage Reduction

((original − compressed) ÷ original) × 100

original ÷ compressed

🔢 Number Systems Review

Convert 45 denary into binary.

45 = 32 + 8 + 4 + 1. Therefore: 00101101.

Convert 10110110 into hexadecimal.

Split into nibbles: 1011 0110 → B6. Answer: B6.

What is the value of hexadecimal 3A in denary?

3 × 16 + 10 = 48 + 10 = 58.

⚙️ Binary Operations Review

Add: 00101101 + 00000111

45 + 7 = 52. Binary: 00110100.

Perform a logical left shift on: 00010110.

Shift every bit one position left and insert zero: 00101100. The value has doubled from 22 to 44.

What happens to a bit shifted out of an 8-bit register?

The bit shifted out is lost. A zero is inserted at the opposite end for a logical shift.

🔤 Character Representation

What is the purpose of a character set?

A character set defines mappings between characters and numerical codes so that computers can represent characters using binary.

Why can different character sets represent the same character using different codes?

Each character set defines its own mapping between characters and numerical values.

🖼️ Image Representation

What happens to bitmap file size if both width and height are doubled while colour depth stays constant?

Pixels increase by 2 × 2 = 4. Therefore the raw bitmap data requires four times as much storage.

What is colour depth?

The number of bits used to represent the colour of each pixel.

Calculate the raw size of a 100 × 100 image using 8 bits per pixel.

100 × 100 × 8 = 80,000 bits. That is 10,000 bytes.

🎵 Sound Representation

Name the four factors used in the basic sampled-sound file-size calculation.

Sample rate, sample resolution, duration and number of channels.

What happens to file size if the sample rate is doubled while everything else remains constant?

The number of samples doubles, so the calculated raw file size also doubles.

What is the difference between mono and stereo?

Mono uses one audio channel. Stereo uses two channels. With all other factors equal, stereo requires twice the raw sample data of mono.

💾 Storage Review

Convert 5 MiB into KiB.

5 × 1024 = 5120 KiB.

Convert 16,384 bits into bytes.

16,384 ÷ 8 = 2048 bytes.

Why should mixed file sizes be converted to the same unit before they are added?

Because values in different units cannot be meaningfully added until they have been expressed using the same unit.

📦 Compression Review

Which type of compression allows exact reconstruction?

Lossless compression.

A 1000 MiB file becomes 250 MiB. What percentage reduction occurred?

Reduction = 1000 − 250 = 750 MiB. 750 ÷ 1000 × 100 = 75%.

What is the compression ratio for the same file?

1000 ÷ 250 = 4 : 1.

🔥 Mixed Practice

These questions deliberately mix different areas. This is closer to real examination thinking.

1. Convert hexadecimal 7C to binary.

7 = 0111 and C = 1100. Answer: 01111100.

2. An image is 640 × 480 pixels with 16-bit colour depth. Calculate its raw size in bits.

640 × 480 × 16 = 4,915,200 bits.

3. A mono recording has a sample rate of 8000 samples/s, sample resolution of 8 bits and duration of 20 seconds. Find the raw size.

8000 × 8 × 20 × 1 = 1,280,000 bits.

4. A 2 GiB device contains 800 MiB of data. How much remains?

2 GiB = 2048 MiB. 2048 − 800 = 1248 MiB.

5. A 500 MiB file is compressed to 350 MiB. Find the percentage reduction.

Reduction = 150 MiB. 150 ÷ 500 × 100 = 30%.

📝 Final Exam Strategy

1
Read the question carefully.

Identify what information has been given and exactly what the question asks you to find.

2
Write the formula or method.

Do not immediately substitute numbers. Establish the correct method first.

3
Keep units visible.

Bits, bytes, KiB and MiB are not interchangeable.

4
Show intermediate working.

Multi-step calculations become easier to check and correct.

5
Check whether the answer makes sense.

A calculated file size should not unexpectedly become negative, and a number of complete files cannot normally be fractional.
