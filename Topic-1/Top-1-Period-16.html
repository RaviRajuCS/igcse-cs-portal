My teaching route
Lesson overview

Period 16 · Image File Size Calculations

Cambridge focus: Bitmap image data is determined by the number of pixels and the colour depth used to represent each pixel. Students apply these ideas to calculate the storage required for an image.

Success criteria: Students can calculate the number of pixels in an image, multiply by colour depth to find the size in bits, convert bits to bytes, and convert the result to the required storage unit.

Prior learning: Period 15 — pixels, resolution and colour depth.

Key vocabulary: resolution, pixel, colour depth, bits per pixel, image size, bits, bytes, KiB, MiB, bitmap.

My teaching route

The calculation chain

Pixels = width × height

Image size (bits) = pixels × colour depth
  1. Find the total number of pixels.
  2. Multiply by the colour depth in bits per pixel.
  3. Divide by 8 to obtain bytes.
  4. Convert to KiB, MiB or another requested unit if necessary.

Keep the answer in the unit requested by the question.

0–5 min · Retrieval

Reconnect with Period 15

  1. What is a pixel?
  2. What does image resolution tell us?
  3. What does colour depth tell us?
  4. How many colours can 8 bits represent?
Bridge: We know what resolution and colour depth mean. Now we use them to calculate image data size.
5–14 min · Model

Worked example 1

An image is 800 × 600 pixels with a colour depth of 8 bits.

Pixels = 800 × 600 = 480,000

Bits = 480,000 × 8 = 3,840,000 bits

Bytes = 3,840,000 ÷ 8 = 480,000 bytes

Answer: 480,000 bytes of raw pixel data.
14–23 min · Model

Worked example 2 · MiB

An image is 1024 × 768 pixels with a colour depth of 24 bits.

Pixels = 1024 × 768 = 786,432

Bits = 786,432 × 24 = 18,874,368 bits

Bytes = 18,874,368 ÷ 8 = 2,359,296 bytes

MiB = 2,359,296 ÷ 1,048,576 = 2.25 MiB

Exam habit: write the unit after every major step.
23–31 min · Guided practice

Build the calculation

Question A: 640 × 480 pixels, 8-bit colour depth.

Question B: 800 × 600 pixels, 16-bit colour depth.

For each, calculate:

  1. Number of pixels
  2. Size in bits
  3. Size in bytes
Teacher move: check that students calculate pixels first. Do not let them multiply width × height × colour depth mentally without showing the structure.
31–36 min · Unit conversion

Bytes → KiB → MiB

8 bits = 1 byte
1024 bytes = 1 KiB
1024 KiB = 1 MiB

For the storage-unit conversions specified in the Cambridge syllabus, use 1024, not 1000.

36–41 min · Application

What makes an image larger?

IncreaseEffect
Width / heightMore pixels → more data
ResolutionMore pixels → larger file
Colour depthMore bits per pixel → larger file
Key relationship: raw bitmap size is directly proportional to the number of pixels and colour depth.
41–47 min · Assessment

Cambridge-style calculation

An image has a resolution of 1280 × 720 pixels and a colour depth of 16 bits.

  1. Calculate the number of pixels.
  2. Calculate the file size in bits.
  3. Calculate the file size in bytes.
  4. Calculate the file size in MiB.
Marking focus: width × height → pixels → × bits per pixel → bits → ÷8 → bytes → storage conversion.
47–50 min · Exit ticket

Three questions before you leave

  1. What is the formula for the number of pixels?
  2. How do you calculate image size in bits?
  3. What do you divide by to convert bits to bytes?
Teacher decision: Period 17 can consolidate image calculations and introduce questions involving changes in resolution and colour depth.

1 · The formulas

Pixels = width × height

Image size in bits = pixels × colour depth

Then:

Bytes = bits ÷ 8

2 · Worked example

800 × 600 pixels, 8-bit colour depth.

Pixels = 800 × 600 = 480,000

Bits = 480,000 × 8 = 3,840,000 bits

Bytes = 3,840,000 ÷ 8 = 480,000 bytes

800 × 600 pixels, 16-bit colour depth.

Pixels = 480,000.

6 · Storage units

8 bits = 1 byte
1024 bytes = 1 KiB
1024 KiB = 1 MiB

Use 1024 for the specified binary storage conversions.

7 · Challenge: MiB

1024 × 768 pixels, 24-bit colour depth.

Pixels = 786,432.
Bits = 18,874,368 bits.
Bytes = 2,359,296 bytes.
MiB = 2,359,296 ÷ 1,048,576 = 2.25 MiB.

8 · Exam practice

An image is 1280 × 720 pixels with a colour depth of 16 bits. Calculate its size in MiB.

Pixels = 1280 × 720 = 921,600.
Bits = 921,600 × 16 = 14,745,600 bits.
Bytes = 1,843,200 bytes.
MiB = 1,843,200 ÷ 1,048,576 ≈ 1.76 MiB.

9 · Think carefully

What happens to raw image size if the colour depth doubles while the resolution stays the same?

10 · Common mistakes

  • Forgetting width × height.
  • Using colour depth as the number of colours rather than bits per pixel.
  • Forgetting to divide bits by 8.
  • Using 1000 instead of 1024 for the specified storage conversion.
  • Giving the answer without the requested unit.
