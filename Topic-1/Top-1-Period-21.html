Teacher answer guide

Key marking points

Number systems: correct place values and conversions.

Character sets: ASCII is 7-bit; Unicode represents a wider range of characters and symbols.

Sound: sample rate = samples per second; sample resolution = bits per sample.

Images: resolution = number of pixels; colour depth = bits used to represent colour.

Storage: use 8 bits = 1 byte and 1024 for the specified binary storage conversions.

Compression: lossy permanently removes data; lossless does not permanently lose data; RLE is a lossless method.
