LESSON 13

Data Compression

Discover how compression reduces the amount of storage required by digital data and why different compression methods are suitable for different types of information.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Explain why data is compressed.
  • Explain the relationship between compression and file size.
  • Distinguish between lossy and lossless compression.
  • Explain why lossless compression is suitable for some data.
  • Explain why lossy compression may be suitable for multimedia.
  • Describe the idea of reducing redundancy.
  • Calculate percentage reduction in file size.
  • Calculate compression ratio.
  • Compare original and compressed file sizes.
  • Choose an appropriate compression approach for a situation.

🔁 Why Do We Need Compression?

Digital files can become very large. High-resolution images, high-quality audio and video can require a considerable amount of storage space.

Compression attempts to represent the same information using fewer bits, or—in the case of lossy compression—to represent it using fewer bits while accepting some loss of information.

Original Data
→
Compression
→
Smaller File

💾 Less Storage

Smaller files require less storage space.

🌐 Faster Transfer

Smaller files generally require less data to transfer.

🧠 The Central Idea — Redundancy

Some data contains information that is repeated or predictable. Such information may contain redundancy.

If the same information appears repeatedly, it may be possible to represent it more efficiently.

Simple Example

Imagine this sequence:

A A A A A A A A A A

Instead of thinking of this as ten separate A characters, we could describe it as:

10 × A

This is only a simple illustration of the idea. Real compression algorithms use formal methods to represent data efficiently.

📦 Two Major Approaches

🔐

Lossless Compression

No information is permanently lost.

  • The original data can be reconstructed exactly.
  • Important for data where every bit matters.
  • Useful for many documents and other exact data.
EXACT RECONSTRUCTION
🎨

Lossy Compression

Some information is discarded to achieve greater reduction in file size.

  • The original data cannot be reconstructed exactly.
  • Can produce much smaller files.
  • Often useful for multimedia where some information may be less noticeable.
SOME INFORMATION DISCARDED

🔐 Lossless Compression

With lossless compression, the compressed representation can be decompressed to recreate the original data exactly.

↓
Compress Smaller representation
↓

Key question: If the data must come back exactly as it was, lossless compression is required.

🎨 Lossy Compression

Lossy compression deliberately removes some information. The objective is to reduce file size while maintaining acceptable quality for its intended use.

Original Large amount of data
→
Compress Some information removed
→
Compressed Smaller file

Once information has been discarded, decompressing the file does not recreate the exact original.

Important: Lossy compression is not simply "bad quality". It is a deliberate trade-off between file size and information or perceived quality.

⚖️ Lossless vs Lossy

Feature Lossless Lossy
Information permanently discarded? No Yes
Original reconstructed exactly? Yes No
Potential size reduction Usually more limited Can be much greater
Suitable when exact data matters? Yes No
Can be useful for multimedia? Yes Yes

📊 File Size Reduction

Compression can be described by comparing the original file size with the compressed file size.

Percentage Reduction

Percentage reduction = ((original size − compressed size) ÷ original size) × 100

Compression Ratio

Compression ratio = original size ÷ compressed size

✏️ Worked Example 1 — Percentage Reduction

A file has an original size of 800 MiB. After compression it is 200 MiB. Calculate the percentage reduction.

Step 1: Find the reduction.

800 − 200 = 600 MiB

Step 2: Divide by the original size.

600 ÷ 800 = 0.75

Step 3: Convert to a percentage.

0.75 × 100 = 75%
Percentage reduction = 75%

✏️ Worked Example 2 — Compression Ratio

A file is originally 1200 MiB and is compressed to 300 MiB.

Compression ratio = 1200 ÷ 300 = 4
Compression ratio = 4 : 1

This means the original file was four times the size of the compressed file.

✏️ Worked Example 3 — Finding the Compressed Size

A file of 600 MiB is reduced by 40%. Find its compressed size.

Amount removed:

600 × 0.40 = 240 MiB

Compressed size:

600 − 240 = 360 MiB
Compressed size = 360 MiB

🔍 When Should We Use Lossless Compression?

📄 Documents

If characters or information cannot be changed, exact reconstruction is important.

Lossless is appropriate.

💻 Program Files

Changing program instructions could change how the program works.

Lossless is appropriate.

🗃️ Important Data

Where every piece of information must remain intact.

Lossless is appropriate.

🎵 When Can Lossy Compression Be Useful?

🖼️ Images

Some image information may be removed while retaining acceptable visual quality.

🎵 Audio

Some sound information may be removed if the result remains acceptable to the listener.

🎬 Video

Large amounts of multimedia data can benefit from substantial reduction in size.

Think about the purpose. The correct choice depends on whether exact reconstruction is required and how much reduction is needed.

🔍 Fix the Mistake

Mistake 1: "Lossless compression means that the compressed file has exactly the same size as the original."

Incorrect. Lossless refers to information, not identical file size. The compressed file is normally smaller, but the original information can be reconstructed exactly.

Mistake 2: "Lossy compression can always recreate the original file."

Incorrect. Lossy compression permanently discards some information, so exact reconstruction is not possible.

Mistake 3: "A 50% reduction means the compressed file is 50 times smaller."

Incorrect. A 50% reduction means half the original size remains. The compressed file is 0.5 times the original size, or the original is 2 times the compressed size.

Mistake 4: "Lossy compression is never suitable for multimedia."

Incorrect. Lossy compression can be very useful for multimedia when a reduction in information or quality is acceptable.

📝 Exam Method

  1. Identify whether the question asks about lossless or lossy.
  2. Ask whether exact reconstruction is required.
  3. For percentage reduction, identify the original size.
  4. Calculate the reduction: original − compressed.
  5. Divide the reduction by the original size.
  6. Multiply by 100 to obtain the percentage.
  7. For compression ratio, calculate: original ÷ compressed.
  8. Always include the correct units and check whether the answer is sensible.

🏆 Challenge

A collection of multimedia files occupies 2.4 GiB. Compression reduces the total size by 35%.

  1. How much data is removed?
  2. What is the compressed size?

Reduction: 2.4 × 0.35 = 0.84 GiB

Compressed size: 2.4 − 0.84 = 1.56 GiB

Answer: 0.84 GiB removed and 1.56 GiB remains.

🚨 Common Mistakes

  • Thinking "lossless" means no reduction in file size.
  • Thinking lossy compression can recreate the exact original.
  • Using the compressed size instead of the original size when calculating percentage reduction.
  • Confusing percentage reduction with compression ratio.
  • Forgetting to subtract the compressed size from the original.
  • Assuming lossy compression is always unsuitable.
  • Assuming lossless compression always produces the greatest possible reduction.
