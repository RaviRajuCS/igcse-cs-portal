Lesson overview

Period 11 · Text Representation

Cambridge focus: Topic 1.2 Text, sound and images — how and why computers represent text, including the use of character sets such as ASCII and Unicode. fileciteturn9file3L226-L232

Success criteria: Students can explain why text must be represented digitally, describe a character set, distinguish ASCII from Unicode, and explain why Unicode is needed for a much wider range of characters and languages.

Prior learning: Binary representation and number systems.

Key vocabulary: character, character set, ASCII, Unicode, encoding, code point, 7-bit, 8-bit, multilingual, representation.

My teaching route

Before students enter

  • Display a short word and ask: “How can a computer store this?”
  • Prepare a simple character-to-number table.
  • Contrast familiar English characters with characters from other writing systems.
  • Keep the distinction visible: character = the symbol; character set = the defined collection and associated codes.
Teaching principle: start with the problem of representing human language, then introduce character sets as the solution.
0–5 min · Retrieval

Reconnect with binary

  1. What does a computer ultimately use to represent data?
  2. Why is binary suitable for electronic computers?
  3. What is a bit?
  4. Why can't a computer simply store the letter A as a human-readable symbol?
Bridge: Computers process binary patterns, so human characters need a defined numerical/binary representation.
5–13 min · Discover

What is a character set?

A computer needs a consistent way to represent characters such as letters, digits and punctuation.

Character set: a defined collection of characters together with a code associated with each character.

Once a character has a code, that code can be stored and processed as binary data.

Think: If two computers use different codes for the same character, what problem could occur when data is exchanged?

13–22 min · Teach

ASCII

ASCII is a character set used to represent common characters. The textbook identifies ASCII as one of the character sets used in computer representation of text. fileciteturn9file3L226-L232

ASCII uses 7 bits for its standard character codes, giving 128 possible codes.

Examples: A = 65₁₀ = 1000001₂; a = 97₁₀ = 1100001₂.

ASCII includes upper- and lower-case letters, digits, punctuation and control characters.

22–31 min · Teach

Why Unicode?

ASCII is limited because its standard 7-bit code provides only 128 character codes. Modern computing needs to represent characters from many writing systems.

Unicode provides a much larger character repertoire. The textbook describes Unicode as a character set representing all the languages of the world and notes that its first 128 characters are the same as ASCII. fileciteturn8file3L201-L206

Key idea: Unicode allows computers to represent far more characters than the original ASCII character set.

37–42 min · Guided activity

Decode the idea

Students work with these decimal ASCII codes:

65 · 66 · 67 · 97 · 98 · 99

Ask students to identify the characters and then explain why the codes for upper- and lower-case letters are different.

Extension: Ask students to convert one of the decimal codes into binary using their place-value knowledge.
42–46 min · Assessment

Cambridge-style questions

  1. Define the term character set.
  2. State how many bits are used by standard ASCII.
  3. Explain one limitation of ASCII.
  4. Explain why Unicode is useful.
Look for: students must explain the need for Unicode, not simply state that it “has more characters”.
46–50 min · Exit ticket

Three questions before you leave

  1. What is a character set?
  2. How many standard ASCII codes are available?
  3. Why is Unicode needed?
Teacher decision: Period 12 can deepen ASCII/Unicode with binary codes, storage implications and practical encoding/decoding exercises.

1 · What is a character set?

A character set defines a collection of characters and gives each character a code.

Character → code → binary data stored by the computer.

For example, a character such as A can be associated with a numerical code, which can then be represented in binary.

2 · ASCII

Standard ASCII uses 7 bits.

2⁷ = 128 possible codes

Some familiar examples:

CharacterDecimalBinary
A651000001
B661000010
a971100001

4 · Why Unicode?

ASCII has a limited number of codes. Modern computers need to represent characters from many languages and writing systems.

Unicode provides a much larger character repertoire and is designed for international text.

The Cambridge textbook states that Unicode represents all the languages of the world and that its first 128 characters are the same as ASCII. fileciteturn8file3L201-L206

7 · Think like an examiner

Question: Explain why Unicode is needed instead of relying only on ASCII.

Standard ASCII has only 128 codes, so it cannot represent the very large range of characters needed for worldwide languages. Unicode provides a much larger character repertoire.

9 · Common mistakes

  • Saying ASCII and Unicode are programming languages.
  • Confusing a character with its code.
  • Thinking ASCII can represent every writing system.
  • Forgetting that the original ASCII standard uses 7 bits.
  • Giving “Unicode has more characters” without explaining why that matters.
