Character Representation

How does a computer store letters, digits, punctuation and symbols when everything inside the computer is represented using bits?

Characters ASCII Extended ASCII Unicode Character Sets

1. What Is Character Representation?

A computer does not store a letter such as A directly as a letter.

Instead, a character is assigned a numerical code. That numerical code is then stored using binary.

Character A
→
Character Code 65
→
Binary 01000001
💡 Key idea: A character set assigns a numerical value to each character. The computer stores that value in binary.

2. Character Sets

A character set is a collection of characters together with a unique code assigned to each character.

For example, a character set may contain:

A B C a b 1 2 + ? @ £ !

Each character is assigned a numerical code. The computer can therefore store and process the characters using binary numbers.

3. ASCII

ASCII stands for American Standard Code for Information Interchange.

ASCII is a character encoding system that assigns numerical codes to characters.

The Original ASCII Character Set

Original ASCII uses 7 bits.

27
=
128

Therefore, 7 bits can represent 128 different values.

These codes include letters, digits, punctuation and control characters.

5. Discovering Patterns in ASCII

ASCII codes are not random. There are useful patterns.

Uppercase Letters

A = 65

B = 66

C = 67

The codes increase by 1.

Lowercase Letters

a = 97

b = 98

c = 99

The codes also increase by 1.

Digits

0 = 48

1 = 49

2 = 50

Digits have consecutive codes.

6. The Limitation of ASCII

Original ASCII uses only 7 bits, giving it 128 possible codes.

This is enough for many common English characters, but it is not enough to represent the enormous number of characters, symbols and writing systems used around the world.

English Many characters supported
Many other scripts Not adequately represented
Large symbol collections More codes are required

7. Extended Character Sets

One approach to increasing the number of available codes was to use 8 bits rather than 7 bits.

28
=
256

Using 8 bits gives 256 possible values.

However, different extended character encodings used the additional values in different ways. This could cause compatibility problems between systems.

⚠ Important: Simply increasing the number of bits does not automatically create one universal character set.

8. Unicode

Unicode was developed to provide a much larger and more consistent character repertoire.

It supports characters from many different writing systems around the world, as well as a large collection of symbols.

A Latin
Ω Greek
Ж Cyrillic
中 Chinese
ع Arabic
अ Devanagari

This makes Unicode much more suitable for modern international computing.

9. Why Unicode Is Important

🌍 International Communication

Computers need to represent text from many languages and writing systems.

💻 Consistency

A common standard helps different computer systems exchange and display text reliably.

🔣 More Symbols

Modern computing requires far more characters than traditional ASCII could provide.

📱 Modern Technology

Websites, applications and digital communication need broad character support.

🕵️ Fix the Mistake

Student statement:

"ASCII stores letters directly as letters."
Not quite. ASCII assigns a numerical code to each character. The computer stores the numerical code in binary.

Student statement:

"ASCII uses 8 bits and therefore has 256 codes."
Original ASCII uses 7 bits, giving 128 possible codes. 8-bit extended character sets can provide 256 values, but these are not simply the same thing as original ASCII.

Student statement:

"Unicode is only another name for ASCII."
No. Unicode is a much larger character repertoire designed to support characters from many writing systems and symbols.
