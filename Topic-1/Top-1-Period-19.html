My teaching route
Lesson overview

Period 19 · RLE with Bitmap Images

Cambridge focus: Apply Run Length Encoding to simple image data and explain how repeated pixel values can be represented more efficiently. RLE is a lossless compression method specified by the Cambridge syllabus.

Success criteria: Students can read a simple row of pixel values, identify consecutive runs, encode them using count + value, decode the result, and explain why RLE can be effective for images containing large areas of the same colour.

Prior learning: Period 18 — basic RLE encoding and decoding.

Key vocabulary: bitmap, pixel, pixel value, run, count, value, encode, decode, lossless, compression.

My teaching route

Make RLE visual

Use a row of coloured squares or 0/1 values on the board.

  1. Read pixels from left to right.
  2. Group identical consecutive values.
  3. Write each run as count + value.
  4. Compare the original pixel sequence with the encoded sequence.
  5. Decode it back to prove the image data is preserved.
Teaching message: RLE does not change the image. It changes how repeated pixel data is stored.

34–40 min · Image reasoning

Why can RLE be effective for images?

Images often contain areas where neighbouring pixels have the same colour.

  • A large white background can create long runs of the same value.
  • A large block of one colour can create long runs.
  • Long runs are represented compactly by a count and value.
Contrast: a highly detailed image with rapidly changing pixel values may contain many short runs and gain little from RLE.

1 · Pixel values

For a simple black-and-white image:

0 = black    1 = white

Example:

0000000011111111000000

2 · Find the runs

Group consecutive identical pixels:

00000000 | 11111111 | 000000

So the runs are:

8 zeros | 8 ones | 6 zeros

3 · Encode

8 0   8 1   6 0

This stores the count followed by the pixel value.

Remember: count + value, not value + count.

9 · Exam practice

Explain why RLE is particularly suitable for an image containing large areas of one colour.

Large areas of one colour create long runs of identical pixel values. RLE can represent each long run using a count and value instead of storing every pixel separately, reducing the amount of data.

10 · Common mistakes

  • Combining identical pixels that are separated by other pixels.
  • Writing value before count when the agreed format is count + value.
  • Forgetting that RLE must be decoded back to the original data.
  • Assuming every image gets a large reduction from RLE.
