DR-10

Sound Representation
From Sound Waves to Digital Data

Sound exists naturally as an analogue signal. Computers, however, store information digitally. In this lesson you will discover how a continuous sound wave is converted into a sequence of numbers that a computer can store and process.

ANALOGUE SOUND
Continuous variation in air pressure
01

What Is Sound?

🌊

Sound is a Wave

When an object vibrates, it causes particles in the surrounding medium to vibrate. These changes travel as a sound wave.

A microphone can detect these changes and convert them into an electrical signal.

🎙️

Microphone

A microphone converts sound waves into an electrical signal.

The electrical signal varies continuously as the sound changes. This is an analogue signal.

💻

Computer

A computer stores information using binary data.

Therefore the analogue sound signal must be converted into digital values before it can be stored as a digital audio file.

02

Analogue and Digital

Analogue

  • Continuous signal
  • Can take any value within a range
  • Changes smoothly over time
  • Natural sound is analogue
  • Microphone output can be analogue

Digital

  • Represented using discrete values
  • Stored as binary data
  • Can be processed by computers
  • Can be copied without analogue degradation
  • Digital audio consists of stored numerical samples
Key idea:

The original sound is continuous. A computer cannot directly store that continuous wave. Instead, it takes measurements of the signal at regular intervals.

03

Sampling — Measuring the Sound

Sampling is the process of taking measurements of an analogue sound signal at regular intervals.

Continuous analogue signal
1

The microphone produces a continuous analogue signal.

2

Measurements are taken at regular intervals.

3

Each measurement is called a sample.

4

Each sample is converted into a digital numerical value.

04

Sample Rate

Sample rate

The number of samples taken from an analogue sound signal per second.

Measured in samples per second (Hz)

Low Sample Rate

Fewer measurements are taken. More detail between samples may be lost.

High Sample Rate

More measurements are taken every second, giving a more detailed representation of changes in the original signal.

Remember:

Increasing the sample rate means that the computer takes measurements more frequently.

05

Sample Resolution / Bit Depth

Sampling tells us when measurements are taken. We also need to know how precisely each measurement is represented.

0 1 2 3

Low Sample Resolution

Fewer possible values are available to represent the amplitude of each sample.

0 1 2 3 4 5 6 7

Higher Sample Resolution

More possible values allow each sample to represent the original signal more precisely.

Sample resolution / bit depth

The number of bits used to store the value of each sample.

More bits per sample provide more possible amplitude values.

06

How Sampling Affects Quality

01

Increase Sample Rate

More samples are taken each second.

This gives a more detailed representation of how the signal changes over time.

Higher sample rate → better representation of time variation
02

Increase Sample Resolution

More bits are available to represent each sample.

This allows the amplitude of the original signal to be represented more precisely.

Higher resolution → more possible amplitude values
03

Increase Both

A high sample rate and high sample resolution can produce a more accurate digital representation of the original sound.

Better representation → potentially larger file size
07

Quantisation

A real analogue signal can have a huge number of possible amplitude values. A digital system has a limited number of values available.

Original Signal

The analogue signal varies continuously.

→

Quantised Values

7 6 5 4 3 2 1 0

Each sample is assigned the nearest available digital level.

Key idea:

Quantisation converts each measured sample into one of the available discrete values.

If there are too few possible values, the digital representation may be less accurate.

08

Sample Rate vs Sample Resolution

Sample Rate Sample Resolution
Question How often are measurements taken? How precisely is each measurement represented?
Related to Samples per second Bits per sample
Increasing it More samples every second More possible values per sample
Effect More detail over time More precise amplitude representation

Mistake 1

“Sampling means converting binary into sound.”

Mistake 2

“Sample rate tells us how many bits are used for each sample.”

Mistake 3

“Increasing sample resolution means fewer possible values.”

Mistake 4

“A digital recording is exactly the same continuous signal as the original sound.”

How to Answer Sound Questions

  1. Identify the concept. Is the question about sampling, sample rate, sample resolution or quantisation?
  2. Define the term. Use precise Computer Science terminology.
  3. Explain the effect. Do not merely say “better quality”. Explain what changes.
  4. Compare carefully. If two recordings are compared, identify what stays the same and what changes.
  5. Link quality and storage. Higher sampling settings generally require more data. DR-11 will calculate exactly how much.
Weak answer: “Higher sample rate gives better sound.”

Stronger answer: “A higher sample rate takes more samples each second, giving a more detailed representation of how the analogue signal changes over time.”
