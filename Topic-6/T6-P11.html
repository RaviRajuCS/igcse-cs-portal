Expert Systems

This period teaches the first AI system type explicitly named in Cambridge 0984: the expert system.

Syllabus boundary: Cambridge limits AI in this syllabus to expert systems and machine learning. An expert system has four required components: knowledge base, rule base, inference engine and interface.

1 · What is an expert system?

An expert system is an AI system designed to simulate the decision-making or problem-solving of a human expert in a particular domain.

0–8 min · Retrieval

2 · The four components

ComponentPurpose
Knowledge baseStores facts and knowledge about the specialist subject area.
Rule baseStores rules used to process the knowledge and reach conclusions.
Inference engineApplies the rules to the available facts/knowledge to infer a conclusion.
InterfaceAllows the user to communicate with the expert system and receive information or conclusions.
8–18 min · Teach

3 · Knowledge base

The knowledge base contains information about the specialist area. It represents the knowledge that an expert system can use when solving a problem.

Medical example: the knowledge base may contain information about diseases, symptoms and relevant medical facts.
Do not confuse the knowledge base with the rule base. The knowledge base stores knowledge/facts; the rule base stores rules for using that knowledge.
18–26 min · Teach

4 · Rule base

The rule base contains rules that connect conditions to conclusions or actions.

Illustrative rule: IF a patient has symptom A AND symptom B, THEN consider condition X.

The exact rule depends on the specialist domain. The important examination idea is that rules are used with the stored knowledge to support reasoning.

26–35 min · Teach

5 · Inference engine

The inference engine is the part that applies the rules to the available information and draws conclusions.

FACTS / INPUT
→
INFERENCE
ENGINE
←

→

It is therefore the component most directly associated with the reasoning process in an expert system.

35–42 min · Teach

6 · Interface

The interface provides communication between the user and the expert system.

  1. The user provides information or answers questions.
  2. The interface passes the information to the system.
  3. The system processes the information.
  4. The conclusion or recommendation is returned through the interface.
Example: A fault-diagnosis system asks a technician questions about a machine and then displays a possible cause of the fault.
42–47 min · Guided workout

7 · Trace an expert system

A farmer enters information about a crop into an expert system. The system asks questions, compares the information with stored knowledge and rules, and gives a recommendation. Identify the four components involved.
Interface: receives the farmer's information and presents the result. Knowledge base: stores crop-related knowledge. Rule base: stores rules connecting conditions to recommendations. Inference engine: applies the rules to the available information and produces the conclusion.
47–50 min · Exit ticket

8 · Four words to remember

KNOWLEDGE → RULES → INFERENCE → INTERFACE

Knowledge base stores what is known. Rule base stores how knowledge is used. Inference engine reasons from it. Interface communicates with the user.

4 · Worked Example — Fault diagnosis

A technician enters symptoms of a machine fault. The system uses stored machine knowledge and rules to identify a possible cause.

Interface: technician enters symptoms and receives the result. Knowledge base: machine faults and relevant facts. Rule base: rules linking symptoms to possible causes. Inference engine: applies the rules to the entered information.

5 · Workout — Knowledge or rule?

Classify these examples: “High temperature is a symptom of fault X” and “IF high temperature AND vibration, THEN consider fault X.”
The first is knowledge/fact stored in the knowledge base. The second is a rule stored in the rule base.

6 · Interactive check

Which component applies the rules to available information to infer a conclusion?

7 · Scenario challenge — Medical expert system

A patient answers questions about symptoms through a computer interface. The system produces a possible diagnosis. Explain how the four components could be involved.
Interface: collects symptom information and displays the result. Knowledge base: stores medical facts. Rule base: stores rules connecting symptoms and possible conditions. Inference engine: applies the rules to the available symptom information to infer a possible diagnosis.

8 · Exam-style question

Question: Describe the four components of an expert system.

Knowledge base: stores specialist knowledge/facts. Rule base: stores rules for using the knowledge. Inference engine: applies the rules to available information to infer a conclusion. Interface: allows communication between the user and the system.

9 · Exam-style application

Question: Explain how an expert system could help diagnose a machine fault.

The user enters information about the fault through the interface. The system uses a knowledge base containing information about possible faults and a rule base containing rules linking symptoms to faults. The inference engine applies the rules to the available information and produces a possible conclusion, which is communicated through the interface.

10 · Expert system vs ordinary program

Expert systemOrdinary fixed-rule program
Designed to simulate expert decision-making in a specialist domain.May simply perform a specified sequence of operations.
Uses a knowledge base, rule base and inference engine.May not have these separate components.
Produces conclusions by applying rules to available knowledge/information.May directly calculate or perform programmed operations.

11 · Common mistakes

  • Calling the knowledge base the rule base.
  • Saying the interface does the reasoning.
  • Forgetting the inference engine.
  • Confusing an expert system with a robot.
  • Assuming an expert system must have a physical robot.

12 · Self-assessment

Can you name and explain all four components of an expert system?
