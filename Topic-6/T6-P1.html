6.1 Automated systems · sensors · microprocessors · actuators
Topic 6 · Period 1

Introduction to Automated Systems

This first period introduces the central idea behind an automated system: information is detected by sensors, processed by a microprocessor and used to control actuators.

Cambridge 0984 focus: Candidates must be able to describe how sensors, microprocessors and actuators work together to create an automated system. citeturn0search12

1 · The basic automated-system cycle

SENSOR
detects input
→
MICROPROCESSOR
processes data
→
ACTUATOR
causes action

The system repeatedly detects → processes → acts. The output from the actuator can change the environment, which may then be detected again by the sensor.

0–8 min · Retrieval

2 · What makes a system automated?

A system receives information from its environment, makes decisions according to programmed instructions and carries out actions without a person having to perform every step manually. What makes this an automated system?
The system uses inputs from sensors, processes those inputs using programmed instructions and controls outputs through actuators with limited or no continuous human intervention.
8–18 min · Teach

3 · Sensors — detecting the environment

A sensor detects a physical property and provides data to the system.

SensorWhat it can detectPossible use
Temperature sensorTemperatureAutomatic heating/cooling
Light sensorLight levelAutomatic lighting
Pressure sensorPressureIndustrial monitoring
Moisture sensorMoisture levelAutomatic irrigation
Remember: The sensor provides the input. It does not normally perform the decision itself.
18–27 min · Teach

4 · The microprocessor — processing the input

The microprocessor receives data from sensors and follows a stored program to decide what should happen.

Example: A temperature sensor reports 31°C. The microprocessor compares this value with the programmed threshold. If the temperature is too high, it sends a control signal to the appropriate actuator.
Sensor reading → 31°C
↓
Microprocessor compares with threshold
↓
31°C > 25°C ?
↓
YES → activate cooling
27–35 min · Teach

5 · Actuators — carrying out the action

An actuator converts a control signal into a physical action.

  • motor → moves something
  • heater → produces heat
  • pump → moves liquid
  • lamp → produces light
  • valve → controls flow
The actuator is the component that produces the system's physical output.
35–42 min · Worked example

6 · Example — Automatic greenhouse watering

Moisture Sensor
→
Microprocessor
→
Pump
  1. The moisture sensor measures the moisture level of the soil.
  2. The sensor sends the reading to the microprocessor.
  3. The microprocessor compares the reading with a programmed threshold.
  4. If the soil is too dry, the microprocessor sends a signal to the pump.
  5. The pump supplies water.
42–47 min · Guided workout

7 · Identify the three components

An automatic street light uses a light sensor. When the surroundings become dark, the system switches on a lamp. Identify the sensor, microprocessor and actuator.
Sensor: light sensor. Microprocessor: processes the light-level reading and applies the programmed rule. Actuator: lamp/light that switches on.

8 · Scenario workout

An automatic greenhouse system has a moisture sensor, microprocessor and water pump. Write a four-step explanation of what happens when the soil becomes too dry.

9 · Exam-style question

Question: Describe how a temperature-controlled heating system can operate automatically using a sensor, microprocessor and actuator.

The temperature sensor measures the temperature and sends the data to the microprocessor. The microprocessor compares the reading with a programmed value/threshold. If the temperature is below the required value, it sends a signal to an actuator such as a heater. The heater then raises the temperature.

10 · Common mistakes

  • Calling the sensor the decision-maker.
  • Calling the microprocessor an actuator.
  • Saying the actuator “detects” the environment.
  • Describing the three components separately without explaining their collaboration.
  • Giving a real-world example without identifying the three components.

11 · Exam vocabulary

TermWhat to remember
