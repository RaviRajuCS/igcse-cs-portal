Advantages and Disadvantages of Automated Systems

This period develops the second major requirement of Topic 6.1: evaluating an automated system in a given scenario.

Cambridge focus: Students must be able to explain advantages and disadvantages of an automated system in a given scenario.

1 · What does “evaluate” mean?

In an exam, evaluation means more than listing a benefit and a drawback. A strong answer links each point to the specific scenario.

SYSTEM
→
BENEFIT / DRAWBACK
→
WHY IT MATTERS
IN THIS SCENARIO
Weak: “Automation is faster.”
Stronger: “Automation can complete repetitive factory tasks quickly, increasing production while reducing the time needed for each item.”
0–8 min · Retrieval

2 · Common advantages

  • Speed: repetitive processes can be carried out quickly.
  • Consistency: the programmed process can be repeated in the same way.
  • Accuracy: suitable automated systems can make precise measurements or movements.
  • 24/7 operation: systems can operate for long periods without human fatigue.
  • Safety: people can be kept away from dangerous environments.
  • Productivity: more output can be produced or monitored in a given time.
8–17 min · Teach

3 · Common disadvantages

  • Cost: purchasing, installing and maintaining equipment can be expensive.
  • Job displacement: some repetitive human jobs may be reduced.
  • Maintenance: sensors, processors and actuators can fail and need servicing.
  • Dependence on programming: an incorrect program can cause incorrect actions.
  • Power dependence: many automated systems require a reliable power supply.
  • Limited judgement: a system follows its programmed rules and may not handle unexpected situations well.
17–27 min · Scenario example

The same advantage can have different importance depending on the situation.

35–42 min · Worked example

6 · Automatic greenhouse system

A greenhouse uses sensors and automated equipment to control watering and temperature.
  1. Advantage: continuous monitoring allows the system to react when conditions change.
  2. Advantage: automatic watering can reduce the need for constant human supervision.
  3. Disadvantage: faulty sensors could cause incorrect watering or temperature control.
  4. Disadvantage: installation and maintenance add cost.
42–47 min · Guided workout

7 · Evaluation practice

An airport uses automated systems to control access doors. Give two advantages and two disadvantages. Explain each one in the context of airport access.
Advantages: automated doors can operate quickly and consistently; access can be controlled according to programmed conditions. Disadvantages: a sensor or actuator failure could prevent correct operation; installation and maintenance can be costly.
47–50 min · Exit ticket

8 · The “because” test

After every advantage or disadvantage, add “because…” and explain its effect on the scenario. This turns a list into an explanation.

🎯 Learning targets

  • State common advantages of automation.
  • State common disadvantages of automation.
  • Explain why each point matters in a particular scenario.
  • Distinguish between a simple statement and a developed explanation.
  • Evaluate an automated system using balanced points.

1 · Quick check

Which is most likely to be an advantage of an automated system performing a repetitive task?

2 · Workout — Develop the point

Turn this statement into a developed answer: “Automation is fast.”
Automated systems can carry out repetitive operations quickly, so a factory may produce more products in a given amount of time.

3 · Interactive check

Which is a realistic disadvantage of automation?

4 · Scenario workout — Agriculture

An automated irrigation system waters crops according to soil moisture. Give one advantage and one disadvantage, each linked to agriculture.
Advantage: crops can be watered automatically when the soil becomes too dry, reducing the need for constant supervision. Disadvantage: a faulty moisture sensor could cause the system to supply too much or too little water.

5 · Worked comparison

PointGood explanation
SafetyPeople can be kept away from hazardous industrial processes.
CostEquipment may require a large initial investment and ongoing maintenance.
ConsistencyThe same programmed process can be repeated without human fatigue.
FailureA system fault can stop a process or produce an unsafe result.

6 · Interactive check

Why is “expensive” a better answer when it is explained as “expensive to install and maintain”?

7 · Challenge — Transport

An automated braking system is used in vehicles. Write two advantages and two disadvantages. Try to make every point scenario-specific.
Advantages: rapid response can help reduce collision risk; automated monitoring can operate continuously. Disadvantages: sensor/software failure could cause incorrect braking; installation and maintenance can be costly.

8 · Exam-style question

Question: A factory is considering an automated system for a repetitive manufacturing task. Explain two advantages and two disadvantages of using the system.

Advantages: the system can work quickly and consistently, increasing production; workers can be kept away from dangerous machinery. Disadvantages: purchase and maintenance can be expensive; faults in sensors, actuators or the program could stop production or cause incorrect actions.

9 · Exam writing frame

Advantage: The system can ________, which means ________ in this scenario.

Disadvantage: If ________ fails/is incorrect, ________ could happen in this scenario.

10 · Common mistakes

  • Writing only a list of advantages and disadvantages.
  • Using the same vague point for every scenario.
  • Claiming automated systems never make errors.
  • Forgetting installation, maintenance or failure costs.
  • Giving a disadvantage without explaining its consequence.

11 · Self-assessment

Can you give balanced, scenario-specific advantages and disadvantages rather than generic lists?
