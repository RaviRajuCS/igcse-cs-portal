Topic 6 · Period 12

Machine Learning

This period covers the second and final AI system type named in Cambridge 0984: machine learning.

Exact syllabus focus: Machine learning is when a program has the ability to automatically adapt its own processes and/or data.

8–18 min · Teach

3 · Automatic adaptation

In machine learning, the important idea is automatic adaptation. A programmer does not have to manually rewrite the program every time the system needs to adjust.

Illustrative example: A recommendation system receives information about user choices. Its process can adapt to those patterns so that later recommendations can change.
For this syllabus, you do not need to teach a particular machine-learning algorithm. Concentrate on the idea of automatic adaptation.
18–27 min · Teach

4 · Adaptation of processes

A machine-learning program may adapt how it processes information.

Suppose a system repeatedly receives examples and its process is adjusted automatically so that it becomes better at producing an appropriate result from later examples.

The key point is that the process changes automatically as part of the learning system.

27–35 min · Teach

5 · Adaptation of data

The syllabus also allows the program to adapt its data. This means the information used by the system can be automatically updated or adjusted as new information becomes available.

A recommendation system can continually update the information it holds about a user's choices so that future recommendations reflect newer information.
35–42 min · Compare

6 · Fixed program vs machine learning

Fixed programmed systemMachine-learning system
Uses instructions that remain unchanged unless a programmer changes them.Can automatically adapt its own processes and/or data.
Example: IF temperature < 20 THEN switch heater on.Example: a system adapts its process/data as new examples or information are provided.
Behaviour is determined by the fixed program.Behaviour/process or data can change automatically through the learning system.
42–47 min · Guided workout

7 · Is it machine learning?

A program always uses exactly the same fixed rules to classify incoming data. A programmer must manually change the code whenever the rules need to change. Does this, by itself, demonstrate machine learning?
No. The description shows a fixed programmed system. Machine learning requires the program to have the ability to automatically adapt its own processes and/or data.
47–50 min · Exit ticket

8 · One sentence to remember

Machine learning = automatic adaptation of a program's own processes and/or data.

7 · Scenario challenge — Changing information

A system receives new examples over time and automatically adjusts the process it uses to produce later results. Explain why this fits the definition of machine learning.
It fits the definition because the program automatically adapts its own process as new information is received. The adaptation occurs as part of the program rather than requiring a programmer to manually rewrite it each time.

8 · AI comparison

9 · Expert system vs machine learning

Expert system: uses a knowledge base, rule base, inference engine and interface to simulate expert decision-making.
Machine learning: a program has the ability to automatically adapt its own processes and/or data.
Both are within the Cambridge 0984 AI scope, but they describe different approaches.

10 · Exam-style question

Question: What is meant by machine learning?

Machine learning is when a program has the ability to automatically adapt its own processes and/or data.

11 · Exam-style application

Question: Explain why a program that automatically changes how it processes new information can be described as using machine learning.

The program is automatically adapting its own process as new information is received. This matches the syllabus definition of machine learning, which is the ability of a program to automatically adapt its own processes and/or data.

12 · Common mistakes

  • Defining machine learning as simply “AI that learns”.
  • Forgetting the word automatically.
  • Ignoring the possibility of adapting processes and/or data.
  • Calling every program that uses data machine learning.
  • Assuming a programmer must manually change the code for it to count as machine learning.
