Section B — Automated Systems and Robotics

Q6. [2]

Explain the role of an actuator in an automated system.

An actuator receives a signal from the microprocessor and produces a physical action, such as moving a motor, opening a valve or switching a device.
Q7. [2]

A greenhouse uses a temperature sensor. When the temperature becomes too high, the microprocessor switches on a fan. Identify the sensor input and the actuator.

Sensor input: the temperature reading. Actuator: the fan/motor that produces the physical action of moving air.
Q8. [2]

State one advantage and one disadvantage of using robots for repetitive manufacturing.

Advantage: a robot can repeat the task consistently and may increase productivity. Disadvantage: purchase/maintenance costs can be high, or a fault may stop production.
Q9. [2]

Explain why a robot may be suitable for work in a dangerous environment.

The robot can carry out the task while reducing a human worker's exposure to the dangerous environment.
Q10. [2]

A mobile robot repeatedly detects an obstacle, changes direction and then checks its surroundings again. Explain how feedback is involved.

Sensors provide new information about the obstacle. The controller processes it and changes the motor/actuator action. After the robot moves, new sensor readings are taken and used for the next decision.
Q11. [2]

A warehouse robot transports boxes. Give two reasons why this task may be suitable for a robot.

The task is repetitive and can be programmed. The robot can work consistently for long periods and can use sensors to navigate and detect obstacles.
Q12. [2]

State one limitation that could make a robot unsuitable for a particular task.

Possible limitations include high cost, maintenance requirements, component failure, safety risks, or difficulty dealing with unexpected situations.
14 marks

Section C — Artificial Intelligence

Q13. [2]

Give the Cambridge 0984 definition of artificial intelligence.

Artificial intelligence is a branch of computer science dealing with the simulation of intelligent behaviours by computers.
Q14. [2]

Explain the difference between a knowledge base and a rule base in an expert system.

The knowledge base stores specialist facts/knowledge. The rule base stores rules for using that knowledge to reach conclusions.
Q15. [2]

What is the role of the inference engine in an expert system?

It applies the rules to available information/knowledge to infer a conclusion or recommendation.
Q16. [2]

What is the role of the interface in an expert system?

It allows the user to communicate with the expert system, providing information and receiving its conclusions or recommendations.
Q17. [2]

State the four components of an expert system.

Q18. [2]

Explain one way in which machine learning differs from a fixed programmed system.

A fixed programmed system follows instructions that remain unchanged unless a programmer changes them. Machine learning allows a program to automatically adapt its own processes and/or data.
Q19. [2]

AI can include the ability to learn and adapt. What does “adapt” mean in the context of machine learning?

The program can automatically change or adjust its own processes and/or data in response to information or experience.
12 marks

Section D — Scenario and Evaluation

Q20. [4]

A hospital considers using a robot to deliver supplies around the hospital. The robot uses sensors to detect obstacles and motors to move.

(a) Explain how the sensors, microprocessor/controller and motors work together. (2)
(b) Give one advantage and one limitation of using this robot. (2)

Model: (a) Sensors detect information such as obstacles; the controller processes the readings and sends signals to the motors, which move the robot. (b) Advantage: reduces routine human work and can operate repeatedly. Limitation: faults, maintenance, cost or unexpected situations may interrupt the service.
Q21. [4]

A company uses an expert system to diagnose faults in machines.

Explain how the knowledge base, rule base, inference engine and interface could work together to produce a diagnosis.

Model: The interface collects information from the user. The knowledge base stores specialist information about machine faults. The rule base contains rules linking symptoms/conditions to possible faults. The inference engine applies the rules to the available information and infers a possible diagnosis, which is returned through the interface.
Q22. [4]

A recommendation program automatically changes the process it uses as new user information is received.

Explain why this is an example of machine learning and distinguish it from an ordinary fixed-rule program.

Model: It is machine learning because the program automatically adapts its own process using new information. A fixed-rule program continues to use its programmed rules unless a programmer manually changes them.
