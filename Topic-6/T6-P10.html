Introduction to Artificial Intelligence

This period begins 6.3 Artificial Intelligence using the exact Cambridge 0984 scope: what AI means and its main characteristics.

Cambridge 0984 focus: AI is a branch of computer science dealing with the simulation of intelligent behaviours by computers. Its characteristics include the collection of data and rules for using that data, the ability to reason, and it can include the ability to learn and adapt.

1 · What is Artificial Intelligence?

Artificial intelligence (AI) is a branch of computer science dealing with the simulation of intelligent behaviours by computers.

The final characteristic is not required in every AI system; Cambridge states that AI can include the ability to learn and adapt.

0–8 min · Retrieval

2 · The four ideas to remember

IdeaMeaning
Collection of dataAI systems use data as information about the problem or environment.
Rules for using dataInstructions or rules determine how the available data is used.
ReasoningThe system can use information and rules to reach a conclusion or decision.
Learning and adaptingSome AI systems can automatically improve/adapt their processes and/or data.
8–18 min · Teach

3 · AI is more than “following instructions”

A conventional program can follow a fixed sequence of instructions. AI systems can be designed to simulate aspects of intelligent behaviour by using data and rules to reach decisions.

Example: A system receives information about symptoms and uses stored knowledge and rules to help reach a possible diagnosis. The important idea is not that the computer is human, but that it is simulating aspects of intelligent behaviour.
Do not confuse: automation and AI. An automated system can operate from fixed programmed rules without being an AI system.
18–27 min · Teach

4 · Data and rules

AI needs information to work with. The system also needs a method for using that information.

COLLECT / PROVIDE
DATA
→
APPLY
RULES
→
REASON / DECIDE

For example, an AI system for identifying objects may receive image data and use rules or learned processes to classify what it has detected.

27–35 min · Teach

5 · Reasoning

Reasoning means using available information and rules to reach a conclusion or decision.

Example: If a system has information about a patient's symptoms and medical rules, it can reason from the available information to suggest possible conditions.
In an exam, explain what information is used and how it leads to the decision. Avoid simply writing “the computer thinks”.
35–42 min · Teach

6 · Learning and adaptation

Some AI systems can learn from data and adapt their own processes and/or data. This is particularly important when introducing machine learning, which will be studied in a later period.

Simple idea: A system receives many examples, detects useful patterns and adjusts its process so that it can make better predictions on later data.
42–47 min · Guided workout

7 · Is it AI or ordinary automation?

A lighting system switches a lamp on whenever a light sensor detects that the room is dark. Is this automatically an example of AI? Explain.
Not necessarily. This is an automated system using a sensor, a programmed rule and an actuator. It does not by itself demonstrate the AI characteristics required in the syllabus.
47–50 min · Exit ticket

8 · AI in one sentence

AI = computer systems simulating intelligent behaviour, using data and rules to support reasoning, and sometimes learning and adapting.

4 · Worked Example — Decision system

A system receives information about a problem and applies stored rules to reach a recommendation.

The data provides information about the problem. Rules describe how the information should be used. The system reasons from the available information to produce a conclusion.

5 · Workout — Explain reasoning

A student writes: “The AI thinks the answer is correct.” Improve this explanation so it describes reasoning more accurately.
The system uses the available data and programmed/learned rules to analyse the information and reach a conclusion or decision.

6 · Interactive check

7 · Scenario challenge — Recommendation system

A system uses information about previous choices to recommend items to a user. Explain how data and reasoning could be involved.
The system collects information about previous choices. It uses rules or learned processes to analyse the data and identify patterns. It then reasons from the available information to produce recommendations.

8 · Automation vs AI

AutomationArtificial intelligence
Can use fixed programmed rules to perform a task automatically.Simulates intelligent behaviour using data and rules and can include reasoning and learning/adaptation.
Example: light turns on below a fixed threshold.Example: a system analyses data to classify or predict an outcome.

9 · Exam-style question

Question: What is meant by artificial intelligence?

Artificial intelligence is a branch of computer science dealing with the simulation of intelligent behaviours by computers.

10 · Exam-style question

Question: Describe the main characteristics of AI.

AI systems involve the collection of data and rules for using that data, the ability to reason, and can include the ability to learn and adapt.

11 · Common mistakes

  • Defining AI as simply “robots”.
  • Assuming every automated system is AI.
  • Saying AI is exactly the same as human intelligence.
  • Forgetting the role of data and rules.
  • Saying every AI system must learn; the syllabus says AI can include learning and adaptation.

12 · Self-assessment

Can you define AI and describe its main characteristics without confusing it with ordinary automation?
