7 · Six-mark challenge

Question: A company uses an AI system to diagnose faults in industrial equipment. Explain how an expert system could perform this task and distinguish it from a machine-learning system.
An expert system could use an interface to collect information about the equipment. A knowledge base could store information about faults, while a rule base could contain rules linking symptoms to possible faults. The inference engine applies the rules to the available information to infer a conclusion. A machine-learning system is different because its defining feature is that the program can automatically adapt its own processes and/or data.
47–50 min · Exit ticket

7 · Scenario question

A technician enters information about a machine fault. The system asks questions and gives a possible cause. Which expert-system components are involved?
The interface communicates with the technician; the knowledge base stores fault information; the rule base stores rules linking symptoms to faults; and the inference engine applies those rules to infer a possible cause.

8 · Distinguish the systems

System A uses a stored knowledge base and rules to infer diagnoses. System B automatically changes its process as new data is received. Identify A and B.
System A: expert system. System B: machine learning.

9 · Exam-style question

Question: Describe the main characteristics of AI.

AI involves the collection of data and rules for using that data, the ability to reason, and it can include the ability to learn and adapt.

10 · Common exam traps

  • Writing “AI is robots”.
  • Forgetting that AI is a branch of computer science.
  • Confusing knowledge base with rule base.
  • Giving “the computer thinks” instead of explaining reasoning.
  • Defining machine learning without the idea of automatic adaptation.
  • Teaching or writing about advanced ML algorithms when the 0984 syllabus does not require them here.

11 · Final self-test

Without looking back, can you write the three essential AI statements?

1. AI = simulation of intelligent behaviour by computers.
2. Expert system = knowledge base + rule base + inference engine + interface.
3. Machine learning = automatic adaptation of processes and/or data.
