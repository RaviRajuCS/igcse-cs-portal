Robotics: Sensors, Actuators and Feedback

This period brings the robotics ideas together. Students trace how a robot senses its environment, processes information and produces a physical response, including repeated feedback.

Key idea: Robot control is not a single action. Sensor readings can be taken repeatedly so that the robot continually adjusts its behaviour.

3 · What is feedback?

Feedback occurs when information about the current state of a system is returned to the controller and used to influence the next action.

Example: A robot is moving toward a wall. Its distance sensor repeatedly measures the distance. As the distance becomes smaller, the controller can change the motor commands so the robot turns away.
Exam distinction: The sensor provides the information; the controller processes it; the actuator performs the response.

5 · Temperature-controlled robot system

A robot-controlled system must maintain a target temperature.
  1. A temperature sensor measures the current temperature.
  2. The controller compares it with the programmed target.
  3. If the temperature is too low, the controller activates a heater.
  4. The temperature changes.
  5. The sensor measures the new temperature and supplies feedback for the next decision.

7 · Analyse the feedback loop

A robot approaches an obstacle. It slows down as the measured distance becomes smaller, then turns away. Explain how feedback is involved.
The distance sensor repeatedly measures the obstacle distance. The controller processes the readings and changes the motor commands as the distance changes. After the robot moves, the sensor takes another reading, providing feedback for the next decision.

4 · Worked Example — Line following

A robot follows a dark line on a light floor. It changes the speed of its left and right motors when the line moves away from the sensors.

The sensors detect the line position. The controller processes the readings and changes motor speeds. The robot moves, the line position changes relative to the sensors, and new readings provide feedback.

5 · Workout — Explain the actuator

In a line-following robot, what does the actuator do after the controller makes a decision?
The motors change the robot's movement, for example by changing the speed of the left or right wheel so the robot adjusts its direction.

7 · Scenario challenge — Obstacle avoidance

A robot repeatedly checks its distance from a wall and turns when it becomes too close. Explain the complete feedback process.
The distance sensor measures the wall distance. The controller processes the reading and checks the programmed condition. If the robot is too close, it sends signals to the motors to turn. The robot moves, then the sensor measures the distance again. This new reading provides feedback for the next control decision.

8 · Exam-style question

Question: Explain how feedback can be used by a robot to follow a line.

Sensors detect the position of the line. The controller processes the sensor readings and follows programmed instructions to decide how the robot should adjust. Motor/actuator speeds are changed to correct the direction. The robot moves and the sensors take new readings, which provide feedback for the next adjustment.

9 · Exam vocabulary

TermMeaning
FeedbackInformation about the current state returned to the controller and used for subsequent control.
Sensor readingMeasured input about the robot's environment or condition.
Control actionAn instruction sent to an actuator to change the physical system.
LoopA repeated cycle of sensing, processing and acting.

10 · Common mistakes

  • Calling the actuator the source of feedback.
  • Describing only the first sensor reading and forgetting repetition.
  • Forgetting that the controller processes the sensor data.
  • Saying feedback means the robot “learns” automatically.
  • Failing to explain how the new reading affects the next action.
