Sensors, Microprocessors & Actuators in Greater Depth

Students now move from naming the three components to explaining what each component does in an automated system, using suitable sensor and actuator examples.

Cambridge 0984 focus: Candidates must describe how sensors, microprocessors and actuators work together to create an automated system and apply this knowledge to given scenarios.

The sensor converts information about the environment into data that can be processed. The microprocessor applies the programmed rules. The actuator converts the resulting control signal into an action.

4 · Microprocessor: compare, decide, control

Sensor input: Temperature = 18°C
Required temperature = 22°C

Microprocessor compares:
18 < 22 ?

YES → send control signal to heater
NO → keep heater off

The microprocessor does not simply “receive data”. It processes the data using the program stored in the system.

27–35 min · Teach

6 · Automatic air-conditioning

Temperature Sensor
→
Microprocessor
→
Cooling Unit / Fan
  1. The temperature sensor measures the room temperature.
  2. The microprocessor receives the reading.
  3. The programmed rule compares it with the required temperature.
  4. If the room is too warm, a control signal is sent.
  5. The actuator operates the cooling equipment.
42–47 min · Guided workout

7 · Scenario analysis

A weather station automatically closes a protective cover when strong wind is detected. Identify a suitable sensor, explain the microprocessor's role and identify a suitable actuator.
Sensor: wind-speed sensor/anemometer. Microprocessor: compares the measured wind speed with a programmed threshold. Actuator: motor that closes the protective cover.
47–50 min · Exit ticket

6 · Workout — Explain the role

Why would saying “the microprocessor detects the person” be inaccurate in an automatic-door answer?
The sensor detects the person. The microprocessor receives and processes the sensor data according to its program.

7 · Interactive check

8 · Scenario workout

A factory machine stops automatically when excessive pressure is detected. Give a suitable sensor, describe the processing and name a suitable actuator.
Sensor: pressure sensor. Processing: microprocessor compares pressure with a programmed safe limit. Actuator: motor/valve mechanism that stops the machine or isolates the process.

9 · Exam-style question

Question: Explain how an automatic greenhouse system can use a moisture sensor, microprocessor and pump.

The moisture sensor measures the soil moisture and sends the data to the microprocessor. The microprocessor compares the reading with a programmed threshold. If the soil is too dry, it sends a control signal to the pump. The pump supplies water to the soil.

11 · Common mistakes

  • Confusing a sensor with an actuator.
  • Leaving out the microprocessor's programmed decision.
  • Choosing an actuator that cannot perform the required physical action.
  • Listing components without explaining the sequence.
  • Using vague phrases such as “the computer does it” instead of precise terminology.

12 · Self-assessment

Can you analyse an unfamiliar automated-system scenario and identify all three main components?
